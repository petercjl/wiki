# 抖音商品卡运营

本目录沉淀抖音货架/商品卡场景的选品、行业判断、商品机会、跟款和竞品分析方法。使用时必须区分稳定经营逻辑与会变化的平台入口、标签、权益和数据口径。

## 阅读顺序

1. [[domains/电商运营/05-抖音/01-商品卡运营/01-行业机会与类目筛选|行业机会与类目筛选]]：先判断行业是否有空间、是否适合当前商家能力。
2. [[domains/电商运营/05-抖音/01-商品卡运营/02-商机中心数据化选品SOP|商机中心数据化选品 SOP]]：再从平台机会池筛选和复核候选商品。
3. [[domains/电商运营/05-抖音/01-商品卡运营/03-跟款生命周期与竞品筛选|跟款生命周期与竞品筛选]]：最后判断增长阶段、竞争强度和可跟性。
4. [[queries/抖音商品卡选品诊断入口|抖音商品卡选品诊断入口]]：让 Agent 按统一输入、顺序和边界完成诊断。

## 使用边界

- 课程数据是 2026 年 1 月快照；后台菜单、字段、权益和资格执行前必须以当前抖店/罗盘页面及官方学习中心为准。
- 课程阈值用于建立筛选假设，不替代类目分位数、完整利润表、退货率、库存和合规判断。
- 没有当前市场数据时，只能给出取数与判断方法，不能断言某类目或商品一定能做。
