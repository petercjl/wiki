# 拼多多多店经营主体与账号合规

多店经营不是注册数量游戏。只有当类目、品牌、风险、团队或经营模型确实需要隔离，并且每家店都能长期合规运营时，多店才有价值。

## 可以成立的多店目的

- 不同品牌或授权链需要分开。
- 不同主营类目、供应链或履约标准需要隔离。
- 不同经营模型需要独立核算和受控测试。
- 避免单店库存、客服和活动承载过度集中，但不能用来规避关联责任。

## 每家店的最低控制要求

| 维度 | 必须回答的问题 |
| --- | --- |
| 主体 | 谁对店铺合同、税务、消费者与平台责任负责？ |
| 授权 | 商标、品牌、商品和类目授权是否真实且在有效期内？ |
| 账号 | 手机号、邮箱、管理员和二次验证是否由公司持续控制？ |
| 财务 | 收款、保证金、推广费、退款和税务能否独立核算？ |
| 供应链 | 库存、采购、发货、售后和质量责任能否对应到店？ |
| 人员 | 员工离职后能否安全收回权限，不依赖其私人号码或身份？ |
| 风险 | 平台是否会把主体、设备、支付、物流或交易行为识别为关联？ |

## 不采用的注册做法

- 购买、租用或使用短期手机号码。
- 借员工、亲友或他人身份绕过主体、账号或数量限制。
- 依赖无法持续控制的私人号码作为主账号。
- 购买所谓“批量注册资源”或利用漏洞突破平台限制。
- 用多店进行关联刷单、补贴套利、重复铺货或处罚规避。

这些做法可能导致账号找回失败、实名争议、关联处罚、资金冻结、税务不清和数据泄露。课程中关于一个主体能注册多少店、等待几天再使用、号码数量等说法均缺少当前官方验证，不进入执行规则。

## 多店立项门槛

新增一家店前，至少完成：

1. 写明新增店解决的具体问题，不能只写“多占流量”。
2. 确认当前官方入驻数量、主体、授权和关联规则。
3. 建立独立预算、库存、利润和风险台账。
4. 指定主账号、备用管理员、权限回收和凭证保管人。
5. 评估最坏情况：某店违规是否影响同主体其他店、保证金和货款。
6. 设退出条件：连续亏损、履约失控、授权到期或组织成本超过增量利润时关闭。
