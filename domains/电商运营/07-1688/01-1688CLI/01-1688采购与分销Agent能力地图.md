# 1688 采购与分销 Agent 能力地图

## 解决什么问题

这套能力把 1688 采购与分销任务拆成七个不同 Skill。Agent 要先识别用户所在阶段、目标对象是否已确定、动作是读取还是写入，再进入正确能力。

## 总览

| Skill | 触发意图 | 核心能力 | 关键输入 | 主要输出 | 风险 |
| --- | --- | --- | --- | --- | --- |
| `1688-product-find` | 找商品、找同款、图搜、链接找货、明确比价 | `text_search`、`image_search`、`link_search`、`compare` | 文本、图片或链接；比价可带规格词 | 完整商品表格与详情链接 | 读取 |
| `1688-source-suppliers` | 找供应商、工厂、地区产业带 | `ali_1688_source_suppliers` | 不经改写的查询关键词 | 公司名称、合作方式、服务等 | 读取 |
| `1688 采购询盘寻源` | 有采购需求但没有具体商品或供应商，希望平台匹配报价 | `procurement` | `offerName`、纯数字 `count`、`demand` | 采购询盘提交结果 | 写入；来源允许字段齐全后直接执行 |
| `1688-marketing-skill` | 查招商活动、建议价、活动报名、商机推荐 | 活动查询、报价查询、报名提交、商机查询 | 活动 ID、商品 ID、报名表单或筛选条件 | 活动、建议价、报名或商机结果 | 报名为写入，必须确认建议价 |
| `1688 分销` | 选品并铺到下游店铺、查分销订单、催发、查知识 | 搜品、分销参谋、店铺、铺货、订单、旺旺、知识库 | 商品/图片、目标店铺、订单或知识条件 | 候选商品、铺货/订单/回复结果 | 铺货需明确确认；品牌授权门禁 |
| `88 生意通` | 管理线下交易采购单 | 查询、创建、签署、拒签、收货、失效、退款 | 角色、对方登录名、商品、采购单号 | 采购单与状态结果 | 资金或状态变化需二次确认 |
| `1688-shopkeeper` | 店管家搜品、查绑定店铺、跨平台铺货 | `search`、`shops`、`publish`、`check` | 关键词、渠道、店铺、数据 ID | 商品、店铺或铺货结果 | 搜索读取；铺货写入 |

## 商品搜索与比价

`1688-product-find` 的统一入口是 `python3 {baseDir}/cli.py <command> [options]`。

| 命令 | 用途 | 来源示例 |
| --- | --- | --- |
| `text_search` | 自然语言搜商品 | `cli.py text_search --query "黑色连帽卫衣"` |
| `image_search` | 图片找同款 | `cli.py image_search --image "/path/to/image.jpg"` |
| `link_search` | 商品链接找同款 | `cli.py link_search --url "https://detail.1688.com/offer/xxx.html"` |
| `compare` | 图片或链接直接比价 | `cli.py compare --image "商品图片URL" --query "规格关键词"` 或 `--url` |
| `configure` / `get_ak` | AK 管理与自动获取 | 设置、状态、清除、重置 |

图片或链接默认是找同款；只有用户明确说“比价、比较、哪家便宜”时才选择 `compare`。`compare` 已内置搜索/解析，不应先额外运行图搜或链搜。默认保留 TOP 3，除非用户明确要求其他数量。

## 供应商与产业带查询

`1688-source-suppliers` 使用 `ali_1688_source_suppliers --query "<关键词>"`。适用于查供应商、工厂、生产厂家、加工厂或某地区产业带，不适用于普通商品浏览。

输出记录的完整性门槛是公司名称、合作方式、服务都不为空；不得虚构公司、地址或联系方式，也不得未经同意改写关键词。来源要求先输出工具 `markdown`，再放供应商入口，最后才可放分析。

## 采购询盘寻源

`procurement --offerName "商品" --count "10" --demand "要求"` 用于“需求已存在，但商品和供应商尚未确定”的场景。`offerName` 是商品名；`count` 必须是纯数字；`demand` 是价格、材质、交付速度等要求。缺哪个字段就单独追问哪个字段。该来源把 `procurement` 视为写入，但规定字段明确时可直接发起；改写用户需求前要征得同意。

## 招商活动与商机

| 命令 | 作用 | 风险/限制 |
| --- | --- | --- |
| `1688_enroll_activity_query` | 查询招商活动 | 只读 |
| `1688_enroll_offer_query` | 查询商品建议提报价 | 只读；返回价格单位为分 |
| `1688_enroll_submit_item` | 提交活动报名 | 写入；输入价格单位为元；必须先确认建议价 |
| `1688_opp_recommend` | 查询商机推荐 | 只读，可按关键词、类目、页码筛选 |
| `configure` / `get_ak` | 管理或获取 AK | 配置动作 |

活动报名固定顺序：查活动 → 选择活动和商品 → 查建议价 → 展示建议价 → 商家明确确认 → 构造有/无 SKU 表单 → 提交。建议价为空时中断。

## 分销全链路

| 工具 | 用途 |
| --- | --- |
| `distribution_select_offer` | 关键词选品 |
| `same_img_offer_search` | 图搜选品 |
| `distribution_offer_info` | 分销参谋与商品详情 |
| `shop_and_tool_info` | 绑定店铺与工具列表 |
| `distribute_offer` | 铺货到下游店铺 |
| `fx_query_order` | 查询分销订单 |
| `fx_send_ww` / `fx_ww_reply` | 旺旺催发与回复查询 |
| `distribution_knowledge_tool` | 分销知识库查询 |

来源快照中的调用方式：

| 能力 | CLI 调用骨架 |
| --- | --- |
| 关键词选品 | `python3 scripts/cli.py product_search_helper search --filters='[...]'` |
| 图搜选品 | `python3 scripts/cli.py product_search_helper search --image_url="..."` |
| 分销参谋 | `python3 scripts/cli.py offer_info query --offer_id="..."` |
| 店铺查询 | `python3 scripts/cli.py shop_info query` |
| 铺货 | `python3 scripts/cli.py distribute_helper execute --app_key="..." --shop_code="..." --channel="..." --offer_ids="..."` |
| 查分销订单 | `python3 scripts/cli.py order_helper query [--order_id=...] [--order_status=...]` |
| 旺旺催发/查回复 | `order_helper send --question="..." --order_ids=...` / `order_helper query_reply --task_id=...` |
| 查分销知识 | `knowledge_helper query --query="..." [--channel="..."] [--business="..."]` |

用户要求 N 个候选时：N≤25 请求 `min(N×2, 50)`；25<N≤50 请求 50；未指定时请求 20 并取前 10。精选优先级是代发价低、30 天分销单量高、服务好。候选必须经过品牌授权检查：`isBrandOffer=true` 且 `isBrandAuth=false` 时禁止铺货。

## 88 生意通采购单

命令覆盖 `account`、`contract-list --role BUYER --page 1 --size 10`、`contract-detail --draft-no <采购单号>`、`contract-summary`、`create-order --role BUYER --counterparty "对方登录名" --items '<JSON>'`、`sign-order --draft-no <采购单号>`、`sign-reject`、`confirm-receipt`、`invalidate-order`、`refund-apply`、`configure` 和 `check`。

典型路径：账号准入 → 创建采购单 → 买家签署 → 查询详情。只读查询可直接执行；创建/签署等写入先确认；退款、确认收货、失效和拒签等资金或状态变化必须二次确认。仅支持主账号和采购单，合同类交易和支付转网页端。

## 店管家

`1688-shopkeeper` 使用 `search --query "连衣裙" --channel douyin`、`shops`、`publish --shop-code CODE --data-id ID`、`configure`、`check`。首次运行先 `check`，再按字段分支：`ak_configured: false` 先配置；`shops_count: 0` 引导开店；`expired_count > 0` 重新授权；全部正常才进入搜品和铺货。刚配置 AK 时，来源要求当前会话命令前加 `ALI_1688_AK=xxx`，重启 Gateway 后全局生效。

经营问答按话题加载：平台选择 `references/faq/platform-selection.md`、选品 `product-selection.md`、定价/运费模板 `listing-template.md`、履约 `fulfillment.md`、售后 `after-sales.md`、新店 `new-store.md`、内容合规 `content-compliance.md`。
