# 商品复制与防重复操作

> 当前状态：商品复制来自历史视频。2026-08-11 飞刀新版当前可见菜单没有“商品复制”入口，前端当前主菜单也没有确认 1688 铺货。保留本页用于旧版与历史任务恢复；新版执行前必须重新确认入口、套餐和账号权限。

商品复制把源店商品按一套规则生成到目标店。必须同时管理四件事：复制规则、源商品范围、目标店铺和重复复制标记。

## 复制规则包含什么

复制前先创建模板或规则，常见项目包括：

- 是否直接上架；
- 是否复制手机端描述；
- 价格按单一倍率、阶梯区间或目标价处理；
- 运费模板沿用原商品还是使用目标店已有模板；
- 店铺分类；
- 是否在复制后建立库存、价格、编码等字段的实时同步。

“复制后开启实时同步”不是普通复制的默认附属动作。只有明确希望源商品后续变化持续影响目标商品时才开启。

## 通用跨店复制

1. 建立并命名复制模板。
2. 选择源店铺，必要时按商品状态、类目或复制标记筛选。
3. 支持跨页选择时，完成选择后核对已选数量。
4. 点击立即复制或定时复制。
5. 在目标店列表中为需要复制的店选择模板。
6. 源店也可能出现在目标列表中；不需要复制回源店时不要勾选。
7. 提交任务并在复制记录中查看进度和详情。

## 分销商模式

- 下游店先选择分销商模式。
- 商品来源是上级分销商授权给当前店铺的商品。
- 选择复制规则、目标分类和运费模板后提交。
- 复制后生成的是下游店的新商品。
- 若规则开启实时同步，上游库存、价格等变化可以继续下传。

## 店群模式

- 由主店账号登录并操作。
- 主店或任一分店都可以作为源店，另一个分店作为目标店。
- 可选择已选商品、当前查询结果、出售中、仓库中或全店范围，具体选项以当前界面为准。
- 支持立即复制和定时复制。

## 防止重复复制

工具可能提供“复制标记”或“是否已复制到某店”的筛选：

1. 首次复制完成后按目标店检查已复制记录。
2. 再次复制前筛选“未复制到目标店”的商品。
3. 对明确不需要复制的商品，可标记为已复制/排除，使其不再出现在待复制列表。
4. 如果复制标记被重置或目标商品被删除，重新复制前先按源商品 ID 和目标商品 ID 核对。

## 任务与失败处理

复制通常是后台离线任务，关闭浏览器不会停止。不要因为页面没有持续刷新就重复提交。

- 通过任务 ID 进入复制记录；
- 检查目标商品 ID、图片数、状态和时间；
- 按失败状态筛选；
- 先根据错误提示修正分类、模板、授权或商品字段，再点击重新复制；
- 重试前确认失败记录没有已经在后台完成。
