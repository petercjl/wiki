# 1688铺货与货源关联

> 当前状态：本页来自历史视频。2026-08-11 飞刀新版当前可见菜单和已发现前端业务路径均未确认 1688 选品、图搜、链接铺货或货源关联。不能断言永久删除，但不得把本页当作新版现行入口。

这部分描述批量修改工具里的 1688 能力：从 1688 找商品并铺到淘宝店，以及把淘宝商品与一个或多个供货链接建立 SKU 对应。它属于淘宝自动化工具流程，同时关联 [[domains/电商运营/07-1688/index|1688 平台知识]]。

## 先建立铺货模板

铺货模板用于统一处理目标商品：

- 模板名称；
- 运费和物流模板；
- 发货时效；
- 价格按统一倍率处理；
- 或按采购价区间分别设置倍率；
- 库存、标题、视频、主图和描述图等复制规则。

定价示例可以按 `0—10 元`、`10—20 元`、`20 元以上`设不同倍率，但区间与倍率必须由目标利润、平台费用、运费和售后成本决定，不能照搬视频示例。

## 三种铺货入口

| 入口 | 输入 | 适用情形 |
| --- | --- | --- |
| 1688 选品 | 商品关键词 + 筛选条件 | 批量浏览候选商品 |
| 图搜同款 | 图片地址 | 已有参考图，寻找近似供货商品 |
| 链接铺货 | 1688 商品链接 | 已经确定具体供货链接 |

### 标准流程

1. 设置铺货模板。
2. 通过关键词、图片或链接找到商品。
3. 选择单品或当前页商品。
4. 点击批量铺货并选择模板。
5. 提交任务。
6. 到铺货记录查看任务和结果。

来源在 2026-06 界面中提到整页全选 50 个商品，这只是当时分页快照，不应视为永久上限。

## 关联货源

工具直接铺货的商品通常会自动带上货源关联。对于其他商品：

1. 打开商品的“添加货源”。
2. 从候选供货商品中选择合适货源。
3. 点击自动关联，检查 SKU 是否全部对应。
4. 自动关联失败的 SKU 用拖拽方式手动匹配。
5. 保存关系。
6. 需要时继续添加第二、第三个货源。
7. 有专属货源时，粘贴专属链接再关联。

## 关联质量检查

- 规格名称相似不代表规格含义相同；核对颜色、尺寸、包装和数量。
- 自动匹配后必须检查未关联 SKU，不能只看“保存成功”。
- 多货源并存时记录主供、备供和切换条件。
- 供货价、起批量、库存和发货时效会变化，正式下单前仍需查看当前 1688 页面。
