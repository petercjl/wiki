# 词包体系：品牌词、品牌品类词、高潜词与类目词

## 六类品牌相关词包

| 类型 | 含义 | 经营用途 |
| --- | --- | --- |
| 纯品牌词 | 品牌或店铺名，不含具体类目 | 核心品牌搜索防守 |
| 品牌别称词 | 系列名、产品名或独有简称 | 承接消费者习惯叫法与种草词 |
| 特殊品牌词 | 品类词同名、多品牌组合或同名品牌 | 需更谨慎判断相关性 |
| 品牌类目词 | 品牌与店铺在售类目的组合 | 将品牌心智落到具体购买需求 |
| 品牌大事件词 | 代言人、IP 联名、发布等事件词 | 承接传播节点新增搜索 |
| 行业特性词 | 型号、书名、主播等有明确品牌指向的行业词 | 适配行业特殊搜索语言 |

系统产词与店铺资质、在售商品和搜索量相关，不保证每个店铺都有全部六类。

## 类目词包

类目词包面向“运动鞋”“外套”等非品牌类目需求，用于突破品牌词流量上限。它更偏进攻，也更容易遇到多店竞争。没有品牌授权时仍可能获得类目词包，但能否生成取决于店铺类目集中度和当前准入。

## 高潜词与自助加词

高潜词智能发掘和自助加词用于捕捉新品型号、代言人、趋势热搜与站外种草形成的新词。新增词仍需满足品牌相关性、资质和审核要求，不能把任意泛词加入品牌词包。

## 词包升级后的检查

1. 查看原计划期望投放的词包是否仍在。
2. 旧词包数据可能只在“报表—关键词报表—店铺直达数据明细”保留。
3. 新旧映射失败或计划词包清空时，手动添加新词包。
4. 词包数量减少不等于 PV 一定下降，先核对实际词覆盖和报表。
5. 不同意图词包分计划，避免创意和出价无法匹配。

## 出价与扣费

品牌进阶模式中，词包有动态起拍价，展现竞争力由起拍价与出价系数共同决定；存在竞争时可能按下一名出价加最小价差扣费。店铺快投则以目标点击出价为主要表达。具体计费和底价以实时页面为准。
