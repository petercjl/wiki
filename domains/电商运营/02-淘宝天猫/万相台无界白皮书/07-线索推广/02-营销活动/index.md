# 营销活动

该官方分支包含首单、消耗返、流量补贴、套餐包、大促护航和企微邀约权益等历史活动。活动门槛、返补比例和期限不可当作现行政策，复用时只提取“新客降门槛、老客控成本、大促分阶段护航”等机制。
