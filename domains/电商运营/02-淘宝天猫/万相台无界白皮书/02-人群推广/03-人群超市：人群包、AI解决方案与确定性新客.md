# 人群超市：人群包、AI解决方案与确定性新客

## 一句话定位

人群超市把本店核心、平台精选、垂直赛道、趋势热点和定制人群包装成托管方案；AI 解决方案进一步把自然语言诉求转成人群、商品、预算和周期组合；确定性新客则在特定商品和预算下增加交付与赔付机制。

## 人群包供给

| 类型 | 典型用途 |
| --- | --- |
| 本店核心与专属定制 | 稳住高价值店铺资产、满足个性化经营 |
| 平台尊享与系统优选 | 触达高净值、高消费力或算法高潜人群 |
| 垂直赛道 | 聚焦细分类目和行业争夺人群 |
| 趋势热点与时令上新 | 捕捉近期热点和季节性机会 |
| 大促限时 | 节点期集中触达，规则和供给有时效 |

创建时可洞察人群规模和营销触达率，设置异常行为或店铺购买人群过滤，再选择“目标人群渗透优先”或“投入产出优先”。智能选品与自定义选品分别适合算法择优和明确货品。

## AI 解决方案

AI 解决方案允许用自然语言描述经营诉求，结合所选商品生成人群包、商品、预算和周期。商家应检查推理和方案，而不是把生成结果直接视为确定事实。

![[raw/assets/alidocs-vy20BglGWOxjGpq0CqEa5YvOVA7depqY-2026-08-04/01.png]]

若画像不合适，应补充人群方向和排除条件；若系统提示无法回答，先确认商品是否通过选品框正式选择，而不是只输入商品 ID。案例中的 ROI、CVR 或新客占比属于单店对比，不外推为普遍效果。

## 确定性新客交付

![[raw/assets/alidocs-20eMKjyp810mMdK4HYp4NExMJxAZB1Gv-2026-08-04/01.webp]]

确定性方案把广告预算与权益联动，针对“确定性保障商品”预估并保障新客成交笔数；投放结束后还有归因期，未达交付时按规则赔付。自定义商品不一定享有同样保障。

保障的正确理解：保障对象是规定周期、预算、商品和归因口径下的新客成交规模，不是利润、客单、长期复购或全店 ROI。具体档位、归因天数、赔付比例和补量扣款均须核对当前合同/页面。

## 续投与退出

- 人群超市通常默认开启自动续投，可设置效果达标门槛；不设门槛可能无条件进入下一轮。
- 自动续投会从余额扣款，余额不足后可能转为限时手动续投。
- 手动续投、手动结束和退款窗口在不同版本中可能是 72 小时、7 天或其他规则，以当前订单页为准。
- 相同人群包可并行多个计划，但商品应尽量差异化，降低内部竞争。

## Agent 决策顺序

1. 明确是本店资产、行业机会、趋势还是确定性新客。
2. 查看人群包规模、营销触达率、过滤条件和账户资格。
3. 选择商品并复核 AI 输出的人群、预算和周期。
4. 下单前确认自动续投、结束、退款和保障口径。
5. 投后分开看目标人群渗透、成交效率和新客交付，不只看预估值。
