# 万相台无界内容营销

内容营销将短视频、直播和短直联动纳入可投放的经营链路，目标从内容观看、互动和种草，延伸到新客、商品收加、直播间成长与长期成交。

## 官方来源结构

1. 超级短视频：有效观看、点击引流、商品收加、长效转化与内容拉新。
2. 超级直播：直播间成长、商品打爆、人群运营与直播全站推广。
3. 短直联动：用短视频蓄水并承接到直播间转化。
