# 万相台无界白皮书

本目录保存阿里官方发布的万相台无界产品说明、规则、操作手册和界面证据。它是官方事实层，回答“平台当前怎么定义、怎么设置、有什么限制”；课程方法、商家经验和诊断模型仍放在对应运营方法目录中。

## 从官方结构开始

- [[domains/电商运营/02-淘宝天猫/万相台无界白皮书/00-官方目录与编译进度|官方目录与编译进度]]：保留“我要推广”的十个一级节点、原始模块边界和当前覆盖状态。
- 本白皮书采用双层结构：官方目录层负责来源路径和上下级关系，主题知识层负责把同一经营问题下的多份文档融合成可直接使用的知识。
- 后续批量编译必须先定位官方父节点，再决定新建、融合或扩展正式页；不能只按抓取顺序把页面平铺到模块根目录。
