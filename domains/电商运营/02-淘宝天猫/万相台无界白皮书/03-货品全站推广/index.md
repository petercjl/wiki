# 万相台无界货品全站推广

货品全站推广以商品为经营单元，在淘系全域流量中由系统完成选品辅助、动态竞价和流量分配。运营的核心不是频繁手工调价，而是选对商品、明确成本或规模目标、给模型足够预算与稳定期，再用诊断和结案数据迭代。

![[raw/assets/alidocs-G1DKw2zgV2KnvL4kF1jPnKPqJB5r9YAn-2026-08-04/01.png]]

## 官方来源结构

1. 投放攻略：新手操作、控投产比、最大化拿量与大促节奏。
2. 选好货投全站：新品、潜力品、爆品、平台推荐与 AI 选品。
3. 出价能力升级：净成交、控费比、效果智达、一键起量和多目标起量。
4. 全店模式：智能托管、分组投放、自动汰换和低效品转投。
5. 全站结案：投放解读、全站增长与指标口径。
6. 其他能力：互斥、竞投诊断、创意、达摩盘回流和授权。

## Agent 路由

- 问“货品全站推广是什么、从哪里开始”：读总览。
- 问“应该推什么商品、新品和爆品怎么区别”：读货品选择。
- 问“控投产比还是最大化拿量、总成交还是净成交”：读出价决策。
- 问“预算怎么设、为什么掉量、多久能调整”：读投放执行。
- 问“怎样快速放量、加购和直接成交目标怎么选”：读增量调优。
- 问“SKU 多怎么托管、怎样分组和自动汰换”：读全店模式。
- 问“计划成交与商品全站成交为何对不上、怎样复盘”：读投放解读与全站结案。
- 问“为什么计划互斥、创意、权限、竞争诊断或数据回流”：读配套能力。
- 问“大促怎样分阶段、案例能不能照搬”：读大促与案例复用。
- 活动资格、补贴、保障、门槛和当前可用功能必须以账户实时页面为准。
