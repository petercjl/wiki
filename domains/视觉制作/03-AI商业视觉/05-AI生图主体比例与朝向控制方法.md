# AI 生图主体比例与朝向控制方法

本页解决两类高频生成失败：

1. 主体被模型自动放大，真实产品变成巨物或挤满画面；
2. 主体朝向、运动方向或多对象前后关系不按创作者意图执行。

鞋子过斑马线和鞋子走向自拍机只是回归样本。可迁移的方法是：**比例用同平面尺度关系与画面占位共同约束，朝向用画布坐标、主体自身轴和环境线共同约束。**

> 重要边界：Prompt 可以提高命中率，但不是像素级布局工具。真实构图参考通常比数字更有约束力；必须精确时，应转入确定性合成、区域控制或 3D 布局。

## 1. 先分清四种参考职责

不要只写“参考这些图片”。每张参考图应承担一种主要职责：

| 参考职责 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| 主体身份图 | 结构、比例、部件位置、材质、颜色、文字、标识和连接关系 | 不决定新场景和画面位置 |
| 构图/机位图 | 画幅、相机方向、透视、主体位置、环境轴线 | 不重绘主体身份 |
| 风格图 | 光线、色彩、材质表现、气氛 | 不改变身份和构图几何 |
| 场景级关键帧 | 主体尺度、空间关系、留白和镜头结果 | 不取代原始身份图 |

发生冲突时，推荐优先级：

```text
主体身份 > 朝向 > 物理尺度 > 动作细节 > 风格
```

产品身份必须使用参考锁定型表达，不把视觉识别笔记重新写成产品说明：

```text
主体身份只来自参考图 1。所有可见结构、比例、部件位置、材质、颜色、文字、标识和连接关系均遵循参考图；不得新增、删除、移动、重释或重新设计主体部件。
```

下图是第一轮实验的原始产品身份图。它承载鞋子身份，不承载斑马线构图和行走方向。

![[raw/assets/ai-image-scale-direction-control-2026-08-04/01-shoe-identity-reference.jpg]]

*原始身份图的知识作用：主体细节由图像参考携带，Prompt 只写锁定关系，避免用文字重绘产品。*

对应的街景图只负责正面透视、道路轴线和斑马线几何：

![[raw/assets/ai-image-scale-direction-control-2026-08-04/02-crosswalk-scene-reference.png]]

*街景参考提供机位和环境线；产品身份和最终光色不从这张图推断。*

## 2. 比例控制：关系锚点为主，画面占位为保险

### 2.1 为什么“真实比例”通常无效

生图模型具有“主体应成为主角、主角应更大”的构图先验。以下写法约束力有限：

- “真实大小”“不要太大”“符合现实比例”；
- 单独写焦距、镜头距离或鞋长；
- 单独写“占画面五分之一”；
- 给一个抽象包围框，并假定模型会像排版软件一样严格服从。

这些内容不是完全无效，但只能作为保险线，不能承担全部比例控制。

### 2.2 比例控制栈

比例至少使用五层互相校验：

```text
1. 同平面锚点：主体与常识尺寸参照物处于同一地面/桌面/墙面深度平面。
2. 相对尺寸：主体相对锚点是略小、相等、几分之一或几倍。
3. 透视尺度链：近景纹理/小物 → 同平面锚点 → 主体 → 中远景家具/建筑/人物。
4. 画面占位保险：主体组中心、宽高范围、环境留白比例。
5. 裁切边界：主体完整出现，不触碰指定边缘，不进入禁入区域。
```

最关键的是“同平面”。位于很近前景的落叶可以帮助建立透视，但不能单独证明远处主体真实大小。真正有力的关系是：主体与锚点处在同一深度平面，且相对尺寸可直接比较。

### 2.3 真实构图参考为什么更有效

第一轮目标效果图已经提供了环境占主导、鞋子受抑制、鞋头朝右的完整视觉关系：

![[raw/assets/ai-image-scale-direction-control-2026-08-04/04-crosswalk-target-effect.png]]

*真实构图参考把主体尺度、位置、环境留白和透视关系同时可视化，比孤立百分比更容易被模型执行。*

加入画布坐标、主体区域和运动向量后，综合结果最接近目标：

![[raw/assets/ai-image-scale-direction-control-2026-08-04/06-variant-b-canvas-coordinates.png]]

*方案 B：方向正确，主体尺度和环境留白在第一轮中最接近目标构图。*

去掉真实构图参考后，即使保留画面百分比和物理关系，主体再次显著放大：

![[raw/assets/ai-image-scale-direction-control-2026-08-04/08-variant-d-no-target-reference.png]]

*方案 D 反证：文字里的百分比不是硬包围盒，广告主角放大先验仍会覆盖它。*

抽象占位图也没有提供真正的尺寸硬控：

![[raw/assets/ai-image-scale-direction-control-2026-08-04/09-variant-e-layout-control.png]]

*方案 E 反证：抽象图能帮助控制大致位置，但没有阻止主体被放大。*

因此，比例控制的优先修正顺序是：

```text
先检查同平面尺度关系
→ 再检查真实构图参考
→ 再用画面占位作保险
→ 若仍需像素级准确，切换确定性工具
```

## 3. 朝向控制：把世界语言翻译成画布几何

“向前走”“横穿”“朝左”容易被场景默认值重新解释。正面道路场景中的“向前”可能被模型理解为朝镜头或朝消失点。

### 3.1 朝向控制栈

```text
1. 画布坐标：明确屏幕 x 轴、y 轴和目标运动向量。
2. 主体自身轴：定义后端→前端、尾部→头部或根部→尖端。
3. 角度容差：主轴相对画面水平/垂直线允许多少误差。
4. 环境关系：与道路中心线、地砖缝、桌边、地平线平行或垂直。
5. 指定可见面：镜头看侧面、正面、背面或顶面，排除歧义视角。
6. 角色分解：多对象分别定义位置、状态、动作阶段和前后关系。
```

通用方向句式：

```text
屏幕坐标中，目标运动向量为画面左→右（+x，→）。
主体自身的【后端】→【前端】轴与 +x 同向，主轴与画面水平线夹角不超过 ±5°。
主体主轴与场景中的【环境线】垂直/平行。
镜头看到主体的【指定可见面】，不采用【会造成方向歧义的视角】。
```

时钟方向可以保留，但不应单独使用。`9 点→3 点` 最好与 `+x`、`后端→前端`、环境线关系和可见面同时出现。

### 3.2 多对象动作必须拆开

不要只说“两只鞋在走路”。应分别定义：

```text
对象 A 位于运动方向前方，处于承重/接触/完成阶段；
对象 B 位于后方一个自然间距，处于离地/摆动/准备阶段；
两者是同一动作的连续阶段，不是对称陈列。
```

实验显示，**动作方向通常比动作相位更稳定**：模型可以正确理解向右走，但抬跟高度、承重脚和自然步幅仍可能弱化。因此生成后必须分开验收“方向命中”和“步态命中”。

## 4. 跨场景回归：鞋子走向自拍机

第二轮没有使用最终效果图参与生成，只输入自拍机场景与产品身份图。自拍机门洞可供成年人直立进入，因此是常识尺度锚点：

![[raw/assets/ai-image-scale-direction-control-2026-08-04/10-selfie-booth-scene-reference.jpg]]

*第二轮场景图同时提供固定正面机位、地面平面和成年门洞尺度锚点。*

事后对照效果图要求鞋子位于左下，从 9 点向 3 点走向入口：

![[raw/assets/ai-image-scale-direction-control-2026-08-04/12-selfie-booth-target-effect.png]]

*效果图只用于生成后比较：鞋组约占画宽 15%，右侧鞋领先并朝入口。*

实际生成结果：

![[raw/assets/ai-image-scale-direction-control-2026-08-04/13-selfie-booth-generated.png]]

*跨场景回归：16:9、自拍机居中、鞋组左下、9→3 点方向和无人物均命中；鞋组约占画宽 17%，但鞋长≈门高 1/7 与后鞋抬跟没有严格执行。*

这次验证说明：

- 画布坐标、主体自身轴、指定可见面可以跨场景迁移；
- `x/y 区域 + 组宽/组高 + 环境留白` 能控制画面占位；
- 成年门洞等常识尺度锚点能避免灾难性巨物，但不能保证严格换算；
- Prompt 中的动作角色分解仍需要生成后 QA。

## 5. 通用 Prompt 模板

```text
用途：{广告关键帧 / 分镜关键帧 / 产品场景图 / 角色场景图}
目标：在 {场景} 中生成 {主体}，完成 {动作或叙事}。

【参考图职责】
参考图 1 是主体身份的唯一事实来源。所有可见结构、比例、部件位置、材质、颜色、文字、标识和连接关系均遵循它；不得新增、删除、移动、重释或重新设计主体部件。
参考图 2 只负责 {构图、机位、透视、场景几何}。
参考图 3 只负责 {光线、色彩、材质表现、氛围}。
参考图 4（如有）只负责 {主体尺度、位置、空间关系、留白}。

【比例控制】
主体与 {常识尺寸锚点} 位于同一 {地面/桌面/墙面} 深度平面。
在该平面上，主体尺寸约为锚点的 {相对关系}。
画面形成 {近景参照} → {同平面锚点} → 主体 → {中远景参照} 的连续透视尺度链。
完整主体组位于画布约 (x={?}%, y={?}%)，宽约 {?–?}%，高不超过 {?}%；至少 {?}% 画面保留环境。
主体完整出现，不进入 {禁入边缘/区域}。

【朝向控制】
屏幕坐标中，目标方向为 {+x / -x / +y / 向量箭头}。
主体自身的 {后端}→{前端} 轴与该向量同向，和画面 {水平/垂直} 线夹角不超过 ±{?}°。
主体主轴与场景中的 {环境线 A} {平行/垂直}，与 {环境线 B} {平行/垂直}。
镜头看到主体的 {指定可见面}，不采用 {歧义视角}。

【动作/多主体角色】
对象 A：{位置、接触状态、动作阶段、可见面}。
对象 B：{位置、接触状态、动作阶段、可见面}。
两者表现同一动作的连续阶段，不是对称陈列。

【优先级】
主体身份 > 朝向 > 物理尺度 > 动作细节 > 风格。

【避免】
避免改变参考主体、主角式夸张放大、错误可见面、主轴旋转、对称陈列、无依据漂浮、重复主体、额外部件、文字和水印。
```

## 6. 控制强度分级

| 需求 | 推荐方法 | 不能承诺什么 |
| --- | --- | --- |
| 探索图、容许波动 | 同平面锚点 + 画布占位 + 朝向控制栈 | 不承诺每次尺寸一致 |
| 商业关键帧、要求稳定 | 原始身份图 + 真实场景/构图关键帧 + 短 Prompt 校验 | 不承诺逐像素复制 |
| 精确版式、严格尺寸 | 确定性合成、区域控制、遮罩、3D 或后期 | 不应继续依赖纯 Prompt |

若目标镜头缺少合格角度，应回到原始身份图生成候选关键帧并逐张验收；不要使用失败稿或派生稿继续累计生成。

## 7. 生成后 QA

| 检查项 | 测量或判断方式 | 常见失败 |
| --- | --- | --- |
| 画幅 | 实际宽高比 | 模型输出近似而非指定比例 |
| 主体占位 | 主体组宽/画宽、主体组高/画高 | 主角放大、环境消失 |
| 同平面尺度 | 与同深度锚点比较 | 数字写了但像素关系不成立 |
| 主轴角度 | 后端→前端轴与目标线夹角 | 朝镜头、斜向、翻转 |
| 可见面 | 是否看到指定侧面/正面/背面 | 方向词正确但镜头面错误 |
| 动作角色 | 前导对象、后随对象、接触/离地状态 | 对称陈列、平移、漂浮 |
| 产品身份 | 与原始身份图逐项视觉核对 | 新增部件、移动结构、材质漂移 |
| 证据等级 | 明确事实、推断和未严格验证项 | 把单次成功写成稳定规律 |

要把方法升级为稳定生产规范，至少应跨主体、跨方向重复采样，记录：

- 主体包围盒占比；
- 主轴角度误差；
- 指定可见面命中率；
- 产品结构变形率；
- 动作角色命中率。

当前实验多数方案 `n=1`，只能证明机制值得保留，不能代表统计成功率。

## 8. 失败诊断

| 症状 | 优先诊断 | 修正顺序 |
| --- | --- | --- |
| 主体仍然巨大 | 是否缺真实构图参考、锚点是否同平面 | 补同平面关系→补场景关键帧→切确定性工具 |
| 主体位置正确但尺寸大 | 抽象框图只控制了位置 | 换成具有真实尺度关系的构图参考 |
| 朝向镜头 | “向前”被场景默认值重释 | 改用画布向量→主体自身轴→指定可见面 |
| 两对象像陈列 | 只写了动作名 | 拆解前后位置、承重/离地和动作阶段 |
| 产品变形 | Prompt 重述了部件细节或参考冲突 | 回到原始身份图，改用关系锁定语句 |
| 方向正确但步态弱 | 动作相位约束低于方向 | 单独验收动作角色，必要时改构图或后期 |
