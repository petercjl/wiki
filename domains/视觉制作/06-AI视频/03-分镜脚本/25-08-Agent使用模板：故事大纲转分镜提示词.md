## 输入诊断

收到故事大纲后，先提取：

| 字段 | 问题 |
| --- | --- |
| 主角 | 谁是视觉中心？外貌和身份是否需要固定？ |
| 目标 | 主角想要什么？ |
| 阻碍 | 什么让目标无法直接完成？ |
| 关键物件 | 哪个物件能承载情绪或信息？ |
| 场景 | 主要地点、时间、天气、时代感是什么？ |
| 情绪曲线 | 开端、发展、转折、余味各是什么情绪？ |
| 风格锚点 | 是否使用某位导演/摄影风格？ |
| 声音需求 | 是否有对白、内心独白、画外音、环境声、BGM？ |
| 台词锁定 | 哪些台词必须一字不差保留？哪些段落明确无对白？ |
| 空间关系 | 主要人物站位、朝向、视线和关键参照物是什么？ |

## 生成步骤

1. 输出一句故事 logline。
2. 输出 4 段结构：开端、发展、转折/高潮、余味。
3. 输出人物与空间设定：人物外貌、服装、关键道具、主场景、站位和视线规则。
4. 输出台词与旁白总表：当面说话、内心独白、画外音分别列出；无对白段落也要标注。
5. 输出镜头任务表，列出每段时长、任务、画面核心、声音策略、连续性。
6. 为每段选择景别、机位、运镜、光色、质感、空间锚点和剪辑点。
7. 写成最终完整视听分段 prompt。
8. 运行自检：主体一致、空间连续、台词锁定、声音可控、镜头不过载、风格统一、无字幕水印。

## 输出结构

```text

【导演/摄影风格锚点】，【色彩】，【光线】，【镜头/质感】，【画幅】。
声音总策略：分段视频只生成环境声和动作音效；除非明确指定，不生成背景音乐；整片 BGM 后期统一处理。
负向限制：不出现字幕、水印、logo、畸形手、突然变脸、场景跳变，不新增台词，不自由添加剧情。

人物与空间设定：
- 人物：
- 服装：
- 关键物件：
- 主场景：
- 站位与视线规则：

台词与旁白总表：
| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |

镜头表：
| 段落 | 时间 | 镜头任务 | 景别/机位 | 运镜 | 画面核心 | 声音策略 | 连续性 |

0-X 秒：...

```

## 示例输出片段

```text
全局风格：
岩井俊二风格，低饱和浅青与雾蓝调，柔和漫射光，轻微 35mm 胶片颗粒，
雨天校园青春片质感，画面清透、克制、留白。
声音总策略：无背景音乐，只保留雨声、脚步声和纸张摩擦声；旁白必须使用台词总表中的原句。
负向限制：不出现字幕、水印、logo，不出现夸张表演，不突然切换人物外貌，不新增对白。

台词与旁白总表：
V1｜少女｜内心独白｜“有些话没有说出口，就会一直停在雨里。”｜素材段落 1｜建立回忆口吻。

【素材段落 1：雨檐下的旧信】
剧情任务：建立雨天旧校园和少女未说出口的情绪。
声音策略：少女内心独白使用 V1；只保留雨声和纸张轻响，禁止背景音乐。
空间锚点：旧校舍木质屋檐下，前景是雨珠，后景是虚化绿叶和走廊，少女站在画面右侧三分线，低头看信封。
完整剧情：
0-6 秒：极致特写，木质屋檐边缘凝着一颗澄澈雨珠，背景是浓郁绿叶虚化成柔和散景。少女画外音：“有些话没有说出口，就会一直停在雨里。”音效：细密雨声。
连续性：作为开场空镜到人物出现的过渡，不出现新人物，不出现字幕。
```

## 不得推断

- 不要在用户没有要求时加入复杂奇幻设定。
- 不要把导演风格写成对在世艺术家的直接“完全复制”；用于风格研究时，优先写可观察影像特征。
- 不要使用无法生成的抽象词代替画面动作。
- 不要让每个镜头都推进或拉远。
- 不要在一个镜头里安排多个主体同时做复杂动作。
- 不要只写“旁白感”“对话感”而不给具体台词。
- 不要让模型自动生成背景音乐；分段视频的 BGM 优先后期统一处理。
- 不要用“同上”“延续上一段”省略空间锚点。

## 质量自检

合格输出应能直接被复制到 AI 视频工具中，且读者不用再猜：

- 画面是什么。
- 相机怎么动。
- 为什么这个镜头在这里。
- 光色质感是什么。
- 上一镜和下一镜如何连接。
- 角色是否说话、谁在说、说什么、声音来自画内还是画外。
- 如果没有对白，是否明确禁止了对白、旁白和随机音乐。
