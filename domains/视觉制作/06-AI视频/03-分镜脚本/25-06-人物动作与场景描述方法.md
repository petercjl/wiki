# 人物动作与场景描述方法

## 问题定义

AI 视频里的人物动作必须可见、具体、单纯。不要只写“她很悲伤”，要写悲伤如何通过身体、手、视线、距离、物件和空间表现。

## 动作层级

| 层级 | 示例 | 适合镜头 |
| --- | --- | --- |
| 大动作 | 奔跑、转身、推门、坐下、离开 | 全景、中景 |
| 中动作 | 抬头、停步、回避视线、把信塞进抽屉 | 中景、中近景 |
| 微动作 | 手指捏紧、眼睫颤动、发丝被风吹起 | 特写、极致特写 |
| 环境动作 | 雨落、窗帘飘动、粉笔灰扬起、树影摇晃 | 空镜、情绪镜头 |

## 人物描述公式

```text
身份/年龄感 + 外观气质 + 当前姿态 + 具体动作 + 情绪证据 + 与环境关系
```

示例：

```text
年轻日系少女，容貌清丽，穿浅色校服，站在木质屋檐下避雨；
她低头握着一封微皱的信，指尖用力，视线没有看向镜头，
身后雨幕和绿叶虚化成柔和散景。
```

## 场景描述公式

```text
地点 + 时间/天气 + 空间层次 + 关键物件 + 光线 + 可动环境细节
```

示例：

```text
雨天的旧校舍走廊，木质屋檐在画面上缘形成遮挡，
前景有滴落的雨珠，中景是避雨的女孩，背景是浓郁绿叶与空荡校门；
阴天漫射光，空气湿润，窗帘和树叶被微风轻轻带动。
```

## 场面调度

人物与场景不是分开写的。Kenworthy 的场面调度思路可以转成三条 prompt 规则：

- 用背景运动给镜头变化找理由：路人、车辆、窗帘、树影、雨滴。
- 用前景丰富画面：门框、玻璃、雨珠、课桌边缘、信封一角。
- 用物件串联故事点：信封、旧课桌、照片、伞、车票、发卡。

## 避免抽象情绪

| 抽象写法 | 可生成写法 |
| --- | --- |
| 她很难过 | 她低头避开镜头，手指把信封边角捏皱 |
| 他很焦急 | 他在门口停步，快速回头看向街角，呼吸急促 |
| 两人关系疏远 | 两人坐在同一张长椅两端，中间隔着未打开的雨伞 |
| 回忆感 | 旧窗帘泛黄，粉笔灰漂浮在斜射光里，画面有轻微胶片颗粒 |

## AI 限制

- 一镜尽量不超过两个主要人物。
- 复杂情绪用多个镜头递进，不要让人物在 5 秒内完成大幅心理变化。
- 角色外貌要保持稳定，换镜头时复用同一套身份描述。
- 场景中的可动物件不要过多，否则模型会把注意力分散。
