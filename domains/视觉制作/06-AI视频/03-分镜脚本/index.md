# AI短视频分镜脚本

分镜脚本是导演决策的执行层。它既要让人看懂，也要能够继续生成图片资产和视频 Prompt。

开始拆镜前，先用 [[domains/视觉制作/06-AI视频/02-导演思维/01-导演动机、导演工具与分镜生成|导演动机、导演工具与分镜生成]] 明确场景任务、观众位置、人物权重、情绪曲线和时间策略；不要从景别或运镜术语起步。

## 最小字段

| 层 | 字段 |
| --- | --- |
| 叙事 | 场景、镜头任务、观众新增信息、情绪变化 |
| 画面 | 主体、动作、景别、机位、构图、光线、色彩、质感 |
| 时间 | 时长、动作顺序、起始状态、结果、切点 |
| 摄影机 | 静止或一个主运镜、运动方向和动机 |
| 声音 | 对白、旁白、环境声、动作音效、BGM 意图 |
| 连续性 | 人物、产品、道具、空间、方向、动作和光线状态 |
| 资产 | 需要的角色、产品、场景、首帧、尾帧和声音参考 |
| 验收 | 必须出现、不能改变和允许模型发挥的内容 |

## 阶段交接

- 需要先固定视觉事实的字段进入 [[domains/视觉制作/06-AI视频/04-图片与控制资产/index|图片与控制资产]]。
- 时间、动作、运镜、声音和连续性字段进入 [[domains/视觉制作/06-AI视频/05-视频生成/index|视频生成]]。
- 分镜不能只列画面描述；每个字段都应能追溯到导演意图，并对应生成后的验收项。
