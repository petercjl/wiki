# AI故事到分镜生产工作流

## 问题定义

故事通过后，还不能直接写视频 prompt。AI 视频需要把故事拆成可生成、可剪辑、可复盘的生产资料：视觉事件、镜头任务、首尾帧、参考资产、声音边界和负向限制。

## 主流程

```text
故事命题
-> 段落结构
-> 人物卡
-> 视觉事件链
-> 镜头问题/答案表
-> 分镜任务表
-> 首尾帧/参考资产
-> 分段视频 prompt
-> 剪辑与声音交接
```

## 视觉事件链

视觉事件不是剧情摘要，而是观众必须看见的变化。

| 剧情摘要 | 视觉事件 |
| --- | --- |
| 她想起旧同学 | 她翻到借书卡背面的旧名字，指尖停住 |
| 他压力很大 | 电脑消息弹出，他把领带扯松却没有离开座位 |
| 产品解决空间问题 | 孩子的画板、行李箱和折叠椅被顺利放进后备箱 |
| 母亲开始理解孩子 | 母亲戴着老花镜照教程学点外卖 |

一个镜头只承担一个主要视觉事件。复杂事件拆成建立镜头、动作镜头、插入镜头和反应镜头。

## 镜头问题/答案表

| 字段 | 说明 |
| --- | --- |
| 上一镜头留下的问题 | 观众此刻想知道什么 |
| 本镜头给出的答案 | 本镜头让观众确认什么 |
| 新问题 | 下一镜头为什么必须出现 |
| 情绪证据 | 眼神、手、距离、物件、声音、光线 |
| 生成约束 | 主体数量、动作复杂度、产品一致性 |

## 分镜字段

```text
镜头编号：
段落任务：
视觉事件：
镜头问题：
镜头答案：
主体：
动作：
关键物件：
景别：
机位：
构图：
主运镜：
光线/色彩：
声音/台词：
连续性：
首帧需求：
尾帧需求：
负向限制：
```

## 首尾帧和资产

| 资产 | 用途 |
| --- | --- |
| 角色图 | 保证人物身份、年龄、服装、表情基准 |
| 产品图 | 保证形态、比例、材质和关键结构 |
| 场景图 | 固定空间、时代、生活层级 |
| 道具图 | 固定叙事物件，如信、杯子、电话卡、记忆卡 |
| 首帧/尾帧 | 控制镜头起止状态，帮助剪辑连续 |
| 声音表 | 固定对白、旁白、环境声、动作音效 |

## 声音边界

- 分段视频 prompt 默认只生成对白、旁白、环境声和动作音效。
- 正式生产阶段默认禁止每段随机生成 BGM。
- 旁白必须补充内心或命题，不解释观众已经看见的事。
- 对白要短，尽量只在人物关系或转折处出现。
- 音乐统一由后期或 [[domains/视觉制作/06-AI视频/07-声音设计与BGM/10-Seed-Audio短视频音频一致性工作流|Seed-Audio短视频音频一致性工作流]] 处理。

## 交接检查

- 每个镜头是否只有一个主要动作？
- 是否有建立镜头、动作镜头、反应镜头和收束镜头的组合？
- 产品特写是否回答上一镜问题？
- 关键情绪是否有视觉证据？
- 是否为高风险产品/人物镜头准备 coverage？
- 每段 prompt 是否禁止随机新增台词、人声和音乐？
