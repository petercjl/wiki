# 景别与情绪表达

## 核心模型

景别不是镜头大小表，而是观众与角色之间的心理距离。选择景别时先问：这一镜要让观众看见环境、关系、动作、表情，还是细节证据？

| 景别 | 主要功能 | 情绪倾向 | AI prompt 用法 |
| --- | --- | --- | --- |
| 远景/大全景 | 建立世界、孤独、渺小、命运感 | 疏离、宏大、冷静 | `人物很小，被雨雾校园包围` |
| 全景 | 看清身体动作和空间关系 | 行动、选择、距离 | `人物从校门走向旧教室` |
| 中景 | 人物关系和日常行为 | 对话、犹豫、观察 | `两人隔着课桌沉默对视` |
| 中近景 | 表情和身体姿态并重 | 亲近、克制、微妙 | `女孩低头，手指捏住信封` |
| 特写 | 表情、物件、心理证据 | 紧张、温柔、压迫 | `眼睫上的雨水轻微颤动` |
| 极致特写 | 抽象化细节 | 记忆、触发、悬念 | `雨珠从屋檐边缘坠落` |

## 空间表达

Mercado 的镜头语言提醒：同一种技术在不同故事里会表达不同意义。长焦压缩可以表达拥挤、阻塞、亲密或孤独；广角可以表达开阔、失衡、滑稽或压迫。不要只写镜头名，要写它在这一镜里的情绪功能。

| 情绪目标 | 可用视觉手段 | prompt 句式 |
| --- | --- | --- |
| 孤独 | 人物小、负空间大、环境吞没人物 | `人物位于画面边缘，四周空旷而安静` |
| 压迫 | 长焦压缩、遮挡、低天花板、窄走廊 | `长焦压缩空间，走廊像向人物挤压` |
| 亲密 | 中近景、浅景深、柔光、身体距离近 | `浅景深中只保留两人的侧脸和手部动作` |
| 犹豫 | 半遮挡、门框/窗框、人物背向镜头 | `人物被窗框分割，视线停在门外` |
| 释然 | 空间打开、运动放缓、色彩亲和 | `镜头拉出，留出更多天空和雨后光线` |

## 视觉强度

Bruce Block 的“对比与亲和”可直接转成分镜规则：

- 情绪升高：提高明暗、色彩、线条、运动、空间或剪辑对比。
- 情绪平复：降低对比，增加相似色、稳定构图、慢节奏和柔和光线。
- 关键转折：让一个视觉组件突然改变，例如从静态到运动、从冷色到暖色、从远景到特写。

## Agent 使用提示

不要让景别孤立存在。每次写景别，都补一句“它为什么适合这个情绪”。例如：

```text
中近景，不直接给大哭表情，而是保留女孩克制的侧脸和握紧信封的手，让情绪停在未说出口的状态。
```
