# 从成片目标反推AI电影生产系统

## 核心判断

AI 电影的可控性主要来自生成前建立的生产系统，而不是在最后一条 Prompt 中堆更多形容词。先把成片当验收基准，再反推故事、资产、镜头、生成批次、修复与剪辑六层交付物。

## 六层系统

| 层 | 必须锁定 | 交付物 |
| --- | --- | --- |
| 故事 | 时长、世界、转折、目标、结尾 | 剧本与场景清单 |
| 资产 | 角色身份、服装状态、地点几何、关键道具 | 可复用资产库与句柄表 |
| 镜头 | 每镜头的戏剧任务、起止状态、空间关系 | 镜头表与参考图分配 |
| 生成 | 当前镜头所需引用、动作、摄影、物理、声音 | 独立镜头 Prompt |
| 修复 | 可见失败、保留部分、单变量补丁 | 批次选择与修复记录 |
| 组接 | 动作、视线、轴线、状态、节奏 | 成片与连续性验收 |

## 为什么先看成片

成片展示不是方法本身，但能定义方法要解决的问题：同一人物跨海盗、沙漠、丛林和室内仍可辨认；关键道具承接目标；转场同时改变世界与服装；对白场景保持空间连续；动作段落能通过批次混剪建立节奏。没有这个验收基准，资产和 Prompt 容易各自优化，却无法成为一部片。

## 生产门禁

进入生成前至少确认：剧本已按镜头拆解；所有跨镜头对象都有唯一名称；关键地点有可导航角度；人物的剧情状态变化有独立资产；每镜头只加载在场引用；复杂空间关系已有草图或构图参考；结尾状态能接到下一镜头。

## Agent 主线

Agent 接到“一句话拍成电影”时，不应直接写全片 Prompt。先追问时长、目标平台、世界数量、必须保留的转折、对白和已有资产；然后输出缺口清单，按“故事→资产→镜头→生成→修复→组接”推进。任何异常处理完，都回到这条主线。
