# AI短视频生产总览

AI 短视频与电影制作共享同一条核心逻辑：先决定讲什么、让观众怎样理解和感受，再把意图转成可执行镜头、控制资产、生成任务与后期成片。AI 改变的是执行工具，不替代剧本、导演、摄影、剪辑和声音判断。

## 主生产线

1. [[domains/视觉制作/06-AI视频/01-项目定义与剧本/index|项目定义与剧本]]：明确成片目标、传播问题、人物、冲突、结构、台词和声音意图。
2. [[domains/视觉制作/06-AI视频/02-导演思维/index|导演思维]]：把剧本转成观众经验、信息揭示、视点、空间调度、镜头流和剪辑策略。
3. [[domains/视觉制作/06-AI视频/03-分镜脚本/index|分镜脚本]]：把导演决策写成镜头任务、景别、机位、构图、动作、运镜、声音和衔接字段。
4. [[domains/视觉制作/06-AI视频/04-图片与控制资产/index|图片与控制资产]]：按风险制作角色、产品、场景、基调、故事板、首尾帧和操作参考。
5. [[domains/视觉制作/06-AI视频/05-视频生成/index|视频生成]]：把分镜与参考资产编译为模型可执行 Prompt，生成、验收并做最小修复。
6. [[domains/视觉制作/06-AI视频/06-视频剪辑与连续性/index|视频剪辑与连续性]]：完成选镜、粗剪、精剪、节奏、连续性、调色和画面锁定。
7. [[domains/视觉制作/06-AI视频/07-声音设计与BGM/index|声音设计与 BGM]]：在前期规划对白与声音，在画面锁定后完成配音、环境声、音效、BGM 和混音。

## 两条横向规则

### 上游决策必须进入下游

每个阶段的输出都要成为下一阶段的显式输入。导演意图如果没有进入分镜字段，分镜字段如果没有进入参考资产或 Prompt，前面的知识就没有形成生产控制力。

```text
剧本依据
→ 导演意图
→ 镜头任务
→ 分镜字段
→ 参考资产职责
→ 图片 Prompt / 视频 Prompt
→ 可观察验收标准
→ 失败原因与最小修复
```

### 参考负责身份，Prompt 负责变化

参考图承担人物、产品、场景、构图和风格等可见事实；Prompt 主要描述故事意图、镜头、动作顺序、时间、声音、连续性和参考无法提供的变化。不要用长文本重新绘制参考图已经明确的对象。

## 阶段门禁

| 阶段 | 进入下一阶段前必须回答 |
| --- | --- |
| 剧本 | 谁在什么处境中想要什么，阻碍和变化是什么，产品或主题为何不可替代？ |
| 导演 | 观众逐段知道什么、感受什么，视点、空间和镜头关系如何组织？ |
| 分镜 | 每个镜头为什么存在，如何拍、如何动、如何说、如何接？ |
| 图片资产 | 没有哪张参考会造成何种失控，当前资产是否忠于来源事实？ |
| 视频生成 | Prompt 是否承接镜头任务，参考职责是否清楚，结果如何验收？ |
| 剪辑 | 镜头是否推动故事，连续性、节奏和画面质量是否成立？ |
| 声音 | 对白、环境声、音效与 BGM 是否服务同一条情绪曲线？ |
