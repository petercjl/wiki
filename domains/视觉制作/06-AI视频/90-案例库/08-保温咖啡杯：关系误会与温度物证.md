# 保温咖啡杯：关系误会与温度物证

## 案例结论

这个保温咖啡杯故事不是从“保温多久”开始，而是从关系误会开始：

```text
曾经一起喝咖啡的朋友产生误会
-> 女主每天都想递出一杯咖啡
-> 工作、错过、沉默让咖啡一直没送到
-> 夜里终于递出，杯中仍有温度
-> 对方明白：关心不是临时补救，而是从早上就被带在身边
```

产品功能被转译成情绪证据：保温不是参数，而是“关心没有因为时间错过而失效”的物证。

## 项目诊断

| 维度 | 判断 |
| --- | --- |
| 产品 | 白色花卉保温咖啡杯，带提绳、隐藏吸管、316 不锈钢内胆、冷热饮适用、防滑杯底 |
| 广告路线 | 关系误会和解型情绪广告 |
| 核心人群 | 年轻职场女性、朋友/伴侣/家人礼物、自用型咖啡饮品用户 |
| 生活观察 | 亲情、友情、爱情里的误会，常常不是不在乎，而是关心没有找到合适的递出时机 |
| 核心命题 | 有些关心不是没有送到，只是一路都没找到开口的时机 |
| 产品角色 | 没有说出口的关心的容器 |
| 片尾收束 | 有些温度，晚一点到，也还是刚好 |

## 构思路径复原

### 1. 先从产品广告退回生活故事

第一版故事走“忙碌职场人终于喝到一口热咖啡”的自我照顾路线，卖点完整，但观看欲不足。问题在于它把生活当成使用场景，而不是戏剧问题。

后来改为先做故事方向分叉，给用户选择不同生活入口：

- 自我边界。
- 关系看见。
- 母女亲情。
- 被延迟的愿望。
- 轻概念规则。
- 关系误会和解。

用户明确指出，故事的选择权应该交给用户。于是形成了 [[domains/视觉制作/06-AI视频/01-项目定义与剧本/08-故事方向分叉与用户选择|故事方向分叉与用户选择]] 这一层。

### 2. 把“关系看见”强化成“误会和解”

“被看见”有温度，但戏剧推进还不够。强化后的方向加入了误会：

```text
她每天都装好一杯咖啡
-> 但每天都没能递出去
-> 对方误以为她忘了约定或不在乎
-> 直到咖啡在夜里仍然温热
-> 对方明白她其实一直记得
```

这个结构让观众产生问题：这杯咖啡到底要给谁？为什么一直没送出去？对方为什么误会她？

### 3. 让产品成为“物证”，不是“道具”

保温杯在故事里承担三个层次：

| 层次 | 剧情作用 | 产品卖点 |
| --- | --- | --- |
| 物理层 | 咖啡从早到晚仍有温度 | 真空保温 |
| 行动层 | 女主一天都把杯子带在身边 | 便携提绳、杯盖 |
| 情绪层 | 证明关心不是临时补救 | 保温成为关系证据 |

如果把杯子拿掉，故事就会塌掉：没有“仍然温热”的证据，误会只能靠台词解释。

## 可迁移结构

```text
关系中有一个未解误会
-> 主角准备一个具体物件/动作
-> 物件多次接近对方但没送到
-> 对方误读主角的沉默或错过
-> 物件在关键时刻保留某种证据
-> 误会不用长篇解释，被一个动作解开
-> 产品价值自然落地
```

## 可替换关系版本

| 版本 | 误会 | 产品物证 | 和解动作 |
| --- | --- | --- | --- |
| 友情 | 好友以为她忘了两人的咖啡约定 | 早上装好的咖啡夜里仍温热 | 地铁口递出杯子 |
| 亲情 | 女儿以为妈妈只会挑剔她晚归、不吃饭 | 妈妈笨拙学会杯盖和吸管 | 玄关把杯子塞进包里 |
| 爱情 | 伴侣以为她总把工作放在前面 | 她一直带着那杯原本要递出的咖啡 | 夜里见面时递出杯子 |

## 适合迁移到哪些产品

- 保温杯、水杯、饭盒、便当盒。
- 咖啡、茶饮、低度饮品。
- 围巾、手套、香氛、睡眠产品。
- 适合作为“关心证据”的小礼品。

## 迁移边界

- 误会要轻，不能变成狗血争吵。
- 物证要真实，不要让产品承担不可信的情感奇迹。
- 产品功能必须能保存、传递或证明某种生活动作。
- 和解最好靠动作完成，而不是人物站着解释。
- 结尾要克制，给观众自己补全情绪。
