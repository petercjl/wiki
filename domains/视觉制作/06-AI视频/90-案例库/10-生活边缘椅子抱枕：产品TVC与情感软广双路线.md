# 生活边缘椅子抱枕：产品TVC与情感软广双路线

同一件产品可以走不同销售叙事，但稿型和验收标准必须随路线变化。本案例用“为你写诗 × 诗人李元胜《生活边缘》系列异形椅子抱枕”分别完成产品介绍型 TVC 与情感故事软广。

## 两条路线比较

| 项目 | 产品介绍型 TVC《把诗放进生活》 | 情感软广《边缘座位》 |
| --- | --- | --- |
| 核心承诺 | 把一句诗变成可抱、可倚、可陈列的生活物件 | 总把位置让给别人，也要给自己留一个位置 |
| 主角 | 产品 | 林夏 |
| 产品职位 | 全程被认识和证明 | 触发器、行动工具和新状态物证 |

| 主要购买理由 | 诗歌设计、椅形造型、软质使用与空间陈列 | 情绪认同与设计意义，同时保持真实用途 |

# 路线A：产品介绍型TVC《把诗放进生活》

## 信息结构

```text
诗句如何只存在纸上？
→ 诗句变成椅形软物件
→ 看清设计、材质声称与使用方式
→ 进入不同生活空间
→ 诗不只被读，也被日常使用
```

## 路线A验收

- 产品在 20 秒内完整出现，不依靠长故事等待。
- 主承诺只有一个：诗歌进入生活物件。
- 材质和尺寸明确标注为商品页声称。
- 使用动作没有把软抱枕误导为可承重硬椅。
- 结尾品牌和行动信息占 8 秒；若实际朗读不清，应缩短文案或提前品牌信息，不能加速硬塞。

# 路线B：情感故事软广《边缘座位》

## 广告命题

> 总把位置让给别人，也要给自己留一个位置。

产品拿掉后，椅形、诗句、清出位置和永久保留位置之间的独特因果会消失，因此它不是结尾贴片。

## 一句话梗概

一个习惯把位置让给别人的都市女性，读到椅形抱枕上的诗句后，第一次亲手为自己清出并保留一个位置。

## 文学剧本

### 1. 内景 / 公司会议室 / 日

早会已经开始。最后一把空椅子在长桌尽头。

林夏，29岁，抱着电脑快步进来。另一名迟到的同事也停在门口。

两人同时看见那把椅子。

林夏先侧身，把路让开。

同事

你先坐？

林夏把椅子向他推了推。

林夏

没事，你坐吧。

同事坐下。林夏打开电脑，靠墙站着。

会议继续。没有人再注意这件事。

### 2. 内景 / 地铁车厢 / 傍晚

晚高峰。林夏抓着扶手，被人群挤在车门边。

她面前的座位空出来。她刚迈出半步，一位抱着孩子的女人上车。

林夏停下，退回门边。

林夏

你坐吧。

女人点头坐下。

列车启动。人群一晃，林夏肩膀撞上车门。她重新站稳，低头看手机。

屏幕上，一条朋友消息：晚上给你留位置。

### 3. 内景 / 小餐馆 / 夜

朋友们围着一张挤满菜的小桌。临时多来一个人，服务员搬来的椅子堵住过道。

林夏把自己的椅子向外拖，示意后来的人坐下。她转身坐到窄窄的窗台上。

朋友

你呢？

林夏调整了一下怀里的包，笑笑。

林夏

我坐这儿就行。

大家重新聊起来。窗玻璃里，林夏的倒影和热闹的人群叠在一起。

### 4. 内景 / 林夏的出租屋·客厅 / 夜

门开。

林夏进来，把钥匙、包和外套逐一放好。每样东西都有固定的位置。

墙边，一个未拆的包裹。

她蹲下，撕开胶带。白色绒面从纸箱里露出来，接着是红色的字、蓝色的线。

她把它完整展开。一个柔软的椅子轮廓。

林夏的手掌按下去。绒面陷下，又慢慢恢复。

她读出上面的句子。

林夏

通常我都坐在生活边上。

房间安静下来。

会议室、地铁、餐馆里的三句话在她记忆里短促地返回。

“你坐吧。”

“你坐吧。”

“我坐这儿就行。”

林夏抱着椅形抱枕，抬头看向窗边。

那里堆着几本旧杂志、一个纸箱和很久没用的晾衣架。

### 5. 内景 / 林夏的出租屋·窗边 / 连续

林夏放下抱枕。

她搬走纸箱，把杂志一本本摞好，折起晾衣架。她擦掉窗台下的一层灰，拉开窗帘。

城市的灯光进来。

她把椅形抱枕放进清出的角落，后退一步，又上前把诗句摆正。

手机视频响起。刚才餐馆里的朋友出现在屏幕上。

朋友（手机里）

到家了？你现在在哪儿呢？

林夏抱起抱枕，在窗边坐下。

她看了看自己刚清出的地方。

林夏

我坐这儿。

朋友没有听出这句话有什么不同，只笑着继续说话。

林夏靠住抱枕。她的肩膀慢慢松下来。

### 6. 内景 / 林夏的出租屋·窗边 / 次日清晨

晨光落在窗边。

林夏拿起包准备出门。走到门口，她回头。

椅形抱枕仍在昨晚的位置，诗句朝向房间。

她没有把杂物放回去。

旁白

总把位置让给别人，也要给自己留一个位置。

产品与品牌信息出现。

旁白

为你写诗，《生活边缘》系列异形椅子抱枕。我们还有诗歌。

淡出。

## 为什么这是文学剧本

- 以场景标题、动作、人物和对白组织，不用时间段或镜头编号组织。
- 写清了“发生什么”，没有预设景别、焦段、运镜与剪辑点。
- “她总忽略自己”被三次让座、靠墙、坐窗台和清出位置外化。
- 转变由“清理并永久保留角落”完成，不由旁白宣布。
- 对白的重复产生潜台词：“我坐这儿就行”是退让，“我坐这儿”是选择。

## 从旧规划到文学剧本的变化

旧稿 `early-beat-plan.md` 是时间段、剧情任务、声音与产品状态的规划表，适合讨论结构，但还不是文学剧本。本稿补上了：

- 场景标题和场景边界；
- 连续可表演的动作；
- 人物与环境的反作用；
- 对白落在具体关系里；
- 每场进入与离开状态；
- 不依赖镜头术语的可读叙事。

## 迁移方法

遇到新产品时，不复制“让座”和“窗边”。应该迁移的是：从产品独特事实找到一种人物重复行为，再让产品帮助人物完成与该行为相反的关键选择。
