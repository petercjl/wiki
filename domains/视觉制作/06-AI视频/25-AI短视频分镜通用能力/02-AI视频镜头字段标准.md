# AI视频镜头字段标准

## 问题定义

AI 视频 prompt 的镜头字段要同时服务两件事：让模型知道画面是什么，让模型知道镜头为什么这样拍。只写“女孩看雨，镜头推进，电影感”不够，因为缺少主体、动作、空间、构图、风格、连续性和限制。

## 标准字段

每个镜头至少包含 12 个字段：

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| 时间 | 控制镜头长度 | `0-6 秒` |
| 镜头任务 | 指明叙事功能 | `建立雨天校园氛围` |
| 主体 | 谁或什么是视觉中心 | `木质屋檐下的雨珠` |
| 动作 | 本镜发生的可见变化 | `雨珠缓慢聚集后坠落` |
| 景别 | 控制观看距离 | `极致特写` |
| 机位/角度 | 控制观看立场 | `低机位仰拍屋檐边缘` |
| 构图 | 控制画面组织 | `主体位于画面右上，背景大面积虚化绿叶` |
| 运镜 | 控制相机运动 | `轻微手持，缓慢向下横移` |
| 镜头/焦点 | 控制透视和清晰范围 | `35mm 复古镜头，浅景深` |
| 光线 | 控制明暗和情绪 | `阴天柔和漫射光` |
| 色彩/质感 | 控制风格 | `低饱和浅青与雾蓝，轻微胶片颗粒` |
| 连续性/限制 | 防止失控 | `保持同一雨天场景，不出现字幕，不突然变换人物` |

## 商业可控升级字段

上面的 12 个字段主要控制画面。商业视频、剧情短片、带台词或旁白的导演风格短片，还必须补充“视听控制字段”，否则模型会自由添加对白、旁白、字幕、音乐或剧情动作。

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| 素材段落 | 让每段 5-15 秒素材可独立生成 | `素材段落 1：雨夜便利店开场` |
| 剧情任务 | 锁定本段必须推进的信息 | `建立男主每天来便利店买过期车票的行为` |
| 空间锚点 | 固定场景、站位、朝向、视线和参照物 | `女店员在收银台内侧，男主在外侧偏右，两人隔着零钱盒不直接对视` |
| 台词/旁白总表 | 先锁定文本，避免模型改写 | `男人内心独白：“那张票过期以后，我才开始等。”` |
| 声音类型 | 区分当面说话、内心独白、画外音 | `女店员说：“你每天都买这一班。”` |
| 声音策略 | 控制是否生成音乐、环境声和音效 | `只生成雨声、风铃声、冰柜嗡鸣声，禁止背景音乐` |
| 反应镜头 | 长台词中途切到听众或物件，防止死盯说话人 | `切到女店员反应特写，男人画外音继续` |
| 剪辑点 | 指明后期如何接下一段 | `以男主推门动作作为下一段动作中衔接点` |
| 禁止自由发挥 | 防止模型自动补剧情 | `禁止新增人物，禁止改台词，禁止自行添加旁白或字幕` |

完整标准见 [[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/09-AI短视频完整视听分镜Prompt结构|AI短视频完整视听分镜 Prompt 结构]]。

## 声音字段写法

声音不能只写“旁白感”。如果需要声音，必须写具体文本；如果不需要声音，也要明确禁止模型生成对白或旁白。

| 需求 | 写法 |
| --- | --- |
| 当面开口 | `女店员说：“你每天都买这一班。”` |
| 心里想法 | `男人内心独白：“我一直以为，只要票还在，她就还会回来。”` |
| 人不在画面内或切到反应镜头 | `男人画外音：“我以为她不会发现。”` |
| 无对白 | `无对白，无旁白，只保留雨声、风铃声和冰柜低频嗡鸣。禁止模型自行添加说话声。` |

分段视频生成时，除非任务明确要求，否则不要让每段各自生成 BGM。整片音乐应参考 [[domains/视觉制作/06-AI视频/10-Seed-Audio短视频音频一致性工作流|Seed-Audio短视频音频一致性工作流]]，在剪辑完成后统一生成。

## 推荐写法

```text
4-9 秒：
镜头任务：引入人物并保持雨天静默氛围。
景别与构图：中近景，屋檐占据画面上缘，女孩位于画面右侧三分线。
主体与动作：年轻女孩站在木质屋檐下避雨，低头握着一封浅色信封。
运镜与焦点：镜头从雨珠缓慢下移到女孩侧脸，轻微手持晃动，浅景深。
光色质感：柔和漫射光，低饱和浅青与雾蓝调，35mm 复古镜头，轻微胶片颗粒。
连续性限制：延续上一镜雨天校园，不出现现代电子屏和字幕。
```

## 字段优先级

当 prompt 太长时，按这个顺序保留：

1. 镜头任务
2. 主体与动作
3. 景别与构图
4. 运镜
5. 光线、色彩、质感
6. 台词/旁白/声音策略
7. 空间锚点
8. 连续性与负向限制

风格词不能代替镜头任务。导演风格是全局锚点，镜头字段是落地执行。

## 适用边界

单镜不要同时要求复杂人物调度、复杂相机运动、复杂情绪转变和复杂环境变化。AI 模型更擅长在一个短镜头里完成一个明确变化。
