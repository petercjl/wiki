# AI短视频分镜通用能力

本专题沉淀“故事大纲 -> AI 短视频分镜提示词”的通用能力。它不按导演组织，而是按 Agent 生成分镜 prompt 时必须掌握的能力组织：拆镜、镜头字段、景别、运镜、光线色彩、人物动作、场景描述、连续性、声音台词控制和质量检查。

## Agent 使用方式

当用户给出故事大纲并要求生成 AI 视频分镜 prompt 时，优先读取本专题。若用于商业视频、剧情短片、带对白/旁白的视频，必须读取 [[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/09-AI短视频完整视听分镜Prompt结构|AI短视频完整视听分镜 Prompt 结构]]，先锁定台词、声音策略、空间锚点和连续性，再写分段 prompt。若用户指定“岩井俊二、王家卫、韦斯·安德森、是枝裕和、小津安二郎”等导演风格，再叠加对应导演风格页。
