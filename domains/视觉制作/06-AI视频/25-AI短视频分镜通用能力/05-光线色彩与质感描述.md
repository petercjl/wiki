# 光线色彩与质感描述

## 核心模型

光线、色彩和质感不是装饰词，而是视觉强度和风格识别的主要控制器。写 AI 视频 prompt 时，要把它们放在“情绪和叙事功能”之后。

```text
情绪目标 -> 光线类型 -> 色彩关系 -> 质感媒介 -> 负向限制
```

## 光线词表

| 情绪目标 | 光线选择 | prompt 句式 |
| --- | --- | --- |
| 温柔、回忆 | 柔和漫射光、窗边自然光、阴天散射 | `柔和漫射光包裹人物轮廓，阴影很浅` |
| 孤独、疏离 | 冷光、局部光、远处环境光 | `冷色窗光从一侧切入，人物另一侧陷入暗部` |
| 压迫、悬疑 | 低照度、高反差、硬阴影 | `狭窄走廊中高反差硬光，墙面投下锐利阴影` |
| 青春、清透 | 逆光、侧逆光、浅色反射 | `雨后逆光穿过树叶，人物发丝边缘发亮` |
| 生活流 | 自然光、混合室内光、低修饰 | `普通室内自然光，轻微曝光不足，质感真实` |

## 色彩关系

Bruce Block 的对比/亲和原则可以转成色彩策略：

- 色彩亲和：相近色、低饱和、低反差，适合回忆、日常、哀伤、留白。
- 色彩对比：冷暖冲突、高饱和点色、明暗反差，适合冲突、欲望、危险、转折。
- 色彩进展：故事从冷到暖、从暖到冷、从低饱和到高饱和，适合表现人物变化。

| 目标 | 色彩提示 |
| --- | --- |
| 岩井俊二式青春 | `低饱和浅青、雾蓝、柔和绿色，白色高光略泛光` |
| 都市孤独 | `霓虹红绿与冷蓝黑夜形成对比` |
| 家庭日常 | `暖白、木色、自然肤色，低对比` |
| 精密悬疑 | `冷灰、蓝绿、低饱和，高控制感` |

## 质感词表

| 质感 | 适用场景 | prompt 句式 |
| --- | --- | --- |
| 胶片颗粒 | 回忆、青春、旧时代、私人影像 | `轻微 35mm 胶片颗粒，柔和高光` |
| 旧镜头眩光 | 逆光、雨天、梦感、青春 | `复古镜头轻微眩光，边缘柔化` |
| 数字冷感 | 科技、都市、心理压迫 | `干净数字影像，锐利边缘，冷色校色` |
| 纪实粗粝 | 现实主义、县城、街头 | `手持纪实质感，轻微噪点，未修饰自然光` |
| 广告精致 | 产品、商业短片 | `高洁净度画面，细腻皮肤质感，受控柔光` |

## 负向限制

光色质感 prompt 常见失控点：

- 过度电影感导致画面黑、脏、不可读。
- 胶片颗粒过重导致主体细节丢失。
- 霓虹过多导致风格变成夜店或赛博。
- 复古镜头过强导致模糊和畸变。

推荐限制：

```text
保持主体清晰，胶片颗粒轻微不过重，不出现过曝白斑，不出现文字水印，不使用夸张赛博霓虹。
```
