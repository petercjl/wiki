# AI短视频分镜知识库建设路线图

## 最终目标

本知识库的最终任务不是讲电影史，也不是收集导演简介，而是支持 Agent 完成以下转换：

```text
输入：一个 2 分钟左右的故事大纲
输出：一组可直接给 AI 视频模型使用的多段分镜提示词
```

标准输出形态类似：

```text
岩井俊二风格，画面低饱和度调色，整体呈浅青与雾蓝调；
柔和漫射光，轻微胶片颗粒质感，35mm 复古镜头拍摄。

0-4 秒：慢动作极致特写，澄澈透亮的雨珠自木质屋檐垂落，
背景是浓郁绿叶虚化形成柔和散景光斑。

4-9 秒：镜头缓慢向下横移，带轻微手持摄影机晃动，
画面缓缓露出屋檐下避雨的年轻日系少女，容貌清丽。
```

## 两层知识结构

### 第一层：通用分镜能力

通用分镜能力解决“无论采用什么导演风格，都必须会”的问题：

- 故事大纲如何拆成 AI 可生成的镜头。
- 一个 AI 视频镜头应该包含哪些字段。
- 什么剧情节点适合什么景别。
- 什么情绪适合什么运镜。
- 如何描述人物、环境、光线、色彩、质感和动作。
- 如何保证镜头之间连续。
- 如何避免单镜头过载、运动过复杂、模型失控。

### 第二层：导演/影像美学大师风格

导演风格层解决“用谁的影像语言来拍”的问题：

- 哪些导演名本身就是大模型已知的高密度风格锚点。
- 该导演风格适合什么故事。
- 该导演的视觉 DNA 是什么。
- 如何把该风格写成全局 prompt。
- 如何把该风格落到秒级镜头 prompt。
- 每个导演至少提供一个 2 分钟短片样例。

## 导演风格页模板

每个导演/影像美学大师页面固定包含：

```text
1. 风格锚点
   - 中文名
   - 英文名
   - 大模型可能认识的提示词表达

2. 适合的故事类型
   - 适合什么题材
   - 不适合什么题材

3. 视觉 DNA
   - 构图
   - 光线
   - 色彩
   - 质感
   - 景别偏好
   - 运镜偏好

4. 叙事 DNA
   - 常见人物关系
   - 情绪结构
   - 时间结构
   - 常见物件/场景

5. Prompt 写法
   - 全局风格 prompt
   - 镜头级 prompt 字段
   - 负向限制

6. 2 分钟短片案例
   - 故事大纲
   - 分镜表
   - 每镜 prompt
   - 为什么这个镜头符合该导演风格
```

## 建设顺序

### 阶段 1：通用骨架

先创建通用能力层，使 Agent 有稳定字段和拆镜方法：

1. `01-故事大纲到AI视频分镜的拆解方法`
2. `02-AI视频镜头字段标准`
3. `04-运镜选择方法`
4. `08-Agent使用模板：故事大纲转分镜提示词`

### 阶段 2：书籍吸收

按实用优先级吸收五本书：

```text
Katz -> Mercado -> Brown -> Kenworthy -> Block
```

每本书都要保留 raw、extraction notes、coverage matrix 和 audit handoff，但正式页面要融合进通用能力层，不做孤立书摘。

### 阶段 3：导演风格页

从 P0 导演开始，每个导演页都要有：

- 风格锚点。
- 视觉 DNA。
- 叙事 DNA。
- 全局 prompt。
- 2 分钟短片故事。
- 8-12 个镜头 prompt。

### 阶段 4：Agent 查询入口

更新 `queries/AI视频导演与分镜入口.md`，使 Agent 根据任务自动选择：

```text
故事大纲 -> 通用分镜能力
特定导演风格 -> 导演风格页
商业产品任务 -> AI商业短视频规划方法
模型参数/能力 -> 模型卡
音频/BGM/声线 -> Seed-Audio工作流
```

## 验收标准

一个合格页面必须满足：

- 能直接帮助 Agent 写出多段分镜提示词。
- 不只是解释术语，而要有字段、判断规则和例子。
- 每个导演风格页都要有具体 2 分钟短片案例。
- 每个镜头 prompt 都要包含时长、景别/机位、构图、运镜、动作、光线、色彩、质感和负向限制。
- 引用书籍或视频来源必须有 raw 和 extraction notes。
- query 入口必须能路由到正确页面。
