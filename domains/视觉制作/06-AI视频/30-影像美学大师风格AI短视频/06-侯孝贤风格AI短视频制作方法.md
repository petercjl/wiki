# 侯孝贤风格AI短视频制作方法

## 风格锚点

侯孝贤风格适合“长镜头、远距离观察、历史感、生活流、时间沉积、人物被环境包围”的 AI 短视频。可写为：

```text
受侯孝贤电影启发，静态长镜头，远景和中远景观察，长焦压缩空间，
少剪辑，人物在生活环境中自然行动，历史记忆和日常时间慢慢沉积。
```

## 适合的故事类型

- 小镇、旧宅、家族记忆、时代变化、离乡与归乡。
- 人物关系通过空间、停顿和日常动作显现。
- 适合低强度剧情、回忆、旧时代气息、乡村/老城生活。

不适合高密度信息广告、强动作、夸张情绪爆发。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 构图 | 人物常处在中远景，环境比表情更重要 |
| 运镜 | 固定镜头、少量缓慢移动，避免频繁切换 |
| 镜头 | 长焦、远距离观察，压缩空间层次 |
| 节奏 | 长时间停留，让观众自己观察关系 |
| 表演 | 自然、低声、非戏剧化，动作常在画面深处发生 |
| 叙事 | 历史和私人记忆并置，不急于解释 |

## Prompt 写法

全局 prompt：

```text
受侯孝贤电影启发，静态长镜头，中远景观察，长焦压缩空间，
自然光，低饱和旧时代色彩，人物在真实生活空间中缓慢行动，
少剪辑，情绪克制，时间感沉静而悠长。
```

负向限制：

```text
不使用快速剪辑，不使用夸张特写，不使用炫技运镜，不出现强烈商业灯光，不出现字幕水印。
```

## 如何调用通用分镜能力

侯孝贤风格要把 [[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/01-故事大纲到AI视频分镜的拆解方法|故事拆镜]] 放慢：一个镜头承担一个完整生活动作，观众在中远景里自己发现关系。[[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/04-运镜选择方法|运镜]] 要尽量克制，除非人物或空间真的需要移动。

| 通用能力 | 侯孝贤式落地 |
| --- | --- |
| 故事拆镜 | 空间建立 -> 人物日常行动 -> 关系停顿 -> 历史/旧物回声 -> 人物离开。 |
| 景别情绪 | 中远景和远景为主，让环境压过表情。 |
| 运镜选择 | 静态长镜头、少量缓慢移动，避免频繁景别切换。 |
| 光色质感 | 自然光、低饱和旧时代色彩、长焦空间压缩。 |
| 人物动作 | 整理胶片、靠门等待、并排坐着、慢慢离开，动作完整保留。 |
| 连续性 | 通过同一空间、同一光线、同一机器声维持时间沉积感。 |

## 范例-两阶段工作流：先抽卡，再固化资产

侯孝贤风格 AI 短视频要先让空间和时间成立，再用开放性抽卡确定老戏院、放映员、孙女、放映机、胶片光束和生活化声音，最后用中远景静态长镜头拆分故事。情绪不靠解释，而靠人物在旧空间里完成动作。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入符合侯孝贤气质的 BGM，用来探索节奏、情绪和声音方向；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，避免每段素材自带不同音乐。

### 故事脚本：老戏院的最后一晚

小镇老戏院即将关门，最后一晚只剩老放映员阿海在整理大厅和放映室。影院过去热闹过，墙上还有褪色海报，木椅上落着灰。孙女阿茵来接他回家，她知道拆除队明天就要进场，也知道阿公舍不得这里。

阿海没有说舍不得，只说再等一卷。他把最后一卷胶片装上放映机，像几十年来每天都做的那样检查齿孔、穿片、调灯。阿茵站在门口，没有催他，只看着机器光束穿过尘埃。两人来到空荡观众席，并排坐着看一段无声旧片。阿茵问这卷以前放过吗，阿海说很久了。

影片结束后，阿海把胶片盒、旧海报和钥匙一一放回原位。他拉下卷帘门时，街道声从门外进来，戏院里面的机器声终于停了。阿茵扶着他慢慢离开，镜头留在空大厅和银幕上，银幕没有画面，只剩微弱反光。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库。

```text
这是一次侯孝贤式老戏院短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒视频，用于确定静态长镜头、旧戏院空间、老放映员、孙女、放映机、胶片、尘埃光束、机器声和日常闲谈式对白。

视觉风格：受侯孝贤电影启发，静态长镜头，中远景观察，长焦压缩空间；自然光和旧灯光混合，低饱和旧时代色彩，人物在真实生活空间里缓慢行动；镜头保持距离，不靠特写煽情。

声音风格：可以有极轻的旧电影放映感环境铺底，但不要煽情旋律；重点是放映机转动声、胶片摩擦声、脚步声、旧门轻响、远处街道声。对白像日常闲谈，低声自然。

0-5 秒：静态中远景，老戏院放映室，老人背对镜头整理胶片，放映机占据前景，空气里有尘埃。

5-10 秒：孙女站在门口，门框把她框在右侧，她低声说：“阿公，时间到了。”老人没有回头，继续穿胶片。

10-15 秒：放映机启动，光束穿过尘埃，两人之间隔着机器和一段安静空间，只听见机器转动声。

负向限制：不要快速剪辑，不要煽情音乐，不要夸张特写，不要商业灯光，不要字幕水印，不要现代影院大厅。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 中远景距离、长焦压缩、低饱和旧时代色、尘埃光束 | 固定侯孝贤式观察距离。 |
| 人物板 | 老放映员服装、动作、背影；孙女站姿和门口位置 | 保持人物关系和空间距离。 |
| 场景板 | 戏院大厅、放映室、观众席、旧街道、出口 | 维持同一老戏院世界。 |
| 道具板 | 胶片盒、放映机、旧海报、木椅、卷帘门 | 锁定历史感物件。 |
| 声音板 | 放映机声、胶片摩擦、脚步、旧门、低声日常对白 | 控制声音真实感。 |
| 镜头板 | 静态中远景、门框构图、空镜、背影并坐 | 固定长镜头语法。 |

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定主要角色的外貌、服装、年龄感、动作习惯和关系距离。
- 场景板：锁定主要空间的结构、光线方向、时代质感和可反复出现的空间锚点。
- 风格板：锁定该导演对应的光色、镜头距离、构图习惯、运镜方式和节奏。
- 道具板：锁定推动剧情的关键物件，确保每段生成时不会随机替换。
- 声音板：锁定对白声线、环境声、动作音效和禁止随机 BGM 的生产规则。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

## 2 分钟短片分镜案例：老戏院的最后一晚

小镇老戏院关门前夜，放映员把最后一卷胶片装上机器。孙女来接他回家，两人在空荡观众席里看完一段无声旧片。

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| D1 | 阿茵 | 当面说话 | 阿公，时间到了。 | Prompt 3 | 提醒关门。 |
| D2 | 阿海 | 当面说话 | 再等一卷。 | Prompt 4 | 表达不舍但仍像日常话。 |
| D3 | 阿茵 | 当面说话 | 这卷以前放过吗？ | Prompt 6 | 引出共同观看旧片。 |
| D4 | 阿海 | 当面说话 | 很久了。 | Prompt 6 | 用短句承载记忆。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：老戏院大厅

```text
段落时长：15 秒以内
全局风格：侯孝贤风格，静态长镜头，中远景观察，长焦压缩空间；自然光和旧灯光混合，低饱和旧时代色彩；人物在真实生活空间中缓慢行动，少剪辑，情绪克制，时间感沉静悠长。

剧情任务：建立老戏院大厅、褪色海报、木椅和老人背影，让空间先于人物承载关门前夜的时间沉积感。
声音策略：只生成音效，禁止生成音乐；无对白；环境声来自本场景真实动作；不得随机新增台词、人声或背景音乐。
空间锚点：老戏院大厅静态中远景，褪色海报在左侧，售票窗口在右侧，木椅排成纵深，阿海从画面深处缓慢走过。

0-5 秒：中远景，固定镜头或受控缓慢运动，角色位于画面稳定构图中，视线朝向关键道具或空间出口；画面交代老戏院大厅的空间关系、光线方向和时代质感。 音效：空间底噪，远处环境声。

5-10 秒：中近景，镜头保持克制，人物完成一个明确动作，表情不夸张，构图让关键道具位于画面中心； 音效：道具轻响，脚步或衣料摩擦声。

10-15 秒：反应镜头或空镜，固定镜头，角色动作结束后留下停顿，空间、道具和光影继续承载情绪，作为下一段的剪辑出口。 音效：环境声延续，动作尾音渐弱。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止快速剪辑，禁止夸张特写，禁止炫技运镜，禁止强烈商业灯光，禁止字幕水印；禁止随机添加长对白、人声或背景音乐。
```
