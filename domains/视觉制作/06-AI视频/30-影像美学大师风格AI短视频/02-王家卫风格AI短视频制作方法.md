# 王家卫风格AI短视频制作方法

## 风格锚点

王家卫风格适合作为“都市孤独、暧昧、错过、夜晚、欲望、记忆错位”的高密度风格锚点。用于 AI 短视频时，建议写成：

```text
受王家卫都市爱情片启发的影像风格，香港夜晚霓虹、潮湿街巷、慢门拖影、手持近距离摄影、镜面反射、浓郁红绿黄与冷蓝对比，孤独旁白感。
```

如果直接使用导演名，应在内部研究和风格学习语境中使用；面向商业交付时，可改写为“霓虹都市怀旧爱情片风格”。

## 适合的故事类型

- 都市夜晚里的错过、等待、暧昧、失恋。
- 两个孤独人物短暂靠近又分开。
- 带旁白感的第一人称记忆。
- 地铁、便利店、雨夜街巷、出租屋、餐馆、天桥、霓虹招牌。

不适合宏大世界观、强情节动作片、清爽明亮产品广告。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 构图 | 狭窄空间、门框/玻璃/镜面遮挡、人物被墙面和霓虹切割 |
| 光线 | 夜晚低照度、霓虹反射、局部暖光、潮湿路面反光 |
| 色彩 | 红、绿、黄、冷蓝交织，高色彩对比，局部颜色主导画面 |
| 质感 | 手持、拖影、慢门、轻微模糊、颗粒、旧胶片感 |
| 景别 | 中近景、特写、贴身跟拍，常让人物被环境挤压 |
| 运镜 | 手持跟随、快速掠过、慢动作拖影、镜面反射中的移动 |

## Prompt 写法

全局 prompt：

```text
受王家卫都市爱情片启发，香港夜晚霓虹街巷，潮湿空气与路面反光，
红绿黄色霓虹与冷蓝阴影强对比，手持近距离摄影，慢门拖影，
镜面和玻璃反射，轻微胶片颗粒，孤独旁白感，暧昧而克制。
```

负向限制：

```text
不出现赛博朋克机甲，不出现夸张科幻城市，不出现字幕水印，不使用干净商业棚拍光，不让人物表情过度戏剧化。
```

## 如何调用通用分镜能力

王家卫风格要把 [[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/01-故事大纲到AI视频分镜的拆解方法|故事拆镜]] 改造成“夜晚城市中的错过链”：环境反光 -> 人物被空间切割 -> 物件暴露秘密 -> 手部/视线短暂停留 -> 人物走入霓虹 -> 错过回声。镜头字段必须特别写清玻璃、镜面、霓虹、慢门拖影和人物距离。

| 通用能力 | 王家卫式落地 |
| --- | --- |
| 故事拆镜 | 用“遇见但不能抵达”的动作链组织镜头，避免把情绪说成台词。 |
| 景别情绪 | 中近景和特写为主，人物被货架、玻璃、门框、霓虹切割。 |
| 运镜选择 | 手持贴身跟拍、缓慢侧移、玻璃内外拍摄、慢动作拖影。 |
| 光色质感 | 红绿黄霓虹与冷蓝暗部对比，潮湿路面反光，胶片颗粒。 |
| 人物动作 | 递零钱、摩挲电话卡、握住硬币、短暂停手、回头被遮挡，都是关系证据。 |
| 连续性 | 保持同一夜晚、同一便利店/街角、同一枚硬币、同一张旧电话卡和同一霓虹色系。 |

## 范例-两阶段工作流：先抽卡，再固化资产

王家卫风格 AI 短视频要先有完整故事脚本，再做开放性风格抽卡，最后进入分段分镜。故事脚本负责让行为、道具和情感逻辑成立；开放性抽卡像一支 15 秒预告片，用来确定霓虹色调、人物气质、便利店空间、雨夜街角和声音氛围；正式分镜再把故事脚本拆成可生成的素材段落。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入王家卫式怀旧都市 BGM，用来探索节奏、情绪和旁白声线；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，否则每段自带音乐会破坏剪辑连续性。

### 故事脚本：凌晨 1 点 12 分的电话卡

雨夜的旧便利店旁边有一部快要被拆掉的公用电话。男主阿森每晚凌晨 1 点 12 分都会走进便利店，买一盒薄荷糖，然后让夜班女店员小瑜找给他一枚一元硬币。他从不吃那盒糖，只把硬币握在手心，走到门外的公用电话前，拨一个早已停机的号码。

小瑜最初以为他只是怪。后来她发现，阿森每次拨号前都会把一张旧电话卡从钱包里拿出来，看一眼背面的数字。电话卡已经失效，边角被雨水泡软，上面贴着一张褪色标签：1:12。小瑜从收银台的旧抽屉里找到同款电话卡，那是很多年前便利店还卖电话卡时留下的库存。她猜到阿森等的不是一个电话，而是一个没有被接通的过去。

有一天晚上，阿森照常买薄荷糖。小瑜找零钱时，故意把那张新电话卡夹进纸币里。她想告诉他：“这张还能用。”但话到嘴边，只说出一句：“今天雨很大。”阿森点点头，拿着零钱走出去。门口风铃响了一下，雨声立刻把便利店和街道分成两个世界。

阿森走到公用电话前，才发现零钱里多了一张新电话卡。他回头望向便利店，小瑜已经追到玻璃门内。就在这时，夜班小巴从两人中间驶过，车窗上的霓虹反光把他们的脸切成一格一格。小巴离开后，小瑜还在门内，阿森还在雨里。电话亭的灯忽明忽暗，他终于把新电话卡插进电话，但没有拨号。第二天凌晨 1 点 12 分，便利店门口只剩下那盒没拆封的薄荷糖。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库：雨夜便利店、阿森的深色外套、小瑜的夜班制服、玻璃门、公用电话、薄荷糖、一元硬币、旧电话卡、新电话卡、霓虹色系和怀旧 BGM。

```text
这是一次王家卫式都市雨夜爱情短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒风格测试视频，用于确定雨夜便利店、公用电话、男主阿森、
女店员小瑜、薄荷糖、一元硬币、电话卡、霓虹反光、手持贴近摄影和孤独旁白气质。

视觉风格：香港雨夜便利店，潮湿玻璃门，红绿黄霓虹与冷蓝冰柜光对比；
手持近距离摄影，慢门拖影，玻璃和镜面反射，低照度胶片颗粒；
人物被门框、货架、收银台和公用电话亭切割，暧昧、克制、像一段已经过期的记忆。

声音风格：必须有怀旧都市 BGM，低速鼓刷、柔和萨克斯或旧唱片质感，
音乐像从街角小店里漏出来；必须有低声、孤独、第一人称的男声旁白。
环境声包含雨声、便利店风铃、冰柜低频嗡鸣、硬币落在柜台上的声音。

0-5 秒：极近距离特写，便利店玻璃门上的雨水缓慢滑落，
红绿霓虹在玻璃上拖成长条光痕，门外公用电话亭灯光忽明忽暗。

5-10 秒：手持镜头透过玻璃看见店内冷蓝冰柜光和黄色收银台顶灯，
男主阿森穿深色外套站在货架间，手里握着一枚硬币和旧电话卡。
男声画外音：“有些号码停机以后，反而每天都有人拨。”

10-15 秒：焦点转到收银台后的女店员小瑜，
她把一张新电话卡夹进找零纸币里，玻璃反射把两个人叠在同一片霓虹里。

负向限制：不要赛博朋克城市，不要夸张科幻霓虹，不要字幕水印，
不要干净商业棚拍光，不要明亮甜美爱情片，不要新增无关顾客。
```

这类 prompt 用于探索风格，不直接商用。抽卡时允许 BGM 和更开放的画面想象；一旦进入正式分段素材，就要禁止音乐并锁定台词、音效、空间和连续性。

### 阶段二：从满意抽卡视频提取资产

一旦某次抽卡出现满意的画面感，不要马上继续盲抽下一段。正确做法是把这段视频拆成可复用资产：

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 色调、霓虹颜色、颗粒、拖影、对比度、镜头距离 | 约束后续所有镜头的光色质感。 |
| 人物板 | 男主外貌、年龄感、服装、发型、姿态、表情 | 保持主角一致，避免下一段换脸换衣服。 |
| 场景板 | 便利店门口、玻璃门、冰柜、收银台、街角、雨夜路面 | 固定故事空间，减少场景漂移。 |
| 道具板 | 薄荷糖、一元硬币、旧电话卡、新电话卡、玻璃门风铃、霓虹招牌 | 固定关键叙事物件。 |
| 声音板 | 雨声、风铃、冰柜嗡鸣、脚步、巴士声、旁白声线方向 | 决定后期音效和声线资产。 |
| 镜头板 | 抽卡视频里最有效的景别、机位、运镜和转焦方式 | 作为后续分段 prompt 的镜头语言依据。 |

这一步把“抽卡得到的惊喜”变成“后续可控生成的参考资产”。抽卡不是交付环节，而是前期视觉开发。

抽卡视频评估清单：

| 维度 | 判断问题 | 处理 |
| --- | --- | --- |
| 风格是否对 | 是否一眼有霓虹、潮湿、拖影、手持贴近、孤独感 | 对则截帧做风格板，不对则继续抽卡或加强风格词。 |
| 人物是否可用 | 人物脸、年龄、服装、气质是否适合故事 | 可用则截正脸/侧脸/背影做人物板。 |
| 场景是否可用 | 便利店、街角、玻璃门、收银台是否有真实空间感 | 可用则截外景、内景、关键角落做场景板。 |
| 道具是否出现 | 是否出现薄荷糖、硬币、电话卡、风铃、霓虹招牌等可叙事物件 | 出现则截图固化，不出现则后续单独生成道具板。 |
| 声音是否干净 | 是否乱加音乐、乱说话、乱出字幕 | 不干净也可只取画面；声音后期重做。 |
| 镜头是否值得复用 | 是否有漂亮转焦、玻璃反射、手持移动、雨滴特写 | 值得复用则写成镜头板规则。 |

资产固化模板：

```text
抽卡视频编号：
可用结论：采用 / 只采用风格 / 只采用人物 / 不采用

风格板：
- 主色调：
- 光线：
- 质感：
- 镜头距离：
- 最有价值的截图时间点：

人物板：
- 男主外貌：
- 男主服装：
- 男主气质：
- 需要补充的角度：
- 是否需要重新生成女店员：

场景板：
- 外部空间：
- 内部空间：
- 固定参照物：
- 镜头可用机位：

道具板：
- 已出现道具：
- 需要补充道具：
- 道具禁止变化项：

声音板：
- 可保留环境声：
- 需要后期重做的声音：
- 旁白声线方向：

后续分镜影响：
- 哪些后续 Prompt 必须继承这次抽卡风格：
- 哪些地方必须改成完整视听控制：
```

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定阿森和小瑜的外貌、服装、姿态和距离感。
- 场景板：锁定便利店、街角和雨夜空间。
- 风格板：锁定王家卫式霓虹、慢门拖影、胶片颗粒。
- 道具板：锁定薄荷糖、一元硬币、旧电话卡、新电话卡和公用电话。
- 声音板：锁定旁白声线、雨声、风铃、冰柜、电车/小巴声和禁止随机 BGM。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

因此，本页后面的“完整视听分镜 Prompt 结构”不是取代开放性 prompt，而是开放性抽卡之后的可控生产稿。

## 2 分钟短片分镜案例：凌晨 1 点 12 分的电话卡

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成更适合控制在 15 秒内，所以这个 2 分钟故事不要一次生成，而要拆成 8 个 15 秒以内的素材段落。每段都必须独立完整，重新写清空间锚点、声音策略、台词/旁白、连续性和负向限制，避免模型自由补剧情。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 故事设定

| 项目 | 设定 |
| --- | --- |
| 男主阿森 | 30 岁左右，深色外套，夜班后疲惫，每晚买薄荷糖换一枚硬币，去便利店门外公用电话拨旧号码。 |
| 女店员小瑜 | 25 岁左右，便利店夜班店员，克制、敏感，注意到阿森每晚 1 点 12 分重复同一个仪式。 |
| 关键物件 | 一盒没拆封的薄荷糖、一枚一元硬币、一张失效旧电话卡、一张可用新电话卡、一叠找零纸币。 |
| 主场景 | 雨夜便利店、玻璃门、收银台、冷蓝冰柜、门外公用电话、潮湿街角、夜班小巴。 |
| 情绪曲线 | 雨夜孤独 -> 仪式被看见 -> 秘密被理解 -> 小瑜主动递出新电话卡 -> 两人被雨夜和车流隔开。 |

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| V1 | 阿森 | 内心独白 | 有些号码停机以后，反而每天都有人拨。 | Prompt 1 | 建立第一人称记忆和公用电话意象。 |
| V2 | 阿森 | 内心独白 | 我买的不是薄荷糖，是一枚刚好够拨一次的硬币。 | Prompt 2 | 解释行为逻辑。 |
| D1 | 小瑜 | 当面说话 | 你每天都是一块钱。 | Prompt 4 | 点破她已经观察到他的仪式。 |
| D2 | 小瑜 | 当面说话 | 今天雨很大。 | Prompt 6 | 她想说更多但只说出口的克制台词。 |
| V3 | 阿森 | 画外音 | 有些人走出便利店，是为了回家；我只是为了听见忙音。 | Prompt 5 | 承接公用电话动作。 |
| V4 | 小瑜 | 内心独白 | 如果那张旧的不能用了，至少新的还可以。 | Prompt 6 | 给她夹入电话卡的动作动机。 |
| V5 | 小瑜 | 画外音 | 可是那天晚上，雨把所有声音都挡在门外。 | Prompt 7 | 强化没有喊出口的错过。 |
| V6 | 阿森 | 内心独白 | 后来我才明白，她给我的不是电话卡，是一个可以不再等待的晚上。 | Prompt 8 | 收束主题。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：雨夜便利店与公用电话

```text
段落时长：15 秒以内
全局风格：受王家卫都市爱情片启发，香港夜晚霓虹街巷，潮湿空气与路面反光；
红、绿、黄霓虹与冷蓝阴影形成强烈色彩对比；
```
