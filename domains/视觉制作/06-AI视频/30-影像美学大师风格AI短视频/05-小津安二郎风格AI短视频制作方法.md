# 小津安二郎风格AI短视频制作方法

## 风格锚点

小津安二郎风格适合“家庭秩序、代际关系、静态构图、榻榻米低机位、空镜过渡、克制情绪”。AI prompt 可写：

```text
受小津安二郎家庭片启发，榻榻米低机位，静态正面构图，人物端坐，室内几何秩序，门框和障子分割空间，空镜过渡，情绪克制而深沉。
```

## 适合的故事类型

- 父母与子女、婚嫁、离家、老去、日常分别。
- 家庭室内、榻榻米房间、走廊、车站、街角、空房间。
- 用静止和空镜表现时间流逝。

不适合高速动作、强烈主观镜头、炫技运镜。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 机位 | 榻榻米低机位，接近坐在地上的视角 |
| 构图 | 静态、正面、几何秩序，门框/障子形成框中框 |
| 运镜 | 极少移动，更多依赖剪辑和空镜 |
| 空镜 | 走廊、茶壶、晾衣、街道、火车、空房间作为情绪间隔 |
| 表演 | 人物端坐、低头、沉默、简短对话 |
| 节奏 | 留白、停顿、生活时间感 |

## Prompt 写法

全局 prompt：

```text
受小津安二郎家庭片启发，榻榻米低机位，固定镜头，
正面静态构图，日式室内几何秩序，门框和障子形成层次，
低饱和自然色，空镜过渡，人物情绪克制，节奏安静缓慢。
```

负向限制：

```text
不使用手持晃动，不使用快速推进，不使用夸张表演，不使用现代霓虹赛博风，不出现字幕水印。
```

## 如何调用通用分镜能力

小津安二郎风格要把 [[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/07-镜头连续性与剪辑衔接|镜头连续性与剪辑衔接]] 做成“静态空间连续性”：同一房间、同一门框、同一茶杯、同一低机位反复出现。拆镜时不要追人物情绪，而要让空镜、物件和坐姿承担情绪。

| 通用能力 | 小津式落地 |
| --- | --- |
| 故事拆镜 | 空镜建立时间 -> 家庭对坐 -> 空镜过渡 -> 物件动作 -> 离开 -> 空房间收束。 |
| 景别情绪 | 榻榻米低机位中景和远景为主，少用强特写。 |
| 运镜选择 | 固定镜头，几乎不移动；通过剪辑和空镜换气。 |
| 光色质感 | 低饱和自然色、木地板、障子、茶杯、清晨光。 |
| 人物动作 | 端坐、点头、擦杯、鞠躬、停顿，不写夸张表情。 |
| 连续性 | 保持低机位、门框几何、茶杯位置和室内明暗关系。 |

## 范例-两阶段工作流：先抽卡，再固化资产

小津安二郎风格 AI 短视频要先建立稳定家庭空间，再用开放性抽卡确定榻榻米低机位、门框几何、父女坐姿、旧茶杯和家庭环境声，最后把离别拆成静态镜头与空镜。这个风格不是靠剧情转折，而是靠空间秩序和物件位置改变来让情绪浮现。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入符合小津安二郎气质的 BGM，用来探索节奏、情绪和声音方向；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，避免每段素材自带不同音乐。

### 故事脚本：空房间里的茶杯

女儿由纪在外地找到工作，搬家前一晚回老家陪父亲吃饭。父亲独居多年，屋里东西都放在固定位置：矮桌、电视、水壶、走廊尽头的柜子，还有由纪小时候用过的小花茶杯。由纪说第二天早上走，父亲只点头，说嗯。

饭后父亲像往常一样洗碗。由纪站在厨房门边，看见父亲把旧茶杯洗干净，才想起小时候自己摔过一次，杯沿留下很小的缺口。她问杯子还在啊，父亲说一直在。两人没有继续说话。夜里，由纪在左侧房间收拾行李，父亲在右侧隔壁房间看电视，两个空间由半开的障子门连着。

第二天清晨，由纪在玄关鞠躬离开。父亲只站在室内阴影里点头，没有追出去。门合上后，房间安静下来。镜头回到空荡榻榻米房间，柜门半开，小花茶杯仍放在中央小格里。阳光慢慢移到杯身上，像父亲没有说出口的挽留。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库。

```text
这是一次小津安二郎式家庭片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒风格测试视频，用于确定榻榻米低机位、日式老屋空间、父亲和女儿形象、旧茶杯、饭桌距离、空镜和家庭环境声。

视觉风格：榻榻米低机位，固定镜头，正面静态构图；日式室内几何秩序，门框、障子、矮桌形成层次；低饱和自然色，pillow shot 空镜过渡，人物情绪克制，节奏安静缓慢。

声音风格：可以没有音乐，或只有极轻、几乎听不见的弦乐/钢琴铺底；重点是碗筷声、电视低音量、水声、柜门声、门外远处火车声。对白极短、平静、低声，不解释情绪。

0-5 秒：固定低机位，父亲和女儿隔着矮桌端坐吃晚饭，门框和墙线把画面切成稳定几何块。

5-10 秒：女儿低声说：“明天早上走。”父亲点头，没有抬眼，只有碗筷轻响和远处电视声。

10-15 秒：空镜切到厨房水壶冒出蒸汽，画面没有人物，水声和碗筷声延续，镜头完全不动。

负向限制：不要手持晃动，不要快速推进，不要夸张哭喊，不要现代霓虹，不要字幕水印，不要煽情配乐。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 榻榻米低机位、静态构图、门框几何、自然低饱和 | 统一小津式空间秩序。 |
| 人物板 | 父亲服装、女儿服装、坐姿、鞠躬、点头方式 | 保持父女形象和克制表演。 |
| 场景板 | 走廊、饭桌、厨房、玄关、空房间 | 构成家庭空间连续性。 |
| 道具板 | 旧茶杯、矮桌、行李箱、水壶、电视 | 让情绪依附物件。 |
| 声音板 | 碗筷声、水声、电视低声、行李轮、门合上、远处火车 | 形成空镜和家庭声音线索。 |
| 镜头板 | 固定低机位、pillow shot 空镜、正面对坐、静态特写 | 固定镜头语法。 |

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定主要角色的外貌、服装、年龄感、动作习惯和关系距离。
- 场景板：锁定主要空间的结构、光线方向、时代质感和可反复出现的空间锚点。
- 风格板：锁定该导演对应的光色、镜头距离、构图习惯、运镜方式和节奏。
- 道具板：锁定推动剧情的关键物件，确保每段生成时不会随机替换。
- 声音板：锁定对白声线、环境声、动作音效和禁止随机 BGM 的生产规则。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

## 2 分钟短片分镜案例：空房间里的茶杯

女儿搬家前回老家吃最后一顿晚饭。父亲没有挽留，只在饭后把她小时候用过的茶杯洗干净放回柜子。第二天清晨，房间空了，茶杯还在。

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| D1 | 由纪 | 当面说话 | 明天早上走。 | Prompt 2 | 说出离别事实。 |
| D2 | 父亲 | 当面说话 | 嗯。 | Prompt 2 | 父亲克制回应。 |
| D3 | 由纪 | 当面说话 | 那个杯子还在啊。 | Prompt 5 | 引出旧茶杯记忆。 |
| D4 | 父亲 | 当面说话 | 一直在。 | Prompt 5 | 用短句承载多年保存。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：老屋走廊空镜

```text
段落时长：15 秒以内
全局风格：小津安二郎风格，榻榻米低机位，固定镜头，正面静态构图；日式室内几何秩序，门框和障子形成层次；低饱和自然色，空镜过渡，人物情绪克制，节奏安静缓慢。

剧情任务：用老屋走廊空镜建立家庭空间和安静节奏。
声音策略：只生成音效，禁止生成音乐；无对白；环境声为远处碗筷声、木地板轻响和室内空气声；不得随机新增台词、人声或背景音乐。
空间锚点：日式老屋走廊，低机位固定镜头，障子门半开，木地板延伸到画面深处，没有人物。

0-5 秒：低机位空镜，固定镜头，日式老屋走廊空无一人，障子门半开，清晨自然光落在木地板上；画面以门框和地板线形成稳定几何。 音效：室内空气声，远处碗筷声。

5-10 秒：低机位空镜，固定镜头，走廊尽头没有人物，光线缓慢移过木地板；空间先于人物进入故事。 音效：木地板轻微响声，远处电视低声。

10-15 秒：低机位空镜，固定镜头，障子门边缘轻轻停住，画面完全不推进，只保留老屋安静的时间。 音效：远处火车声，室内安静声。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止手持晃动，禁止快速推进，禁止夸张表演，禁止现代霓虹赛博风，禁止字幕水印；禁止随机添加长对白、人声或背景音乐。
```
