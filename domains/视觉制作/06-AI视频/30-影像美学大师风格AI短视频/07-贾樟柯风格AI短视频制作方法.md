# 贾樟柯风格AI短视频制作方法

## 风格锚点

贾樟柯风格适合“县城现实、时代变迁、边缘人物、冷静旁观、纪实质感、流行音乐与公共空间”的 AI 短视频。可写为：

```text
受贾樟柯现实主义电影启发，县城街道、工厂、车站、KTV、拆迁现场，
固定长镜头和冷静旁观，DV/纪实质感，普通人在时代变化中沉默行动。
```

## 适合的故事类型

- 小城青年、漂泊、打工、旧厂区、拆迁、县城商业街。
- 个人命运与城市变化并置。
- 普通人生活里的荒诞、孤独、时代感。

不适合精致棚拍、童话风、强英雄主义广告。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 场景 | 县城街道、工厂、车站、舞厅、旧商场、施工围挡 |
| 构图 | 固定远景/中景，人物在真实公共空间中移动 |
| 光线 | 自然光、荧光灯、廉价彩灯、灰尘空气 |
| 质感 | DV、纪实、粗粝、低修饰 |
| 运镜 | 固定观察、缓慢跟随，少夸张运动 |
| 叙事 | 时代背景不解释，出现在广告牌、建筑、广播、流行歌里 |

## Prompt 写法

全局 prompt：

```text
受贾樟柯现实主义电影启发，县城公共空间，固定长镜头，
自然光与荧光灯混合，DV 纪实质感，灰尘和空气颗粒可见，
人物沉默行动，城市拆迁、广告牌、车站广播和流行音乐构成时代背景。
```

负向限制：

```text
不使用精致商业棚拍，不使用过度美颜，不使用夸张戏剧表演，不出现赛博城市，不出现字幕水印。
```

## 如何调用通用分镜能力

贾樟柯风格要把 [[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/06-人物动作与场景描述方法|人物动作与场景描述]] 和公共空间绑定：人物只是时代现场的一部分，广告牌、施工围挡、荧光灯、旧门头和广播声都是叙事信息。拆镜时不要只拍人物反应，要拍人物怎样被县城空间包住。

| 通用能力 | 贾樟柯式落地 |
| --- | --- |
| 故事拆镜 | 县城空间 -> 普通人物行动 -> 时代信息进入 -> 失落动作 -> 公共空间余味。 |
| 景别情绪 | 固定远景和中景保留环境，少用煽情特写。 |
| 运镜选择 | 固定观察、缓慢跟随，保留真实时间。 |
| 光色质感 | 自然灰光、荧光灯偏绿、DV 纪实质感、灰尘颗粒。 |
| 人物动作 | 停车、翻底片、收回信封、站到围挡前，动作要普通。 |
| 连续性 | 用同一条街、同一照相馆、同一拆迁声和同一旧照片串联。 |

## 范例-两阶段工作流：先抽卡，再固化资产

贾樟柯风格 AI 短视频要先让县城空间、时代变化和普通人的行动成立，再用开放性抽卡确定街道、照相馆、拆迁围挡、旧底片、现场声和纪实质感，最后把故事拆成公共空间里的观察镜头。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入符合贾樟柯气质的 BGM，用来探索节奏、情绪和声音方向；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，避免每段素材自带不同音乐。

### 故事脚本：拆迁围挡前的合影

县城老街要拆，围挡已经立到照相馆门口。小赵从外地回来，想在照相馆关门前找到一张童年全家福底片。照相馆老板老马认识他父亲，也记得那张照片大概是哪一年拍的，但旧底片柜被搬过几次，编号已经乱了。

两人在照相馆里翻找底片，外面挖掘机和电动车的声音不断传进来。小赵说我爸以前说这里拍得最好，老马说那时候大家都来这里拍。底片最终没有找到，只找到一个空袋子，上面写着小赵家的姓。老马没说抱歉，只把店里的旧相机拿出来，让小赵站到围挡前再拍一张。

傍晚，拆迁围挡前，小赵和老马并排站了一会儿。小赵举着空底片袋，老马按下快门。新照片拍完后，街道没有发生什么戏剧变化，电动车继续经过，广场舞音乐从远处传来。照相馆卷帘门半落，围挡上的城市更新标语在风里晃动。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库。

```text
这是一次贾樟柯式县城现实短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒视频，用于确定县城十字路口、老照相馆、拆迁围挡、小赵、老马、旧底片袋、DV 纪实质感和现场环境声。

视觉风格：受贾樟柯现实主义电影启发，县城公共空间，低饱和灰黄调，DV/数字纪实质感；中远景固定观察，偶尔轻微手持，真实街道招牌、电动车、围挡、尘土和普通人行动进入画面。

声音风格：可以有远处广场舞或商铺喇叭形成时代背景，不要煽情配乐；重点保留电动车声、挖掘机远声、街边人声、卷帘门声和短促现实对白。

0-5 秒：县城十字路口中远景，电动车从前景经过，老照相馆门口被拆迁围挡挤压。

5-10 秒：小赵站在照相馆门口看旧招牌，老马从店里掀开帘子出来，两人没有热情寒暄。

10-15 秒：旧相机对准拆迁围挡，小赵手里拿着空底片袋，街道现场声不断进入画面。

负向限制：不要精致商业广告质感，不要赛博都市霓虹，不要夸张悲情，不要干净棚拍，不要字幕水印。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 低饱和灰黄调、DV 纪实、县城公共空间、真实街道声 | 固定贾樟柯式现实质感。 |
| 人物板 | 小赵返乡服装、迟疑表情；老马店主形象、慢动作作业方式 | 保持普通人气质。 |
| 场景板 | 县城十字路口、老照相馆、底片柜、拆迁围挡、街道余味 | 形成时代变化空间。 |
| 道具板 | 旧底片袋、旧相机、卷帘门、围挡标语、旧照片袋 | 锁定叙事物件。 |
| 声音板 | 电动车、挖掘机、喇叭、广场舞远声、卷帘门、短对白 | 保留现场声。 |
| 镜头板 | 中远景固定观察、轻微手持、公共空间空镜、慢反应镜头 | 固定现实主义镜头语法。 |

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定主要角色的外貌、服装、年龄感、动作习惯和关系距离。
- 场景板：锁定主要空间的结构、光线方向、时代质感和可反复出现的空间锚点。
- 风格板：锁定该导演对应的光色、镜头距离、构图习惯、运镜方式和节奏。
- 道具板：锁定推动剧情的关键物件，确保每段生成时不会随机替换。
- 声音板：锁定对白声线、环境声、动作音效和禁止随机 BGM 的生产规则。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

## 2 分钟短片分镜案例：拆迁围挡前的合影

县城老街拆迁前，返乡青年想找回一张童年全家福底片。底片没有找到，照相馆老板在拆迁围挡前为他重新拍了一张。

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| D1 | 小赵 | 当面说话 | 我想找一张老底片。 | Prompt 2 | 说明行动目标。 |
| D2 | 老马 | 当面说话 | 哪一年的？ | Prompt 2 | 进入现实查找。 |
| D3 | 小赵 | 当面说话 | 我爸说，这里拍得最好。 | Prompt 3 | 连接父亲记忆。 |
| D4 | 老马 | 当面说话 | 那时候大家都来这里拍。 | Prompt 5 | 承载县城旧时光。 |
| D5 | 老马 | 当面说话 | 站那儿吧，我再给你拍一张。 | Prompt 7 | 用新合影替代找不到的底片。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：县城十字路口

```text
段落时长：15 秒以内
全局风格：贾樟柯风格，县城现实主义，低饱和灰黄调，DV/数字纪实质感；中远景固定观察，轻微手持，公共空间、普通街道招牌、电动车、围挡和现场声构成时代变化。

剧情任务：建立县城十字路口、拆迁围挡和老照相馆被挤压的现实环境。
声音策略：只生成音效，禁止生成音乐；无对白；环境声来自本场景真实动作；不得随机新增台词、人声或背景音乐。
空间锚点：县城十字路口中远景，老照相馆在画面右侧，拆迁围挡占据左侧，电动车从前景经过。

0-5 秒：中远景，固定镜头或受控缓慢运动，角色位于画面稳定构图中，视线朝向关键道具或空间出口；画面交代县城十字路口的空间关系、光线方向和时代质感。 音效：空间底噪，远处环境声。

5-10 秒：中近景，镜头保持克制，人物完成一个明确动作，表情不夸张，构图让关键道具位于画面中心； 音效：道具轻响，脚步或衣料摩擦声。

10-15 秒：反应镜头或空镜，固定镜头，角色动作结束后留下停顿，空间、道具和光影继续承载情绪，作为下一段的剪辑出口。 音效：环境声延续，动作尾音渐弱。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止精致商业广告质感，禁止赛博霓虹，禁止夸张悲情，禁止干净棚拍，禁止字幕水印；禁止随机添加煽情旁白、人声或背景音乐。
```

#### Prompt 4：照相馆空镜

```text
段落时长：15 秒以内
全局风格：贾樟柯风格，县城现实主义，低饱和灰黄调，DV/数字纪实质感；中远景固定观察，轻微手持，公共空间、普通街道招牌、电动车、围挡和现场声构成时代变化。
```
