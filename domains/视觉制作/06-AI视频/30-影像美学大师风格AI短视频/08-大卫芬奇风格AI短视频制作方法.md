# 大卫芬奇风格AI短视频制作方法

## 风格锚点

大卫·芬奇风格适合“冷峻、精密、控制、心理压迫、调查、都市阴影、道德暧昧”的 AI 短视频。可写为：

```text
受大卫·芬奇心理惊悚片启发，低饱和冷色，精密构图，受控镜头运动，
暗部细节丰富，工业/办公室/地下空间，角色被秩序和信息压迫。
```

## 适合的故事类型

- 调查、秘密、监控、失踪、职场阴影、心理博弈。
- 人物执念、控制欲、系统压力。
- 高质感品牌悬疑、科技产品安全感、犯罪短片。

不适合温暖家庭、童话、强手持纪实、轻快喜剧。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 构图 | 精密、稳定、几何秩序，人物常被建筑/屏幕框住 |
| 色彩 | 低饱和冷绿、冷蓝、灰黑，局部钨丝暖光 |
| 光线 | 低照度、高控制，暗部保留细节 |
| 运镜 | 稳定、隐形、精确，运动服务信息揭示 |
| 景别 | 谨慎使用特写，特写意味着关键信息 |
| 质感 | 数字洁净、锐利、压抑、无多余浪漫 |

## Prompt 写法

全局 prompt：

```text
受大卫·芬奇心理惊悚片启发，低饱和冷绿与冷蓝调，
精密稳定构图，受控缓慢运镜，低照度室内，暗部细节丰富，
玻璃、屏幕、金属和办公空间形成压迫秩序，冷静、严密、心理紧张。
```

负向限制：

```text
不使用鲜艳糖果色，不使用手持乱晃，不使用夸张表演，不出现恐怖怪物，不出现字幕水印。
```

## 如何调用通用分镜能力

大卫·芬奇风格要把 [[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/02-AI视频镜头字段标准|镜头字段]] 写得非常精确：每个镜头都必须有信息揭示功能，特写只能给关键证据。[[domains/视觉制作/06-AI视频/25-AI短视频分镜通用能力/07-镜头连续性与剪辑衔接|连续性]] 要靠编号、屏幕、门禁、走廊方向和冷色光保持严密。

| 通用能力 | 芬奇式落地 |
| --- | --- |
| 故事拆镜 | 系统异常 -> 证据放大 -> 人物被空间压迫 -> 逐层追查 -> 真相反噬。 |
| 景别情绪 | 中近景保持压迫，特写只给屏幕、编号、刷卡器、日志。 |
| 运镜选择 | 受控缓慢推近、稳定跟拍、对称机房远景，避免随意晃动。 |
| 光色质感 | 低饱和冷绿冷蓝、暗部细节、屏幕光、金属和玻璃。 |
| 人物动作 | 停止敲键盘、刷卡、看日志、抬头看摄像头，克制但精确。 |
| 连续性 | 同一异常编号贯穿，空间从监控室到走廊、电梯、机房逐级下沉。 |

## 范例-两阶段工作流：先抽卡，再固化资产

大卫芬奇风格 AI 短视频要先建立系统、空间和心理压迫的因果链，再用开放性抽卡确定监控室、门禁日志、冷色屏幕、红色刷卡器、系统声和受控运镜，最后把故事拆成精密推进的镜头组。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入符合大卫芬奇气质的 BGM，用来探索节奏、情绪和声音方向；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，避免每段素材自带不同音乐。

### 故事脚本：凌晨 3:17 的门禁记录

凌晨 3:17，安全分析员林栩在一栋办公楼的监控室值班。系统弹出一条异常门禁记录：他的工号刚刚通过地下机房认证。但林栩本人坐在监控室，工牌也在桌上。他以为是系统错误，开始追查日志。

监控画面里，一个和他轮廓相似的人穿过走廊，刷过红色门禁器，进入地下机房。林栩沿着同一条走廊追查，电梯镜面不断反射他的脸和屏幕上的时间。系统女声冷静重复 authentication failed 和 user authenticated，像在替某个看不见的人说话。

林栩抵达地下机房，发现服务器屏幕上显示的不是入侵者，而是他自己的实时监控画面。3:17 的记录不断刷新，仿佛不是过去发生的事，而是系统正在迫使他完成的路径。最后，他回到监控室，屏幕弹出 User authenticated，镜头显示他的工牌仍在桌上，而门禁记录时间再次跳回 3:17。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库。

```text
这是一次大卫芬奇式科技心理惊悚短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒视频，用于确定冷色监控室、安全分析员、门禁日志、红色刷卡器、玻璃反射、地下机房、系统女声和低频心理压迫。

视觉风格：受大卫芬奇心理惊悚片启发，低饱和冷绿/冷蓝色，精密构图，受控缓慢推进；暗部细节清晰，屏幕光、玻璃反射、对称走廊和红色门禁点构成压迫。

声音风格：可以有低频、极简、持续的心理惊悚 BGM；环境声包括服务器低鸣、键盘声、荧光灯电流、门禁滴声和冷静系统女声。

0-5 秒：监控室极端对称构图，林栩坐在屏幕墙前，时间显示 03:17。

5-10 秒：门禁日志特写，红色异常编号跳出，系统女声说：“Authentication failed.”

10-15 秒：走廊监控画面里出现一个像林栩的背影，红色刷卡器闪烁，低频声音压下来。

负向限制：不要血腥恐怖，不要手持混乱，不要赛博霓虹，不要夸张鬼影，不要字幕水印。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 低饱和冷绿冷蓝、精密构图、暗部细节、受控推进 | 固定芬奇式心理压迫。 |
| 人物板 | 林栩制服、工牌、疲惫表情、克制动作 | 保持主角身份连续。 |
| 场景板 | 监控室、屏幕墙、办公楼走廊、电梯、地下机房 | 形成追查路径。 |
| 道具板 | 工牌、门禁日志、红色刷卡器、服务器屏幕、电梯镜面 | 锁定悬疑线索。 |
| 声音板 | 服务器低鸣、键盘、荧光灯、电梯、门禁滴声、系统女声 | 控制惊悚节奏。 |
| 镜头板 | 对称构图、缓慢推进、屏幕反射、细节特写、镜面反应 | 固定精密镜头语法。 |

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定主要角色的外貌、服装、年龄感、动作习惯和关系距离。
- 场景板：锁定主要空间的结构、光线方向、时代质感和可反复出现的空间锚点。
- 风格板：锁定该导演对应的光色、镜头距离、构图习惯、运镜方式和节奏。
- 道具板：锁定推动剧情的关键物件，确保每段生成时不会随机替换。
- 声音板：锁定对白声线、环境声、动作音效和禁止随机 BGM 的生产规则。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

## 2 分钟短片分镜案例：凌晨 3:17 的门禁记录

凌晨值班的安全分析员发现自己的工号出现在异常门禁记录里。他追查到地下机房，却发现系统像在预先写好他的行动。

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| V1 | 系统女声 | 画外音 | Authentication failed. | Prompt 2 | 建立异常。 |
| D1 | 林栩 | 低声说话 | 我没有离开监控室。 | Prompt 3 | 确认矛盾。 |
| V2 | 系统女声 | 画外音 | User authenticated. | Prompt 8 | 最终反噬确认。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：监控室 3:17

```text
段落时长：15 秒以内
全局风格：大卫芬奇风格，低饱和冷绿冷蓝色，精密构图，暗部细节清晰，受控缓慢推进；屏幕光、玻璃反射、对称走廊、红色门禁点和低频环境声形成心理压迫。

剧情任务：建立凌晨监控室、屏幕墙、林栩和 03:17 的异常时间。
声音策略：只生成音效，禁止生成音乐；无对白；环境声来自本场景真实动作；不得随机新增台词、人声或背景音乐。
空间锚点：监控室对称构图，林栩坐在屏幕墙前，桌上有工牌，中央屏幕显示 03:17。

0-5 秒：中远景，固定镜头或受控缓慢运动，角色位于画面稳定构图中，视线朝向关键道具或空间出口；画面交代监控室 3:17的空间关系、光线方向和时代质感。 音效：空间底噪，远处环境声。

5-10 秒：中近景，镜头保持克制，人物完成一个明确动作，表情不夸张，构图让关键道具位于画面中心； 音效：道具轻响，脚步或衣料摩擦声。

10-15 秒：反应镜头或空镜，固定镜头，角色动作结束后留下停顿，空间、道具和光影继续承载情绪，作为下一段的剪辑出口。 音效：环境声延续，动作尾音渐弱。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止血腥恐怖，禁止手持混乱，禁止赛博霓虹，禁止夸张鬼影，禁止字幕水印；禁止随机添加解释性长对白、人声或背景音乐。
```
