# 是枝裕和风格AI短视频制作方法

## 风格锚点

是枝裕和风格适合“家庭、日常、儿童、记忆、温柔观察、低戏剧化冲突”。AI prompt 可写：

```text
受是枝裕和生活流家庭片启发，自然光，低机位观察，克制表演，日常动作承载情绪，饭桌、厨房、走廊、阳台等生活空间，温柔而不煽情。
```

## 适合的故事类型

- 家庭成员之间未说出口的爱与遗憾。
- 儿童视角、亲子关系、临时家庭、兄弟姐妹。
- 饭桌、家务、放学路、旧屋整理、探亲。
- 小动作中藏情绪，而不是强冲突对白。

不适合高速动作、强类型悬疑、夸张视觉奇观。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 构图 | 低调、自然、不过度设计；常让人物处在生活空间中 |
| 光线 | 自然光、窗光、阴天柔光、室内暖光 |
| 色彩 | 生活化低饱和，木色、白墙、自然肤色 |
| 运镜 | 静态观察、轻微跟随，少炫技 |
| 场景 | 厨房、饭桌、玄关、阳台、街边、学校路 |
| 表演 | 小动作、停顿、沉默、儿童自然反应 |

## Prompt 写法

全局 prompt：

```text
受是枝裕和生活流家庭片启发，自然光，低饱和生活色彩，
静态观察镜头，低机位和中景为主，饭桌、厨房、玄关等日常空间，
人物表演克制，情绪通过手部动作、停顿和生活细节流露。
```

负向限制：

```text
不使用夸张哭喊，不使用强烈戏剧光，不使用快速剪辑，不出现梦幻滤镜，不出现字幕水印。
```

## 如何调用通用分镜能力

是枝裕和风格要把 [[domains/视觉制作/06-AI视频/03-分镜脚本/25-06-人物动作与场景描述方法|人物动作与场景描述方法]] 放到核心位置：情绪不靠台词，而靠做饭、系鞋带、摸贴纸、打开饭盒这些日常动作。拆镜时优先选择厨房、饭桌、玄关、车站等生活空间，让故事自然流动。

| 通用能力 | 是枝裕和式落地 |
| --- | --- |
| 故事拆镜 | 日常动作开始 -> 未说出口的关系 -> 离开动作 -> 物件触发情绪 -> 安静余味。 |
| 景别情绪 | 中景观察生活关系，特写只给手、饭盒、梅子等情绪证据。 |
| 运镜选择 | 固定镜头和轻微跟随为主，不用炫技运动。 |
| 光色质感 | 自然窗光、低饱和木色、白墙、普通街道光。 |
| 人物动作 | 停顿、低头、整理、帮忙、吃第一口饭，比直接哭更重要。 |
| 连续性 | 用便当盒、书包、玄关、车站长椅串起离别过程。 |

## 范例-两阶段工作流：先抽卡，再固化资产

是枝裕和风格 AI 短视频要先把家庭关系写成可信的生活过程，再用开放性抽卡确定普通住宅、自然窗光、人物年龄感、便当盒、梅子和生活声音，最后进入分段分镜。这个风格的重点不是制造戏剧事件，而是让离别藏在做饭、整理、停顿和吃第一口饭这些日常动作里。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入符合是枝裕和气质的 BGM，用来探索节奏、情绪和声音方向；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，避免每段素材自带不同音乐。

### 故事脚本：饭盒里的梅子

女孩小澄从小跟外婆住在一起。母亲在外地工作，外婆每天早上给她做便当，便当里总会有一颗红色梅子。小时候小澄嫌梅子太酸，总把它拨到盒子角落；长大后，她反而记得最清楚的就是这个味道。

高中毕业后的清晨，小澄要搬去母亲所在的城市。外婆没有办送别，也没有说舍不得，只像平常一样洗米、装饭、把筷盒放到便当袋旁。小澄几次想开口说“我会常回来”，但每次都被厨房里的水声、拉链声和外婆的背影吞掉。玄关处，外婆蹲下来替她重新系鞋带，说鞋带松了；小澄说自己来，却没有真的把脚挪开。

小澄离开家门，走过熟悉的住宅街，到小车站等车。她在长椅上打开便当，发现白米中央仍放着一颗梅子，位置和小时候一模一样。她夹起第一口饭，低声说还是这个味道。列车经过时，便当袋轻轻碰到她的膝盖，外婆没有出现在画面里，却像还坐在她身边。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库。

```text
这是一次是枝裕和式家庭生活流短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒风格测试视频，用于确定旧厨房、外婆、小澄、便当盒、红色梅子、自然窗光、低戏剧化表演和生活环境声。

视觉风格：受是枝裕和生活流家庭片启发，自然窗光，低饱和木色和白墙；普通厨房、饭桌、玄关、住宅街和小车站都保持真实生活质感；静态观察镜头，中景和手部特写为主，情绪藏在洗米、装饭、拉链、系鞋带和吃第一口饭这些小动作里。

声音风格：可以有极轻、几乎听不见的温柔钢琴或木吉他 BGM，用来探索家庭记忆感；重点保留洗米声、饭勺碰便当盒、筷盒轻响、书包拉链、清晨街道远声。对白必须短、低声、像家人平时说话。

0-5 秒：清晨旧厨房，中景固定镜头，外婆背对镜头洗米，小澄坐在饭桌边整理书包，自然窗光从左侧进入。

5-10 秒：手部特写，外婆把白米装进便当盒，蒸汽很轻，红色梅子放在米饭中央。外婆低声说：“筷子别忘了。”

10-15 秒：小澄把筷盒放进便当袋，手指在袋口停一秒，没有回答，只轻轻拉上拉链。

负向限制：不要夸张哭喊，不要广告棚拍光，不要梦幻滤镜，不要精致摆拍便当，不要字幕水印，不要戏剧化告别台词。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 自然窗光、低饱和木色、普通住宅质感、静态观察镜头 | 保持家庭生活流真实感。 |
| 人物板 | 外婆围裙、年龄感、手部动作；小澄校服、书包、克制表情 | 固定两代人形象和表演方式。 |
| 场景板 | 厨房、饭桌、玄关、住宅街、小车站长椅 | 串联离别路径。 |
| 道具板 | 便当盒、筷盒、便当袋、书包、红色梅子、桌脚贴纸 | 锁定情绪物件。 |
| 声音板 | 洗米声、饭勺声、拉链声、自行车铃、列车风声、短对白语气 | 形成后期声音设计方向。 |
| 镜头板 | 固定中景、低机位、手部特写、静态留白 | 固定是枝式观察方式。 |

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定主要角色的外貌、服装、年龄感、动作习惯和关系距离。
- 场景板：锁定主要空间的结构、光线方向、时代质感和可反复出现的空间锚点。
- 风格板：锁定该导演对应的光色、镜头距离、构图习惯、运镜方式和节奏。
- 道具板：锁定推动剧情的关键物件，确保每段生成时不会随机替换。
- 声音板：锁定对白声线、环境声、动作音效和禁止随机 BGM 的生产规则。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

## 2 分钟短片分镜案例：饭盒里的梅子

女孩准备搬离外婆家。外婆像平常一样给她做便当，两人都不提离别。女孩在车站打开饭盒，发现米饭中央放着她小时候最讨厌、后来最想念的一颗梅子。

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| D1 | 外婆 | 当面说话 | 筷子别忘了。 | Prompt 2 | 用日常话替代告别。 |
| D2 | 小澄 | 当面说话 | 嗯。 | Prompt 2 | 克制回应。 |
| D3 | 外婆 | 当面说话 | 鞋带松了。 | Prompt 4 | 用照顾动作表达不舍。 |
| D4 | 小澄 | 当面说话 | 我自己来。 | Prompt 4 | 表示已经长大但仍被照顾。 |
| D5 | 小澄 | 低声自语 | 还是这个味道。 | Prompt 8 | 收束梅子记忆。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：清晨厨房

```text
段落时长：15 秒以内
全局风格：是枝裕和风格，家庭生活流自然主义，自然窗光，低饱和木色与白墙；静态观察镜头，中景、低机位和手部特写为主；表演克制，情绪通过停顿、低头、整理、装饭、递东西和吃第一口饭流露。

剧情任务：建立清晨厨房和外婆照常做便当的生活节奏。
声音策略：只生成音效，禁止生成音乐；无对白；环境声为洗米声、饭勺声、清晨住宅远声；不得随机新增台词、人声或背景音乐。
空间锚点：旧厨房中景，左侧窗户自然光，外婆在灶台前背对镜头，小澄坐在饭桌边整理书包，便当盒放在台面上。

0-5 秒：中景，固定镜头，外婆背对镜头在左侧水槽洗米，小澄坐在右侧饭桌边整理书包，视线低垂不看外婆；自然窗光从左侧照进来，低饱和木色和白墙让空间像普通家庭清晨。 音效：洗米水声，远处住宅街轻声。

5-10 秒：手部特写，固定镜头，外婆把白米装进便当盒，木质饭勺从画面左侧进入，白米蒸汽很轻；小澄的书包在背景虚化，动作缓慢熟练。 音效：饭勺碰便当盒声，蒸汽轻响。

10-15 秒：低机位细节镜头，固定镜头，小澄的脚在桌下轻轻晃动，便当盒在台面中央，外婆的围裙边缘从前景经过；画面不煽情，只让生活动作继续。 音效：布料轻响，远处自行车铃声。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止夸张哭喊，禁止广告棚拍光，禁止梦幻滤镜，禁止精致摆拍便当，禁止字幕水印；禁止随机添加告别台词、人声或背景音乐。
```

#### Prompt 2：没说出口的离别

```text
段落时长：15 秒以内
全局风格：是枝裕和风格，家庭生活流自然主义，自然窗光，低饱和木色与白墙；静态观察镜头，中景、低机位和手部特写为主；表演克制，情绪通过停顿、低头、整理、装饭、递东西和吃第一口饭流露。

剧情任务：用极短日常对白表现没说出口的离别。
声音策略：只生成音效，禁止生成音乐；本段如有对白，只按时间轴原句生成；环境声为筷盒声、拉链声；不得随机新增台词、人声或背景音乐。
空间锚点：饭桌与厨房之间，外婆站在台面旁，小澄坐在饭桌边，两人之间隔着便当袋和书包。

0-5 秒：中景，固定镜头，小澄坐在饭桌右侧，把课本塞进书包，身体朝向桌面，视线几次抬起又低下；外婆在左侧台面旁整理便当，不主动看她。 音效：书包拉链声，厨房轻响。

5-10 秒：中近景，固定镜头，外婆把筷盒放到便当袋旁，身体侧对小澄，声音平常。外婆说：“筷子别忘了。”小澄低声说：“嗯。” 音效：筷盒轻放声，饭盒盖扣合声。

10-15 秒：细节镜头，轻微静止观察，小澄把筷盒放进便当袋，手指在袋口停顿一秒，又慢慢拉上拉链；她没有说再见，光线停在手背上。 音效：拉链声，室内安静声。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止夸张哭喊，禁止广告棚拍光，禁止梦幻滤镜，禁止精致摆拍便当，禁止字幕水印；禁止随机添加告别台词、人声或背景音乐。
```

#### Prompt 3：桌脚贴纸的记忆

```text
段落时长：15 秒以内
全局风格：是枝裕和风格，家庭生活流自然主义，自然窗光，低饱和木色与白墙；静态观察镜头，中景、低机位和手部特写为主；表演克制，情绪通过停顿、低头、整理、装饭、递东西和吃第一口饭流露。

剧情任务：用桌脚贴纸触发童年记忆，不靠台词解释。
声音策略：只生成音效，禁止生成音乐；无对白；环境声为远处自行车铃、厨房轻响；不得随机新增台词、人声或背景音乐。
空间锚点：饭桌下方低机位，桌脚在画面左侧，褪色贴纸在桌脚边缘，小澄的手从右侧伸入画面。

0-5 秒：低机位细节镜头，固定镜头，饭桌下方的旧桌脚占画面左侧，小澄小时候贴的褪色贴纸贴在桌脚边缘；小澄坐在画面右上方虚化，视线落向贴纸。 音效：远处自行车铃声，厨房水声。

5-10 秒：极近距离特写，固定镜头，小澄的手指从右侧伸入画面，摸过贴纸翘起的边缘，动作停顿一秒；贴纸没有被撕下，只在自然光里显出旧痕。 音效：指尖擦过贴纸声，木桌轻响。

10-15 秒：低机位空镜，固定镜头，小澄收回手，贴纸留在画面角落，桌脚和地板占据大部分画面；童年没有闪回，只作为一个没有被带走的痕迹。 音效：远处碗筷声，室内空气声。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止夸张哭喊，禁止广告棚拍光，禁止梦幻滤镜，禁止精致摆拍便当，禁止字幕水印；禁止随机添加告别台词、人声或背景音乐。
```

#### Prompt 4：玄关整理鞋带
