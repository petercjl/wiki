# 岩井俊二风格AI短视频制作方法

## 为什么“岩井俊二风格”很重要

这条微信视频号教程真正有价值的地方，不只是给了一组日系青春片 prompt，而是示范了一个 AI 短视频制作原则：

```text
当一个影像美学大师的风格已经被大模型充分理解时，
“岩井俊二风格”本身就是一个高密度风格锚点，
它胜过千言万语地罗列自然光、留白、青春、雨天、低饱和、暗恋和遗憾。
```

大模型通常知道岩井俊二关联的影像气质：日系青春、自然光、轻微胶片颗粒、低饱和色彩、空镜留白、雨天/校园/田野、书信/旁白/回忆，以及克制而未说出口的情绪。真正写 prompt 时，不应只写“大师名”，也不应只堆一长串风格词，而是采用双层结构：

```text
岩井俊二风格
-> 激活模型中的整体审美先验
-> 再用镜头级提示词锁定具体画面
```

## 适合的短视频主题

| 适合 | 不适合 |
| --- | --- |
| 夏天、毕业、暗恋、初恋、未说出口的喜欢 | 强促销硬广 |
| 校园、图书馆、教室、雨天、小巷、田野 | 高节奏信息流种草 |
| 旧信、旧照片、耳机、雨伞、书本、单车 | 需要强展示产品功能的演示片 |
| 克制、遗憾、回望、物是人非 | 高饱和、强刺激、强转化叫卖 |

## 风格控制栈

| 层级 | 控制方式 | 岩井俊二式写法 |
| --- | --- | --- |
| 风格锚点 | 用大师名调用模型先验 | `岩井俊二风格`、`Shunji Iwai inspired Japanese youth film aesthetic` |
| 情绪命题 | 先定义没说出口的情绪 | 暗恋、告别、遗憾、回望、未曾发生 |
| 构图 | 用少量信息和大面积留白承载情绪 | 人物偏下/偏侧，天空、远山、稻田、窗帘、雨幕留出空间 |
| 光线 | 让光成为记忆的介质 | 自然光、窗边漫射逆光、丁达尔光、光晕、轻微过曝 |
| 色彩 | 压低商业感 | 低饱和、浅青、雾蓝、米黄、淡白、褪色胶片 |
| 质感 | 让画面像被回忆过滤过 | 16mm/35mm/8mm 胶片颗粒、柔焦、低保真录像感、轻微动态模糊 |
| 镜头 | 慢下来，轻微不稳定 | 慢镜、长镜、手持微晃、呼吸推近、浅景深 |
| 叙事 | 不把情绪说透 | 书信、旁白、旧物、非线性回忆、视线躲闪 |

## 如何调用通用分镜能力

写岩井俊二风格时，先读 [[domains/视觉制作/06-AI视频/03-分镜脚本/25-01-故事大纲到AI视频分镜的拆解方法|故事大纲到AI视频分镜的拆解方法]]，把故事拆成“环境空镜 -> 人物出现 -> 微动作 -> 旧物/光线触发 -> 远去或留白”的镜头任务链。再用 [[domains/视觉制作/06-AI视频/03-分镜脚本/25-02-AI视频镜头字段标准|AI视频镜头字段标准]] 补齐每镜的时长、景别、运镜、光色、质感和连续性。

岩井俊二风格的通用能力映射：

| 通用能力 | 岩井俊二式落地 |
| --- | --- |
| 故事拆镜 | 少用剧情解释，多用雨、窗帘、书、信、耳机、背影作为情绪节点。 |
| 景别情绪 | 特写给手指、眼睫、雨珠和旧物；远景给稻田、校园、路口和远去背影。 |
| 运镜选择 | 慢动作、轻微手持、缓慢下移、呼吸式推近、失焦转场，避免强戏剧化运动。 |
| 光色质感 | 低饱和浅青、雾蓝、米黄，自然漫射光、逆光、胶片颗粒、柔焦。 |
| 人物动作 | 把暗恋写成手指停住、耳尖泛红、低头、抬眼、回避视线。 |
| 连续性 | 通过同一雨天、同一校服、同一旧物、同一色调保持短片统一。 |

## 范例-两阶段工作流：先抽卡，再固化资产

岩井俊二风格 AI 短视频要先有完整故事脚本，再做开放性风格抽卡，最后进入分段分镜。故事脚本负责让旧物、人物关系和情绪逻辑成立；开放性抽卡像一支 15 秒预告片，用来确定雨天、校园、角色气质、胶片色调和声音氛围；正式分镜再把故事脚本拆成可生成的素材段落。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入岩井俊二式轻柔、透明、带青春回忆感的 BGM，用来探索节奏和旁白声线；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，避免每段素材自带不同音乐。

### 故事脚本：雨停以前写给你的信

夏末的雨天，28 岁的林夏回到即将拆除的旧高中。她收到一封没有寄出的信，信封上只有一句话：“雨停以前，去旧图书馆第三排。”她以为这是同学会的恶作剧，却在校门口屋檐下看见一只十年前用过的透明伞，伞柄上仍有她高中时写下的蓝色名字。

林夏沿着旧校舍往里走。教室里还留着白纱窗帘，窗外雨声很轻。她想起 17 岁那年，自己坐在课桌前翻书，喜欢的少年青木从她身边经过，影子落在书页上，她的手指停在纸页中间，却没有回头。后来两人在图书馆同时伸手拿同一本书，青木把书推给她，里面夹着一张借书卡。借书卡背面写着：“如果毕业那天下雨，我在老槐树下等你。”

毕业那天真的下雨。林夏去了车站，没有去老槐树。青木也没有再提起那句话。十年后，林夏按照信封提示走到图书馆第三排，找到那本旧书，又从书里滑出一张褪色借书卡。卡背面多了一行字：“我把没寄出的信放在树洞里。”

傍晚雨停前，林夏撑着透明伞来到操场边的老槐树下。她从树洞里摸出发黄的信。信里没有告白，只有一张随身听贴纸和一句话：“那天你没有来，但我听见雨停了。”林夏把信放回伞下，远处传来单车铃声。她回头，只看见一个穿白衬衫的少年背影穿过湿漉漉的林荫路，像记忆最后一次经过她。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库：雨天旧高中、28 岁林夏、17 岁回忆中的少年青木、透明伞、旧图书馆、借书卡、树洞旧信、低饱和浅青雾蓝色调和轻柔回忆感 BGM。

```text
这是一次岩井俊二式日系青春回忆短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒风格测试视频，用于确定雨天旧高中、成年林夏、少年青木、
透明伞、旧图书馆、借书卡、树洞旧信、浅青雾蓝调、胶片颗粒和轻柔旁白气质。

视觉风格：岩井俊二风格，低饱和浅青与雾蓝调，柔和漫射自然光；
35mm 胶片颗粒，轻微柔焦，窗帘、雨幕、旧书、透明伞和树影形成大面积留白；
手持微晃，慢动作，浅景深，画面像被回忆和雨水过滤过。

声音风格：可以有轻柔、透明、带青春回忆感的钢琴或弦乐 BGM，
节奏克制，不要煽情；必须有一段低声、温柔、像读旧信的女声旁白。
环境声包含细雨、屋檐滴水、翻书声、远处单车铃声。

0-5 秒：极近距离特写，旧校舍木质屋檐下雨珠缓慢垂落，
背景绿叶虚化成浅青色光斑，透明伞柄挂在画面边缘。

5-10 秒：手持镜头缓慢向下，成年林夏站在屋檐下，
她穿浅色风衣，低头看一封没有寄出的旧信，雨光映在脸侧。
女声画外音：“有些信不是寄丢了，只是一直等到雨停。”

10-15 秒：焦点从旧信转到图书馆窗内，一个穿白衬衫的少年背影一闪而过，
画面轻微过曝，像回忆被雨水冲淡。

负向限制：不要现代商业校园写真，不要高饱和滤镜，不要字幕水印，
不要夸张哭戏，不要快节奏剪辑，不要新增无关学生人群。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 浅青雾蓝色调、雨幕柔光、胶片颗粒、柔焦、留白构图 | 统一后续所有镜头的回忆质感。 |
| 人物板 | 成年林夏的风衣、发型、神情；少年青木的白衬衫和背影 | 保持人物连续性，避免换脸换衣。 |
| 场景板 | 旧校门屋檐、教室窗帘、图书馆书架、老槐树、湿漉漉林荫路 | 支撑后续场景切换。 |
| 道具板 | 透明伞、旧信封、借书卡、旧书、随身听贴纸、树洞 | 锁定叙事物件。 |
| 声音板 | 细雨、屋檐滴水、翻书、脚步、单车铃、女声旁白 | 形成后期声音资产方向。 |
| 镜头板 | 雨珠特写、手部特写、窗帘空镜、缓慢转焦、背影远去 | 固定岩井式镜头语法。 |

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定成年林夏、少年青木的外貌、服装、站位和距离。
- 场景板：锁定旧高中、教室、图书馆、老槐树和雨后林荫路。
- 风格板：锁定低饱和浅青雾蓝、自然漫射光、柔焦和胶片颗粒。
- 道具板：锁定透明伞、旧信、借书卡、旧书和树洞。
- 声音板：锁定旁白声线、雨声、翻书声、单车铃和禁止随机 BGM。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

## 2 分钟短片分镜案例：雨停以前写给你的信

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| V1 | 成年林夏 | 画外音 | 有些信不是寄丢了，只是一直等到雨停。 | Prompt 1 | 建立旧信和雨天回忆。 |
| V2 | 成年林夏 | 内心独白 | 我十七岁那年，连回头看他一眼都不敢。 | Prompt 2 | 点出教室暗恋。 |
| D1 | 少年青木 | 当面说话 | 这本书，你先看。 | Prompt 3 | 用克制台词建立关系。 |
| V3 | 成年林夏 | 画外音 | 原来他把答案夹在我借过的书里。 | Prompt 4 | 揭示借书卡线索。 |
| V4 | 成年林夏 | 画外音 | 我没有去老槐树，所以那个夏天一直没有结束。 | Prompt 5 | 解释遗憾但保持诗意。 |
| D2 | 成年林夏 | 低声说话 | 对不起，我来晚了。 | Prompt 6 | 情绪转折。 |
| V5 | 成年林夏 | 画外音 | 信里没有告白，只有雨停以后的声音。 | Prompt 7 | 旧信揭示。 |
| V6 | 成年林夏 | 内心独白 | 我终于明白，有些人只会以背影回来。 | Prompt 8 | 收束主题。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：雨檐下的旧信

```text
段落时长：15 秒以内
全局风格：岩井俊二风格，日式青春回忆美学，低饱和浅青与雾蓝调；
柔和漫射自然光，35mm 胶片颗粒，轻微柔焦，浅景深；
手持微晃，慢动作，雨幕、窗帘、旧物和大面积留白承载情绪。

剧情任务：建立雨天旧高中、成年林夏、透明伞和没有寄出的旧信。
声音策略：只生成音效，禁止生成音乐；本段如有画外音，只按下方时间轴中的原句生成；环境声为屋檐滴水、细雨、远处校铃残响；不得随机新增台词、人声或背景音乐。
空间锚点：旧高中校门屋檐下，前景是木质屋檐雨珠，右侧挂着透明伞，成年林夏站在屋檐下偏左，旧校舍和湿绿树影在后景虚化。

0-5 秒：极近距离特写，固定镜头，澄澈雨珠从木质屋檐边缘缓慢垂落，透明伞柄在画面右侧虚化，背景浓郁绿叶形成柔和浅青散景。音效：屋檐滴水声，细密雨声。

5-10 秒：中近景，轻微手持镜头缓慢下移，成年林夏穿浅色风衣站在屋檐下偏左，身体面向雨幕，视线低垂看手中发黄信封；柔和漫射光从雨幕反射到她脸侧，表情平静但怅惘。成年林夏画外音：“有些信不是寄丢了，只是一直等到雨停。”音效：远处旧校铃残响，雨声持续。
```

## 从这些提示词学到的写法

### 1. 先写大师风格名，再写具体控制

弱写法：

```text
日系，青春，电影感，雨天，暗恋，温柔
```

强写法：

```text
岩井俊二风格，日式青春美学，低饱和浅青雾蓝调，
35mm 胶片颗粒，窗边漫射逆光，手持微晃，
少女指尖停在书页中间，不敢回头看少年。
```

### 2. 把情绪翻译成微动作

| 情绪 | prompt 动作 |
| --- | --- |
| 暗恋 | 手指停住、眼睫颤动、影子落在书本上 |
| 初遇 | 两只手同时伸向同一本书，指尖险些相触 |
| 遗憾 | 多年后回到树下，摸出发黄的信 |
| 回忆 | 雾化转场，年轻轮廓和成年轮廓渐渐重合 |
| 青春自由 | 双人骑行、奔跑抓拍、风吹乱头发 |

### 3. 用“光”和“旧物”代替解释

这条教程反复使用：

- 雨珠
- 书页
- 有线耳机
- 随身听/CD 播放器
- 透明雨伞
- 树洞
- 发黄的信
- 10 年前邮票
- 圆珠笔字

这些旧物不是装饰，而是让大模型生成“被时间浸过”的画面。

### 4. 秒级分镜比单条 prompt 更稳定

这条教程的提示词几乎都按秒拆分。未来制作类似短视频时，应使用：

```text
全局风格 prompt
-> 镜头 1：时长 + 景别/焦段 + 构图 + 光线 + 动作
-> 镜头 2：时长 + 景别/焦段 + 构图 + 光线 + 动作
-> 镜头 3：时长 + 景别/焦段 + 构图 + 光线 + 动作
-> 统一质感和负向限制
```

## Agent 使用规则

当用户要做“岩井俊二感”“日系青春片”“夏天暗恋”“毕业遗憾”“借一场微雨”“特定导演风格 AI 短视频”时，Agent 应先读取本页，然后输出：

1. 风格锚点：直接写出大师名和风格英文/中文标签。
2. 情绪命题：这条片到底是什么未说出口的情绪。
3. 旧物和场景：雨、书、耳机、树洞、信、伞、田野、教室等。
4. 全局风格 prompt。
5. 5-8 个秒级镜头 prompt。
6. 负向限制：不要高饱和、不要商业硬光、不要直接告白、不要现代写真质感。
