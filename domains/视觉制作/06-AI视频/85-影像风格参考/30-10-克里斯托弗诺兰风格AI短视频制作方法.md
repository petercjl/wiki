# 克里斯托弗诺兰风格AI短视频制作方法

## 风格锚点

克里斯托弗·诺兰风格适合“时间结构、宏大空间、实拍物理感、道德困境、精密叙事、IMAX 式沉浸”的 AI 短视频。可写为：

```text
受克里斯托弗·诺兰电影启发，宏大真实空间，实拍物理感，
非线性时间结构，冷峻写实光线，大画幅史诗构图，低沉紧张氛围。
```

## 适合的故事类型

- 时间循环、倒计时、记忆错位、任务倒计时。
- 个体选择与宏大空间/物理规则相连。
- 科幻、悬疑、战争、建筑、航天、深海等高概念短片。

不适合柔和日常生活流、复古童话、轻喜剧。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 结构 | 非线性、交叉剪辑、倒计时、多时间层并置 |
| 空间 | 巨大建筑、旷野、海面、机库、城市峡谷 |
| 质感 | 实拍、物理重量、少漂浮感，强调真实材质 |
| 色彩 | 冷峻自然色、低饱和、深阴影、金属灰 |
| 运镜 | 稳定、宏大、清晰，强调空间方向和物理运动 |
| 声音感 | 低频压力、时钟、机械、呼吸感可写入后期提示 |

## Prompt 写法

全局 prompt：

```text
受克里斯托弗·诺兰电影启发，大画幅史诗构图，真实外景和实拍物理感，
低饱和冷峻色彩，宏大空间尺度，稳定清晰的镜头运动，
非线性时间感和倒计时压力，严肃、沉浸、具有物理重量。
```

负向限制：

```text
不使用卡通科幻，不使用漂浮廉价特效，不使用赛博霓虹，不让空间方向混乱，不出现字幕水印。
```

## 如何调用通用分镜能力

诺兰风格要把 [[domains/视觉制作/06-AI视频/03-分镜脚本/25-01-故事大纲到AI视频分镜的拆解方法|故事拆镜]] 扩展为“多时间线镜头任务表”：现在、记忆、机械内部三个时间/空间层必须各自清楚。[[domains/视觉制作/06-AI视频/06-视频剪辑与连续性/25-镜头连续性与剪辑衔接|连续性]] 要靠倒计时、手部动作、机械齿轮和空间方向保持观众可理解。

| 通用能力 | 诺兰式落地 |
| --- | --- |
| 故事拆镜 | 宏大空间 -> 倒计时 -> 现实行动 -> 记忆插入 -> 机械内部 -> 动作匹配 -> 停止时间。 |
| 景别情绪 | 大画幅远景表现尺度，特写给倒计时、齿轮、手和笔记。 |
| 运镜选择 | 稳定推近、清晰横移、方向明确的空间行动，不制造无意义眩晕。 |
| 光色质感 | 低饱和冷灰、真实外景、金属质感、实拍物理重量。 |
| 人物动作 | 穿过大厅、翻笔记、沿钢梯移动、伸手按装置，动作要有物理阻力。 |
| 连续性 | 通过倒计时数字、钟楼结构、父亲笔记和手部匹配剪辑连接多时间线。 |

## 范例-两阶段工作流：先抽卡，再固化资产

诺兰风格 AI 短视频要先让时间压力、空间方向和情感锚点成立，再用开放性抽卡确定钟楼、建筑师、倒计时、父亲记忆、齿轮装置和低频压力，最后把故事拆成物理行动明确的镜头组。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入符合克里斯托弗诺兰气质的 BGM，用来探索节奏、情绪和声音方向；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，避免每段素材自带不同音乐。

### 故事脚本：倒走的钟楼

城市旧钟楼将在中午 12 点爆破拆除。建筑师陆明被临时叫回现场，因为钟楼内部出现反向运转的机械异常。广播倒计时只剩两分钟，他穿过封锁线和空荡大厅，发现这套装置不是施工队留下的，而像是父亲年轻时的设计。

陆明的父亲曾是钟楼维修工。童年时，父亲带他上过钟楼顶层，给过他一块旧怀表，说时间不是一条直线。多年后父亲去世，陆明一直以为那只是哄孩子的话。现在，机械层的齿轮逆向咬合，父亲笔记里画着完整的钟楼剖面图，怀表指针与图纸箭头方向相反。

陆明沿钢梯爬向顶层停止装置，爆破倒计时不断压缩。最后一刻，他按下金属按钮，童年记忆中父亲松开他手的动作与现在的手部动作匹配。钟面指针轻微倒退一格，爆破停止。钟楼没有倒塌，陆明站在楼顶边缘，第一次理解父亲留下的不是机关，而是让他选择保留记忆的机会。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库。

```text
这是一次克里斯托弗·诺兰式时间悬疑短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒视频，用于确定大画幅钟楼空间、建筑师陆明、机械倒计时器、齿轮质感、父亲记忆线、低频倒计时音乐和真实机械声。

视觉风格：大画幅史诗构图，真实外景和实拍物理感；低饱和冷灰色，宏大空间尺度，稳定清晰的镜头运动；非线性时间感和倒计时压力，严肃、沉浸、具有物理重量。

声音风格：必须有低频、脉冲式、倒计时压力感的 BGM，像时钟、机械、呼吸和远处警报叠在一起；环境声包括倒计时广播、齿轮转动、金属震动、脚步回声。

0-5 秒：清晨旧钟楼远景，封锁线、工程车辆、空旷广场，建筑师站在广场边缘显得很小。

5-10 秒：机械倒计时器特写，数字从 02:00 跳到 01:59，金属齿轮真实运转，低频压力加强。

10-15 秒：建筑师穿过巨大大厅，画面短暂插入童年记忆中父亲把怀表放进男孩手里。

负向限制：不要卡通科幻，不要漂浮廉价特效，不要赛博霓虹，不要空间方向混乱，不要字幕水印，不要夸张爆炸场面。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 大画幅、低饱和冷灰、真实建筑、物理重量 | 固定诺兰式现实质感。 |
| 人物板 | 陆明外貌、服装、行动阻力；童年男孩和父亲 | 保持多时间线人物一致。 |
| 场景板 | 钟楼外景、大厅、机械内部、顶层钢梯、楼顶 | 维持空间方向清楚。 |
| 道具板 | 倒计时器、怀表、父亲笔记、停止装置、齿轮 | 锁定时间结构物件。 |
| 声音板 | 低频压力、倒计时广播、齿轮声、脚步回声、警报声 | 形成时间压力。 |
| 镜头板 | 稳定推近、机械特写、宏大远景、手部匹配剪辑 | 固定非线性叙事语法。 |

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定主要角色的外貌、服装、年龄感、动作习惯和关系距离。
- 场景板：锁定主要空间的结构、光线方向、时代质感和可反复出现的空间锚点。
- 风格板：锁定该导演对应的光色、镜头距离、构图习惯、运镜方式和节奏。
- 道具板：锁定推动剧情的关键物件，确保每段生成时不会随机替换。
- 声音板：锁定对白声线、环境声、动作音效和禁止随机 BGM 的生产规则。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

## 2 分钟短片分镜案例：倒走的钟楼

城市钟楼将在 12 点爆破拆除。建筑师发现父亲曾在钟楼里留下反向运行的机械装置，必须在倒计时结束前做出选择。

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| V1 | 倒计时广播 | 画外音 | 爆破倒计时，两分钟。 | Prompt 1 | 建立时间压力。 |
| D1 | 父亲 | 记忆中说话 | 记住，时间不是一条直线。 | Prompt 4 | 建立父亲主题。 |
| D2 | 陆明 | 当面低声 | 是你留下的。 | Prompt 6 | 认出父亲笔记。 |
| V2 | 倒计时广播 | 画外音 | 四十七秒。 | Prompt 6 | 压缩时间。 |
| D3 | 父亲 | 记忆中说话 | 放手的时候，才知道它还在走。 | Prompt 8 | 手部匹配剪辑。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：钟楼和封锁线

```text
段落时长：15 秒以内
全局风格：克里斯托弗·诺兰风格，大画幅史诗构图，真实外景和实拍物理感；低饱和冷灰色，宏大空间尺度，稳定清晰的镜头运动；非线性时间感和倒计时压力，严肃、沉浸、具有物理重量。

剧情任务：建立旧钟楼、封锁线、工程车辆和两分钟爆破倒计时。
声音策略：只生成音效，禁止生成音乐；无对白；环境声来自本场景真实动作；不得随机新增台词、人声或背景音乐。
空间锚点：清晨城市中心旧钟楼远景，封锁线和工程车辆围绕广场，陆明站在广场边缘仰望钟楼。

0-5 秒：中远景，固定镜头或受控缓慢运动，角色位于画面稳定构图中，视线朝向关键道具或空间出口；画面交代钟楼和封锁线的空间关系、光线方向和时代质感。 音效：空间底噪，远处环境声。

5-10 秒：中近景，镜头保持克制，人物完成一个明确动作，表情不夸张，构图让关键道具位于画面中心； 音效：道具轻响，脚步或衣料摩擦声。

10-15 秒：反应镜头或空镜，固定镜头，角色动作结束后留下停顿，空间、道具和光影继续承载情绪，作为下一段的剪辑出口。 音效：环境声延续，动作尾音渐弱。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止卡通科幻，禁止漂浮廉价特效，禁止赛博霓虹，禁止空间方向混乱，禁止字幕水印；禁止随机添加长篇科幻解释、人声或背景音乐。
```

#### Prompt 4：顶楼童年记忆

```text
段落时长：15 秒以内
全局风格：克里斯托弗·诺兰风格，大画幅史诗构图，真实外景和实拍物理感；低饱和冷灰色，宏大空间尺度，稳定清晰的镜头运动；非线性时间感和倒计时压力，严肃、沉浸、具有物理重量。

剧情任务：插入童年记忆，父亲讲出时间主题并交出怀表。
```
