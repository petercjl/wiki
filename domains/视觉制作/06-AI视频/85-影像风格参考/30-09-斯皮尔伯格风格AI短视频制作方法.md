# 斯皮尔伯格风格AI短视频制作方法

## 风格锚点

斯皮尔伯格风格适合“儿童视角、家庭情感、奇观与情绪结合、温暖逆光、流畅场面调度、惊奇感”的 AI 短视频。可写为：

```text
受斯皮尔伯格冒险家庭片启发，温暖逆光，儿童视角，流畅场面调度，
人物视线引导奇观揭示，镜头运动自然服务情感，明亮而有惊奇感。
```

## 适合的故事类型

- 孩子发现秘密、家庭重聚、冒险、奇观第一次出现。
- 产品/品牌希望传递希望、亲情、勇气、童年记忆。
- 需要“先看人物反应，再揭示奇观”的结构。

不适合冷峻心理惊悚、纯写实县城纪实、极简静态家庭片。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 构图 | 人物关系清楚，群像调度流畅 |
| 光线 | 温暖逆光、轮廓光、烟尘/空气中的光束 |
| 运镜 | 流畅跟随、推近、环绕、oner 式连续调度 |
| 情绪 | 惊奇、亲情、恐惧后转向希望 |
| 叙事 | 人物反应先于奇观，观众跟随视线发现 |
| 景别 | 从中景关系过渡到仰视奇观或特写反应 |

## Prompt 写法

全局 prompt：

```text
受斯皮尔伯格冒险家庭片启发，温暖逆光和柔和轮廓光，
儿童视角，流畅连续场面调度，人物视线引导奇观揭示，
镜头运动自然、情感真诚，画面明亮、宽阔、有惊奇感。
```

负向限制：

```text
不使用阴暗恐怖风，不使用冷峻工业色调，不使用过度手持晃动，不出现字幕水印，不让奇观遮住人物情绪。
```

## 如何调用通用分镜能力

斯皮尔伯格风格要把 [[domains/视觉制作/06-AI视频/03-分镜脚本/25-04-运镜选择方法|运镜选择]] 和人物视线绑定：先拍人物看见什么，再揭示奇观。[[domains/视觉制作/06-AI视频/03-分镜脚本/25-03-景别与情绪表达|景别]] 要从儿童视角的中景/低机位，逐渐打开到仰拍或远景奇观。

| 通用能力 | 斯皮尔伯格式落地 |
| --- | --- |
| 故事拆镜 | 儿童探索 -> 发现物件 -> 成人加入 -> 反应先行 -> 奇观揭示 -> 情感收束。 |
| 景别情绪 | 儿童低机位、中近景反应、仰拍奇观、远景家庭余味。 |
| 运镜选择 | 流畅跟随、自然推近、视线引导、轻微环绕，运动服务情感。 |
| 光色质感 | 温暖逆光、尘埃光束、月光和台灯混合，明亮但不刺眼。 |
| 人物动作 | 抬头、拉阁楼梯、共同看星图、并肩坐下，比奇观本身更重要。 |
| 连续性 | 用星图、阁楼、父子视线和同一光源维持情绪递进。 |

## 范例-两阶段工作流：先抽卡，再固化资产

斯皮尔伯格风格 AI 短视频要先让家庭矛盾和儿童视角成立，再用开放性抽卡确定阁楼、纸箱、父亲、男孩、手绘星图、月光投影和温暖奇观，最后把发现过程拆成流畅场面调度。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入符合斯皮尔伯格气质的 BGM，用来探索节奏、情绪和声音方向；正式分段素材生成时必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。整片 BGM 应在剪辑完成后统一制作，避免每段素材自带不同音乐。

### 故事脚本：阁楼里的星图

搬家前夜，男孩诺诺不愿把旧房子里的东西装箱。他和父亲最近总是沉默：父亲忙着搬家、签文件，诺诺觉得父亲只想尽快离开。停电前，他在客厅纸箱之间发现一根垂下来的阁楼拉绳，趁父亲在楼下找手电时爬上阁楼。

阁楼里堆着旧箱子、玩具和落灰的纸板。诺诺在箱底找到一张手绘星图，边缘有胶带和父亲年轻时写下的名字。他这才知道父亲小时候也在这间阁楼里幻想过宇宙。父亲爬上阁楼，看到星图后愣住，说他以为它早就不见了。

停电让房间暗下来，月光从小窗照进星图。星图在屋顶投出银河般的光点。父亲和诺诺没有急着解释搬家的事，而是并肩坐下，一起看那张曾属于父亲、现在又属于儿子的夜空。楼下纸箱还在，搬家不会取消，但他们重新找回了共同看向同一个地方的能力。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是正式分镜，而是“预告片式风格测试片”。它把故事中最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库。

```text
这是一次斯皮尔伯格式家庭奇观短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒视频，用于确定儿童视角、搬家纸箱、阁楼、父亲、男孩、手绘星图、月光投影、温暖逆光和亲子修复气质。

视觉风格：受斯皮尔伯格家庭冒险片启发，儿童视角，温暖逆光，流畅场面调度，先拍人物反应再揭示奇观；纸箱、拉绳、木梯、尘埃、月光和星光投影形成温暖惊奇。

声音风格：可以有温暖、轻微冒险感的管弦/钢琴 BGM；环境声包括纸箱摩擦、木梯落下、停电声、夜晚风声和父子低声对白。

0-5 秒：低机位跟随男孩穿过纸箱迷宫，温暖台灯逆光照出尘埃。

5-10 秒：男孩拉下阁楼梯，父亲在楼下画外音说：“你在上面吗？”

10-15 秒：月光照到手绘星图，男孩和父亲的脸被星光点亮，奇观先从他们的眼睛里出现。

负向限制：不要阴暗恐怖风，不要冷峻工业色调，不要过度手持晃动，不要字幕水印，不让奇观遮住人物情绪。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 温暖逆光、儿童视角、奇观揭示、家庭冒险感 | 统一斯皮尔伯格式情绪。 |
| 人物板 | 诺诺的年龄、睡衣/家居服、好奇表情；父亲疲惫但温柔 | 保持亲子关系连续。 |
| 场景板 | 搬家客厅、纸箱迷宫、阁楼、旧箱子、月光小窗 | 形成探索路径。 |
| 道具板 | 阁楼拉绳、木梯、手绘星图、旧胶带、纸箱、手电 | 锁定奇观触发物。 |
| 声音板 | 纸箱声、木梯声、停电声、夜风、父子短对白、星光轻鸣 | 形成温暖冒险声音。 |
| 镜头板 | 低机位跟拍、反应镜头、仰拍揭示、流畅调度、背影并坐 | 固定奇观揭示语法。 |

### 阶段三：进入完整视听分镜

当资产被固化后，再进入完整视听分镜 prompt。此时不再依赖模型自由发挥，而是使用：

- 人物板：锁定主要角色的外貌、服装、年龄感、动作习惯和关系距离。
- 场景板：锁定主要空间的结构、光线方向、时代质感和可反复出现的空间锚点。
- 风格板：锁定该导演对应的光色、镜头距离、构图习惯、运镜方式和节奏。
- 道具板：锁定推动剧情的关键物件，确保每段生成时不会随机替换。
- 声音板：锁定对白声线、环境声、动作音效和禁止随机 BGM 的生产规则。
- 完整视听分镜：锁定剧情、台词、空间锚点、连续性和负向限制。

## 2 分钟短片分镜案例：阁楼里的星图

搬家前夜，男孩在阁楼发现父亲童年的手绘星图。停电后，月光让星图在屋顶投出银河，父子在奇观中重新靠近。

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| D1 | 父亲 | 画外音 | 你在上面吗？ | Prompt 3 | 父亲介入。 |
| D2 | 诺诺 | 当面低声 | 爸爸，这是你画的吗？ | Prompt 5 | 发现父亲童年。 |
| D3 | 父亲 | 当面低声 | 我以为它早就不见了。 | Prompt 5 | 父亲被记忆触动。 |
| D4 | 诺诺 | 当面低声 | 它在发光。 | Prompt 6 | 奇观前反应。 |
| D5 | 父亲 | 当面低声 | 那我们就再看一次。 | Prompt 8 | 温柔收束。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：搬家前夜的拉绳

```text
段落时长：15 秒以内
全局风格：斯皮尔伯格风格，儿童视角，温暖逆光，流畅场面调度，家庭冒险感；先拍人物反应再揭示奇观，纸箱、木梯、月光、尘埃和星光投影服务亲子情绪。

剧情任务：建立搬家前夜、纸箱和垂下来的阁楼拉绳，让儿童探索开始。
声音策略：只生成音效，禁止生成音乐；无对白；环境声来自本场景真实动作；不得随机新增台词、人声或背景音乐。
空间锚点：客厅低机位，纸箱堆在前景和两侧，阁楼拉绳从天花板垂下，诺诺站在画面下方抬头。

0-5 秒：中远景，固定镜头或受控缓慢运动，角色位于画面稳定构图中，视线朝向关键道具或空间出口；画面交代搬家前夜的拉绳的空间关系、光线方向和时代质感。 音效：空间底噪，远处环境声。

5-10 秒：中近景，镜头保持克制，人物完成一个明确动作，表情不夸张，构图让关键道具位于画面中心； 音效：道具轻响，脚步或衣料摩擦声。

10-15 秒：反应镜头或空镜，固定镜头，角色动作结束后留下停顿，空间、道具和光影继续承载情绪，作为下一段的剪辑出口。 音效：环境声延续，动作尾音渐弱。

连续性：保持本段人物服装、道具位置、空间方向和上一段情绪状态一致；为下一段保留清楚剪辑出口。
负向限制：禁止阴暗恐怖风，禁止冷峻工业色调，禁止过度手持晃动，禁止字幕水印；禁止让奇观遮住人物情绪，禁止随机添加背景音乐或无关人声。
```
