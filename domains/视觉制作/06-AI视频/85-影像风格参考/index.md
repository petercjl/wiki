# AI短视频影像风格参考

影像风格用于补充已经明确的故事和镜头任务，不替代剧本、导演和分镜判断。风格页中的 Prompt、案例和镜头结构在本轮全部保留。

## 使用顺序

```text
故事命题与导演任务
→ 选择与任务匹配的风格语法
→ 提取可见的构图、光色、运动、节奏和质感特征
→ 进入图片/视频 Prompt
→ 检查风格是否压过人物、产品与叙事
```

不要只写导演姓名或“电影感”。只有能转成可见、可执行、可验收字段的风格知识才进入生成阶段。
