# 韦斯安德森风格AI短视频制作方法

## 风格锚点

韦斯·安德森风格适合“秩序感、怪诞童话、章节化叙事、复古物件、对称构图、精确横移”的 AI 短视频。内部研究可用导演名；商业 prompt 可改为：

```text
复古童话式对称构图，中央轴线，粉彩高饱和配色，精确横移镜头，舞台式场面调度，手工模型感和章节标题感。
```

## 适合的故事类型

- 小镇、旅馆、图书馆、邮局、博物馆、学校等秩序空间。
- 怪诞但温柔的人物关系。
- 章节式、清单式、任务式叙事。
- 适合产品展示、人物介绍、轻喜剧、复古品牌片。

不适合写实悲剧、混乱手持纪实、黑暗压迫惊悚。

## 视觉 DNA

| 维度 | 特征 |
| --- | --- |
| 构图 | 严格正面、中心构图、对称、平面化空间 |
| 色彩 | 粉彩、姜黄、红、湖蓝、薄荷绿、复古暖色 |
| 美术 | 微缩模型感、手工道具、标签、制服、整齐陈列 |
| 运镜 | 水平横移、垂直俯拍、快速推近、机械精确 |
| 叙事 | 章节感、旁白感、人物像收藏盒里的标本 |
| 表演 | 克制、面向镜头、轻微荒诞、节奏干脆 |

## Prompt 写法

全局 prompt：

```text
复古童话式对称构图，中央轴线，粉彩高饱和配色，
舞台布景般的平面空间，精确水平横移和正面固定镜头，
人物动作克制，手工道具和整齐陈列，轻喜剧般的怪诞秩序。
```

负向限制：

```text
不使用手持晃动，不使用阴暗脏乱写实风，不出现赛博霓虹，不出现自然主义凌乱构图，不出现字幕水印。
```

## 如何调用通用分镜能力

韦斯·安德森风格要把 [[domains/视觉制作/06-AI视频/03-分镜脚本/25-01-故事大纲到AI视频分镜的拆解方法|故事拆镜]] 改造成“秩序被一个异常物件打破，再被带着情绪修复”的任务链。每个镜头都要用 [[domains/视觉制作/06-AI视频/03-分镜脚本/25-02-AI视频镜头字段标准|镜头字段]] 锁定中央轴线、对称构图、色彩格子、精确横移和道具陈列。

| 通用能力 | 韦斯·安德森式落地 |
| --- | --- |
| 故事拆镜 | 建立秩序 -> 出现异常物件 -> 清单式寻找 -> 发现回忆 -> 恢复秩序。 |
| 景别情绪 | 正面远景和中景建立舞台；俯拍用于物件清单和档案感。 |
| 运镜选择 | 固定正面、快速推近、精确水平横移，避免手持和自然主义游移。 |
| 光色质感 | 粉彩高饱和、复古暖色、手工道具、平面化空间。 |
| 人物动作 | 面无表情、机械整理、同步摇头、偏离中心轴线半步。 |
| 连续性 | 用同一抽屉编号、同一色彩系统、同一中央构图维持风格统一。 |

## 范例-两阶段工作流：先抽卡，再固化资产

导演风格 AI 短视频不是从分镜直接开始，而是先有完整故事脚本，再用导演风格抽卡确定人物、场景和美术系统，最后把故事脚本拆成可生成的分段分镜脚本。故事脚本回答“发生了什么”，开放性风格抽卡回答“这个故事世界长什么样、听起来是什么气质”，分镜脚本回答“每 15 秒怎么拍、谁说什么、有什么声音”。

声音边界要分阶段处理：开放性风格抽卡阶段可以加入导演气质相近的 BGM，用来探索声音风格、节奏感和旁白质感；进入正式分段素材生成后，必须只生成对白、旁白、环境声和动作音效，禁止生成音乐。后期剪辑时再统一铺设整片 BGM，避免 8 段素材各自带不同音乐导致无法顺畅拼接。

### 故事脚本：失物招领处第 17 号抽屉

小镇火车站有一间失物招领处，墙上整齐排列着 72 个粉彩抽屉。失物招领员艾略特每天早上 8 点整打开柜台灯，把雨伞、钥匙、围巾、车票按颜色、尺寸和字母顺序归档。他相信，只要每件失物都有正确编号，世界就不会真的乱掉。

这天早上，艾略特发现第 17 号抽屉里多出一只红色儿童手套。登记簿上没有这只手套，车站当天也没有小孩报失。按照规则，未知失物必须在当日归还主人；如果无人认领，就要贴上“UNCLAIMED”标签，放进地下档案室。艾略特不喜欢“无人认领”这个词，因为它听起来像一个人被世界漏掉。

艾略特拿着红手套去站台询问三个人：邮递员、花店女孩和老列车员。三个人都不是主人，却都记得很多年前有个小男孩在大雪天丢过一只红手套。老列车员提醒艾略特去查旧登记簿。艾略特回到柜台，把一本泛黄登记簿打开，发现夹层里有一张旧车票，日期正是他小时候被送离小镇的那一天。车票背面写着一个孩子的名字：Elliot。

艾略特打开抽屉墙最底层的旧档案抽屉，里面整齐放着一张童年照片、一枚小火车模型和另一只红手套。他终于明白，第 17 号抽屉不是在保管别人的失物，而是在等他找回自己。艾略特把两只红手套并排放回第 17 号抽屉，没有贴“UNCLAIMED”，而是贴上一张红色标签：FOUND。第二天早上，失物招领处照常开门，墙上的抽屉依然整齐，但艾略特第一次把柜台上的“失物登记簿”改名为“找回登记簿”。

### 阶段一：开放性风格抽卡

开放抽卡 prompt 不是第一个正式分镜，而是一支“预告片式风格测试片”。它可以把故事里最重要的人物、场景、道具和声音气质压缩到 15 秒内，用来确定后续资产库：失物招领空间、艾略特的制服与脸、抽屉墙、17 号抽屉、红色手套、旁白声线和复古 BGM。抽卡结果满意后，再把这些元素固化为后续所有分段素材的参考。

```text
这是一次韦斯·安德森式复古童话短片的预告片式视觉与声音概念抽卡，不是最终成片。
目标是生成一段 15 秒风格测试视频，用于确定小镇火车站失物招领处、失物招领员艾略特、
粉彩抽屉墙、第 17 号抽屉、红色儿童手套、复古旁白声线和轻快怪诞的背景音乐方向。

视觉风格：复古小镇火车站失物招领处，中央轴线，严格正面对称构图；
粉彩高饱和配色，姜黄、薄荷绿、粉红、湖蓝；
舞台布景般的平面空间，手工道具，固定正面镜头和精确水平横移。

人物与道具：失物招领员艾略特穿粉彩制服、圆框眼镜、表情克制；
一整面彩色抽屉墙上有清晰编号，第 17 号抽屉是核心视觉锚点；
红色儿童手套必须出现，并且要被呈现为故事的异常物件。

声音风格：必须有轻快但克制的复古童话配乐，
木琴、拨弦、手风琴或轻微室内乐质感，节奏像钟表一样规整；
必须有一段冷静、干巴巴、像童话书旁白的男声画外音。
环境声包含火车站钟声、抽屉轻响、纸标签摩擦声。

0-5 秒：正面对称远景，复古火车站失物招领处像舞台布景一样展开，
中央柜台、彩色抽屉墙和墙上钟表都落在中央轴线上。

5-10 秒：失物招领员穿粉彩制服，站在中心轴线上，
面无表情地整理雨伞、钥匙、车票和标签，动作机械精准。
男声画外音：“在第 17 号抽屉打开以前，小镇上没有任何东西真正丢失。”

10-15 秒：极正面特写，第 17 号抽屉被拉开，
里面是一只红色儿童手套，画面完全对称，配乐保持轻快但略带怪诞。

负向限制：不要自然主义凌乱构图，不要手持晃动，不要阴暗现实主义，
不要赛博霓虹，不要字幕水印，不要现代大型车站。
```

### 阶段二：从满意抽卡视频提取资产

| 资产 | 从抽卡视频中提取什么 | 后续用途 |
| --- | --- | --- |
| 风格板 | 粉彩色卡、中央构图、舞台布景、道具陈列方式 | 统一后续所有镜头的美术秩序。 |
| 人物板 | 失物招领员制服、圆框眼镜、表情、站姿 | 固定主角形象和动作节奏。 |
| 场景板 | 抽屉墙、柜台、站台、公告栏、旧登记簿桌面 | 支撑后续场景切换。 |
| 道具板 | 第 17 号抽屉、红色儿童手套、车票、登记簿、FOUND 标签 | 锁定叙事物件。 |
| 声音板 | 复古童话配乐、旁白男声、钟声、抽屉声、纸张声 | 形成声音资产方向。 |
| 镜头板 | 正面固定、俯拍网格、水平横移、快速正面推近 | 固定韦斯式镜头语法。 |

## 2 分钟短片分镜案例：失物招领处第 17 号抽屉

### 完整视听分镜 Prompt 结构

Seedance 2.0 单次生成建议控制在 15 秒内。这个故事按 8 个独立素材段落生成，每段都要写清声音策略、空间锚点、连续性和负向限制。正式分段素材的声音策略统一为：只生成音效，禁止生成音乐；可以生成明确指定的当面对白、内心独白或画外旁白；不得随机新增台词、人声或背景音乐。

每个时间块必须写成镜头级完整句：`0-X 秒：景别，运镜/固定镜头，角色站位与视线关系，详细画面内容，包括人物动作、表情、情绪、构图、光影。角色名说/内心独白/画外音：“原台词”。音效：具体音效。` 如果是反应镜头、细节镜头或空镜，要在景别后直接标注。

#### 台词与旁白总表

| 编号 | 人物 | 声音类型 | 文本 | 出现段落 | 叙事功能 |
| --- | --- | --- | --- | --- | --- |
| V1 | 旁白男声 | 画外音 | 第 17 号抽屉，是全镇唯一从不丢东西的地方。 | Prompt 1 | 建立怪诞童话规则。 |
| V2 | 旁白男声 | 画外音 | 他按照颜色整理世界，直到红色拒绝归档。 | Prompt 2 | 说明秩序被打破。 |
| D1 | 失物招领员 | 当面说话 | 这不是本站登记的红色。 | Prompt 3 | 用干巴巴台词表达异常。 |
| V3 | 旁白男声 | 画外音 | 他问了三个人，三个人都把头摇成同一个角度。 | Prompt 4 | 强化清单式寻找。 |
| V4 | 旁白男声 | 画外音 | 日期比手套更早认出了他。 | Prompt 5 | 引入童年记忆。 |
| D2 | 失物招领员 | 低声说话 | 我好像把自己弄丢过。 | Prompt 6 | 情绪转折。 |
| V5 | 旁白男声 | 画外音 | 他没有找到失主，只找回了一个很久以前的自己。 | Prompt 7 | 解释归档动作的情绪意义。 |
| V6 | 旁白男声 | 画外音 | 从那天起，FOUND 不再只是一个标签。 | Prompt 8 | 收束主题。 |

以下每个 Prompt 都已经内嵌全局风格、完整声音策略和负向限制；对白/旁白只出现在具体发生的时间轴镜头中，可以单独复制到视频生成模型中使用，不需要再拼接外部字段或查表。

#### Prompt 1：失物招领处开场

```text
段落时长：15 秒以内
全局风格：复古童话式对称构图，中央轴线，粉彩高饱和配色；
舞台布景般的平面空间，精确水平横移和正面固定镜头；
人物动作克制，手工道具和整齐陈列，轻喜剧般的怪诞秩序。

剧情任务：建立失物招领处的对称秩序和第 17 号抽屉。
声音策略：只生成音效，禁止生成音乐；旁白是冷静、干巴巴、像童话书朗读的男声；本段如有旁白，只按下方时间轴中的原句生成；环境声为钟声和抽屉墙轻响；不得随机新增台词、人声或背景音乐。
空间锚点：复古小镇火车站失物招领处，柜台在画面中央，
背后是一整面彩色抽屉墙，失物招领员站在中心轴线上面对镜头。

0-5 秒：远景，固定正面镜头，失物招领员艾略特站在柜台后方中心轴线上，身体正对镜头，视线平静看向前方；柜台位于画面中央，背后一整面彩色抽屉墙形成严格对称构图，姜黄、薄荷绿、粉红与湖蓝构成整齐色块，柔和复古暖光均匀照亮空间。音效：远处火车站钟声，抽屉墙轻微木质响动。

5-10 秒：中景，固定正面镜头，艾略特仍站在中心轴线上，双手平放在柜台边缘，眼睛直视镜头但表情克制；柜台左右两侧各摆一摞标签纸和一枚黄铜铃，画面像舞台开幕一样整齐。音效：黄铜铃轻轻振动，远处列车低鸣。

10-15 秒：细节镜头，快速正面推近，第 17 号抽屉位于画面中央偏下，艾略特的身体留在远处虚化中心，视线仍朝向抽屉墙；抽屉编号被柔光照亮，周围抽屉保持粉彩对称排列。旁白男声画外音：“第 17 号抽屉，是全镇唯一从不丢东西的地方。”音效：墙上钟表跳秒声，纸标签轻微摩擦声。

连续性：保持抽屉墙、中心轴线、粉彩色卡和失物招领员制服。
负向限制：不使用手持晃动，不使用阴暗脏乱写实风，
不出现赛博霓虹，不出现自然主义凌乱构图，不出现字幕水印；
不随机添加台词，不改变第 17 号抽屉和红色手套的叙事功能；
禁止现代候车大厅；禁止随机人物进入柜台前景。
```

#### Prompt 2：失物按颜色归档

```text
段落时长：15 秒以内
全局风格：复古童话式对称构图，中央轴线，粉彩高饱和配色；
舞台布景般的平面空间，精确水平横移和正面固定镜头；
人物动作克制，手工道具和整齐陈列，轻喜剧般的怪诞秩序。

剧情任务：展示主角按颜色整理世界的规则，红色手套成为异常。
声音策略：只生成音效，禁止生成音乐；旁白是冷静、干巴巴、像童话书朗读的男声；本段如有旁白，只按下方时间轴中的原句生成；音效为标签纸摩擦和物件轻放声；不得随机新增台词、人声或背景音乐。
空间锚点：失物招领处柜台桌面，俯拍角度，
桌面物件按颜色排成网格，主角双手从画面下方进入整理物件。

0-5 秒：俯拍全景，固定镜头，艾略特的双手从画面下方进入，身体不入镜但动作沿桌面中心线展开；蓝色雨伞、黄色钥匙扣、绿色围巾、红色儿童手套按颜色排列成精确网格，桌面灯光柔和均匀，阴影短而整齐。音效：标签纸摩擦声，物件被轻放到木桌上的细小声响。

5-10 秒：细节镜头，固定俯拍，艾略特左手用尺子对齐标签，右手把每件物品推到格线内，手指动作机械精准；红色儿童手套被推到最右下格时稍微偏出一毫米，画面秩序被微弱破坏。音效：尺子轻碰桌面声，布料摩擦声。

10-15 秒：中近景，固定正面镜头，艾略特站在柜台后方中心轴线上，低头看向桌面右下角的红色手套，表情仍然平静但眉毛轻微收紧；前景桌面物件整齐到近乎荒诞，红色手套在粉彩环境里格外醒目。旁白男声画外音：“他按照颜色整理世界，直到红色拒绝归档。”音效：最后一枚标签被按平的纸张声，钟表跳秒声。

连续性：红色儿童手套成为后续关键物件，不能变成成人手套或围巾。
负向限制：不使用手持晃动，不使用阴暗脏乱写实风，
不出现赛博霓虹，不出现自然主义凌乱构图，不出现字幕水印；
不随机添加台词，不改变第 17 号抽屉和红色手套的叙事功能；
```
