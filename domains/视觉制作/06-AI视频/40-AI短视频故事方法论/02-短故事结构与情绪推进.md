# 短故事结构与情绪推进

## 问题定义

短视频故事不是长片三幕剧的压缩摘要，而是一条高密度情绪因果链。观众需要在很短时间内知道：原本怎样，发生了什么，因此人物做了什么，最后留下什么变化。

Cowgill 强调短片必须用有限动作触达观众情绪；McDonald 的七步故事模板提醒每一步都应由“because of this”推进；Alessandra 的结构工具适合把这种推进变成可执行的表格。

## 核心模型

```text
平衡状态
-> 触发事件
-> 因果推进
-> 情绪/行动转折
-> 结果
-> 余味
```

压缩到产品短视频里，就是：

```text
进入处境
-> 暴露缺口
-> 关键行动
-> 变化可见
-> 命题收束
```

## 时长结构

| 时长 | 结构 | 镜头数量 | 适合内容 |
| --- | --- | --- | --- |
| 15 秒 | 一个视觉问题 + 一个关键动作 + 一个记忆点 | 3-5 | 单卖点、风格测试、投放素材 |
| 30 秒 | 处境、缺口、产品/行动、结果 | 5-8 | 标准产品广告、生活方式短片 |
| 60 秒 | 人物状态、阻碍升级、转折、余味 | 8-12 | 情绪软广、节日片、品牌短片 |
| 2 分钟 | 开端、发展、高潮/转折、余味 | 10-18 | 完整剧情短片、世界观预告、导演风格样片 |

越短越要选一个代表性瞬间，不要交代完整背景。15 秒可以只拍“一个人终于做出一个选择”；60 秒才适合加入前因和余味。

## 七步短故事压缩

| McDonald 七步 | 短视频转译 | 产品广告写法 |
| --- | --- | --- |
| Once upon a time | 原本的生活秩序 | 用户现在怎样生活 |
| And every day | 重复的压力/习惯 | 问题长期存在 |
| Until one day | 触发事件 | 某个瞬间让缺口被看见 |
| Because of this | 第一次行动 | 人物尝试解决 |
| Because of this | 阻碍升级或认知变化 | 产品/关系/世界规则介入 |
| Until finally | 关键选择 | 人物做出可见动作 |
| Ever since that day | 新状态 | 产品价值和情绪落点 |

## 情绪推进

情绪不是越来越煽情，而是越来越具体：

```text
处境压力
-> 观众认出自己
-> 人物有一个小动作
-> 动作暴露真实愿望
-> 产品或主题成为答案
-> 观众替人物松一口气
```

| 情绪阶段 | 画面证据 |
| --- | --- |
| 压力 | 消息、截止时间、拥挤空间、冷光、身体收紧 |
| 缺口 | 空座位、未完成动作、旧物、视线落空 |
| 觉察 | 人物停顿、回看、放下手中事 |
| 选择 | 拿起、递出、打开、靠近、转身 |
| 余味 | 呼吸、静止、空镜、物件再次出现 |

## 结构质检

- 开头 3 秒是否提出视觉问题，而不是只铺氛围？
- 观众是否每 3-8 秒获得新信息？
- 中段是否有阻碍或反差，而不是一路展示？
- 转折是否由动作完成，而不是旁白宣布？
- 结尾是否回应开头的物件、动作或问题？
- 片子是否只有一个主要情绪方向？如果同时想燃、治愈、搞笑和高级，通常会散。

## Agent 使用提示

在分镜前先生成“段落结构表”：

```text
目标时长：
进入处境：
暴露缺口：
关键行动：
变化可见：
命题收束：
每段的视觉事件：
每段的声音/台词边界：
```
