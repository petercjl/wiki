# 故事方向分叉与用户选择

## 问题定义

讲好一个生活故事，不等于给产品找一个单一正确脚本。产品营销短视频在策划早期应该先产出多个故事方向，让用户选择自己想要的生活观察、情绪口味和叙事机制，再进入深化。

Agent 的职责不是一稿替用户决定故事，而是把知识库中的结构能力转成可比较的故事方向。用户选择方向以后，Agent 才展开人物、冲突、段落、分镜和生成提示词。

## 为什么要先分叉

同一个产品可以进入不同生活命题：

- 保温杯可以讲自我照顾，也可以讲关系看见、职场边界、礼物传递或日常仪式。
- 低度果酒可以讲放松，也可以讲朋友关系、自我批准或人生阶段压力。
- 母亲节可以讲感恩，也可以讲嘴硬、学习、距离和照顾方式变化。

如果 Agent 直接推荐一个故事，常见风险是：

- 把产品卖点误当成故事主线。
- 把生活场景串成流水账。
- 把用户审美偏好锁死在 Agent 的第一判断里。
- 过早进入分镜，后续修改成本变高。

## 生活故事方向的六种来源

| 方向来源 | 观众想看的问题 | 适合产品/主题 | 产品入场方式 |
| --- | --- | --- | --- |
| 未完成动作 | 他为什么总是没有完成这件小事？ | 饮品、日用品、办公用品、情绪消费品 | 产品成为那个反复未完成动作的物件 |
| 关系误会 | 他们之间到底误解了什么？ | 礼品、食品、节日、亲情/友情/伴侣产品 | 产品成为被误解或被看见的证据 |
| 被延迟的愿望 | 他什么时候才允许自己得到它？ | 酒水、咖啡、香氛、睡眠、旅行 | 产品成为自我允许的仪式 |
| 小选择/小反抗 | 他会不会在关键时刻先照顾自己？ | 职场、女性、通勤、健康、效率产品 | 产品成为人物选择的动作支点 |
| 物件意义变化 | 同一个物件为什么前后意义不同？ | 高复购日用品、礼品、家居、数码 | 产品从普通道具变成关系或状态的证据 |
| 生活规则反转 | 如果生活里有一个隐藏规则，会发生什么？ | 概念片、科技、IP、品牌态度片 | 产品成为规则中的关键物或通行证 |

## 方向候选的最小字段

每个方向不需要先写完整脚本，但必须足够让用户判断想不想继续：

```text
方向名称：
生活观察：
观众问题：
人物：
表面事件：
真正冲突：
产品暗藏方式：
首尾呼应物件/动作：
情绪口味：
风险：
适合深化成：
```

## 输出数量

默认输出 4-6 个方向，而不是 1 个方向：

- 至少 1 个关系方向。
- 至少 1 个自我/心理方向。
- 至少 1 个功能摩擦方向。
- 至少 1 个更有创意或轻概念的方向。
- 如果产品适合送礼，再补 1 个礼物/关系方向。
- 如果产品能保存、传递或证明某种关心，再补 1 个误会和解方向。
- 如果用户指定平台或人群，按平台观看习惯压缩方向数量。

## 方向比较表

Agent 应该帮助用户选择，而不是用更长文字包装某个单一答案：

| 维度 | 要比较什么 |
| --- | --- |
| 观看欲 | 开头是否自然提出问题 |
| 生活真实感 | 是否像真的生活，而不是广告场景 |
| 产品暗藏程度 | 产品是否自然存在，不抢戏也不可替代 |
| 情绪强度 | 是轻喜、心疼、治愈、松一口气，还是轻微反抗 |
| 生成可行性 | AI 视频能否稳定生成角色、物件、动作和场景 |
| 商业承接 | 片尾是否能自然回到产品价值 |

## 用户选择后的深化

用户选择方向后，才进入单一故事深化：

```text
选定方向
-> 人物卡
-> 关键生活事件
-> 阻碍与代价
-> 产品暗藏动作
-> 首尾呼应
-> 70 秒段落结构
-> 镜头任务表
-> 分镜和视频提示词
```

如果用户对多个方向都感兴趣，不要把它们混成一个故事。应该拆成 A/B/C 三条短片，分别深化。

## 质检

- 是否先给了用户选择权，而不是直接输出一个完整脚本？
- 每个方向是否有不同的生活观察，而不是同一个故事换标题？
- 产品是否藏在生活动作里，而不是变成主角？
- 每个方向是否能提出一个观众想知道答案的问题？
- 用户选定前，是否避免过早写长分镜和完整旁白？
- 用户选定后，是否能把方向深化成单一清楚的故事？
