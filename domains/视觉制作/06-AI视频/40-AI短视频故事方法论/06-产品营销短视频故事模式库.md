# 产品营销短视频故事模式库

## 问题定义

案例库不能当模板库照抄，但可以当“问题相似性”检索层。新产品进入短视频策划时，先判断它像哪类传播问题，再迁移故事模式。

## 模式选择

```text
如果产品价格高、用户需要身份理由 -> 记忆保存型 / 生活状态型
如果产品功能明确但表达同质化 -> 功能摩擦型
如果产品送礼、节日、亲情强 -> 关系动作型 / 关系误会和解型
如果产品能保存、传递或证明某种关心 -> 关系误会和解型
如果产品是情绪消费 -> 自我批准型
如果主题有文化资产 -> 时间纵深型
如果产品或品牌需要世界观 -> 世界规则型
```

## 迁移边界

- 只能迁移“问题结构”，不能复制人物、情节和风格表皮。
- 功能摩擦型必须让功能在动作中发生，不要靠口播解释。
- 情绪型必须有生活动作，不能只靠慢镜头和文艺旁白。
- 关系误会和解型必须让产品成为误会解除的证据，不要靠人物长篇解释。
- 世界规则型必须有规则和代价，不能只做氛围预告片。
- 文化型必须有时间、人物和现代连接，不能只堆传统符号。
