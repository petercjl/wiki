# AI短视频导演思维

导演思维负责把剧本中的事件、关系和情绪转成观众能够通过画面经历的信息。它不是镜头术语表，也不是把剧本机械切成若干段。

## 核心问题

- 这一段由谁的视点主导？
- 观众先知道什么，后知道什么？
- 人物、产品和空间关系怎样变得可见？
- 应该靠动作、构图、机位、调度、声音还是剪辑表达？
- 一个镜头提出什么问题，下一个镜头怎样回答？
- 哪些画面必须生成，哪些可以省略或留给声音？

## 阶段输出

```text
剧本段落
→ 观众经验目标
→ 信息揭示顺序
→ 视点与空间关系
→ 人物/产品调度
→ 镜头任务序列
→ 剪辑和声音意图
```

这些输出必须进入 [[domains/视觉制作/06-AI视频/03-分镜脚本/index|分镜脚本]]，再通过图片和视频 Prompt 转成模型能够执行、结果能够验收的可见事实。
