# AI短视频视频生成

视频生成不是重新创作故事，而是把已经确认的镜头任务、参考资产、动作、摄影机、时间、声音和连续性编译为模型能够执行的条件，并用验收和最小修复闭环得到可剪素材。

## 生成闭环

```text
分镜任务与验收项
→ 选择最小充分参考资产
→ 编译 Prompt
→ 检查约束冲突与负载
→ 生成候选
→ 按语义、身份、构图、动作、运动、声音和连续性验收
→ 只修复可见失败
→ 保存入选素材及失败理由
→ 交给剪辑
```

## 边界

- 模型参数和接口属于 [[domains/视觉制作/06-AI视频/80-模型与工具/index|模型与工具]]，执行前需复核当前能力。
- 单条 Prompt 不承担剧本、导演、资产规划和剪辑的全部工作。
- 参考图负责静态事实，Prompt 主要负责时间、动作、镜头、声音、连续性和参考图无法表达的变化。
