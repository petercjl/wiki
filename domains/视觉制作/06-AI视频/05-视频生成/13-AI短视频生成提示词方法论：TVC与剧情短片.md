# AI短视频生成提示词方法论：TVC与剧情短片

本页解决的不是“如何把 Prompt 写得更像电影”，而是：**角色、场景、道具和风格资产已经具备时，怎样把一个短视频生成段写成模型能够稳定完成、又方便后期剪辑的镜头任务。**

它来自两类本机实验：约 5 秒的耳机 TVC 氛围/产品镜头，以及含两个自然镜头的 15 秒校园剧情片段。两类片段共用同一条主线：

> 镜头优先，最小充分约束；参考图负责“是什么”，提示词负责“怎么发生”。

这不是对任何闭源模型内部机制的测量，也不是“所有视频都该这样做”的产品规格。它是截至 2026-07-27 在当前工作流中可复用、可继续 A/B 验证的制作方法。

## 1. 方法的适用边界

本页从“已有可用资产”开始：

```text
人物 / 场景 / 道具 / 风格资产已准备
        ↓
判定自然镜头与动作负载
        ↓
写生成 Prompt
        ↓
生成、验收、最小补丁、剪辑
```

它不覆盖产品洞察、故事命题、角色小传、场景选择、资产清单或生图 QA。那些属于前导阶段，应读取 [[domains/视觉制作/06-AI视频/01-项目定义与剧本/02-AI商业短视频规划方法|AI商业短视频规划方法]]、[[domains/视觉制作/06-AI视频/04-图片与控制资产/11-AI短剧角色场景道具资产构建方法|AI短剧角色场景道具资产构建方法]] 与 [[queries/AI短视频故事策划|AI短视频故事策划]]。

| 类型 | 本页回答的问题 | 不回答的问题 |
| --- | --- | --- |
| 5 秒左右 TVC | 这一镜怎样运动、人物/产品怎样行动、光影和声音怎样落下 | 这个产品为什么值得拍成这个故事 |
| 10—15 秒剧情段 | 哪些自然镜头应留在同一条生成中，人物关系与对白怎样不丢 | 完整短剧的世界观、人物弧光和资产设计 |

## 2. 不要把“5 秒”当成硬限制

早期经验是：约 5 秒的单镜头很容易控制。但后续 15 秒校园片段证明，决定稳定性的不是一个固定数字，而是模型需要同时完成的**约束负载**。

约束负载不是可量化的模型参数，而是编写时的风险清单：

- 镜头数量、景别与切换关系；
- 彼此独立的动作链；
- 人物之间的身份、站位、视线、对白对象；
- 背景人群的方向与行为；
- 关键道具；
- 跨镜头的天气、光线、服装、动作连续性；
- 环境声、对白、旁白，以及多张参考图的独立控制任务。

| 生成段情况 | 推荐处理 | 原因 |
| --- | --- | --- |
| 一个起始状态 + 一个主动作 + 一个结果 | 约 5 秒，单自然镜头 | 例如水滴落下形成涟漪、猫耳转动、风铃轻摆。 |
| 单一镜头但旁白/动作需要多一点呼吸 | 约 6 秒或按模型可用档位 | 不为凑 5 秒切掉动作结果或旁白落点。 |
| 同一地点、同一时刻的两个自然镜头 | 可在同一条 10—15 秒视频中明确切镜 | 共享雨势、光线、服装和动作状态通常比拆开后再拼更连贯。 |
| 同一中景内包含多个连续事件 | 仍先把它视为一个镜头；只在自然切点拆分 | 硬拆会让雨势、湿润、光线和人物动作难以接上。 |
| 多个互不相关的机位、多人关系、独立剧情转折 | 分成多个生成段，并设计剪辑衔接 | 继续延长只会增加约束竞争。 |

这补充而不推翻 [[domains/视觉制作/06-AI视频/06-视频剪辑与连续性/09-AI长视频连续性组接方法|AI长视频连续性组接方法]]：当确实存在自然镜头边界时，应按镜头组接；不要用“所有内容必须做进一条长镜头”代替叙事和剪辑。

## 3. 提示词的两层结构

### 3.1 单自然镜头公式

```text
镜头结构与运镜
+ 主体及参考
+ 一个主要动作链
+ 表情或动作结果
+ 必要环境同步运动 / 行为
+ 参考图未承载的光影变化
+ 声音
+ 画面质感与风格参考
```

这不是要求每段都填满。没有旁白就不写旁白；参考图已经清楚给出静态光线，就不再用一串近义词复述；没有发生过的失败，也不预先堆叠负向限制。

一个合格的单镜头应能浓缩成：

> 一个起始状态 + 一个主要动作 + 一个可见结果。

例如，“她咬下一口西瓜，嘴角轻轻上扬”比“她坐在廊下享受夏日、像听见了什么、心情很好”更容易验收。解释性心理动机只在它确实决定后续表演时保留；否则让可见动作和表情承担叙事。

### 3.2 多自然镜头的嵌套结构

当一条 10—15 秒视频内确实有两个自然镜头，不要把所有信息写成一长串。先声明共享世界和硬关系，再逐镜头描述：

```text
【共享硬约束】
时长、自然镜头数、同一时间/场景，以及不能变化的角色、道具、天气或关键关系。

【镜头一】
镜头结构与运镜 + 主体及参考 + 主要动作链 + 结果 + 必要环境行为。

【镜头二】
镜头结构与运镜 + 主体及参考 + 前一镜延续状态 / 新动作 + 情绪结果。

【关键细节】
只保留参考图无法表达、却会改变叙事结果的方向、光线、关系或道具信息。

【声音】
环境声 + 不要任何背景音乐 + 必要对白/旁白及其发声关系。

【风格控制】
R3D、景深、胶片颗粒、色调参考。
```

分层标题的作用是帮助编写者和模型建立优先级，不是用更多标题替代清晰内容。其理论依据见 [[domains/视觉制作/06-AI视频/05-视频生成/12-AI视频Prompt分层强控方法|AI视频 Prompt 分层强控方法]]。

## 4. 最小充分约束，而不是最短 Prompt

“简洁”不是删掉剧情核心，而是去掉重复、模糊和由参考图已经承担的信息。应优先保留以下类型：

| 信息 | 何时必须写 | 写法 |
| --- | --- | --- |
| 镜头结构 | 景别、机位或切镜会改变叙事阅读 | `固定中景缓慢推进；随后直接切为低机位仰拍近景。` |
| 主动作链 | 观众必须看到的因果或动作次序 | `足球滚到脚边；男孩跑入画面捡球；看见女孩后停住并坐到她旁边。` |
| 结果/表情 | 动作结束后的情绪落点 | `最后抬头，眼中含泪。` |
| 方向与关系 | 左右、内外、谁对谁说话会改变故事 | `母亲牵着自己的孩子，低头对孩子说；不与女孩交流。` |
| 背景行为 | 背景的错误行为会破坏常识或剧情 | `已接到孩子的家长和学生从校门内向外离开。` |
| 关键光影变化 | 参考图中没有、却影响剧情或剪辑 | `光斑在座椅上缓慢移动。` |

不必预先写“不要所有音乐化音效”“不要角色张嘴”“不要其他人声”等扩张性否定句，除非已经观察到该具体失败。提示词修复应遵循：**先生成—按语义/构图/运动/声音验收—只补丢失的那一条必要约束。**

## 5. 参考图：按职责分配，并保持最小充分

参考图负责视觉身份；提示词负责时间、动作、关系和声音。每张图都应有一个明确问题：没有它，哪一项会不稳定？

| 参考类型 | 主要职责 | 何时加入 |
| --- | --- | --- |
| 人物身份图 | 脸、服装状态、体态与角色识别 | 人物跨镜头出现或身份不可漂移时。 |
| 场景图 | 空间、材质、陈设、时代与环境关系 | 需要保持同一地点或避免场景自由改写时。 |
| 本镜关键图 | 构图、姿势、物件位置、当下光线 | 单一镜头的画面质量和首帧最重要时。 |
| 产品/关键道具图 | 产品或道具的身份与剧情功能 | 它必须被看清、被使用，且人物/场景图不足以锁定时。 |
| 风格图 | 跨场景的色彩、对比、胶片气质 | 场景图和关键图尚不能承担系列统一时。 |

不要在文字中重建设备、产品、人物或场景图已经清楚显示的细节；应说“产品/人物/场景身份遵循参考图”，再把文字留给本镜的运动与剧情。

### 参考图删减测试

在校园案例中，人物图、场景图、足球图、风格图同时输入，并不总是比只保留人物图和场景图更稳定。这是一个待复测的工作假设：额外参考图可能增加条件竞争或引入不同视觉布局。

因此不推导“图越少越好”，而采用单变量测试：

1. 固定 Prompt、模型参数、时长与其他输入；
2. 先使用当前最小可用的角色和场景图；
3. 每次只增加或移除一张道具、关键图或风格图；
4. 分别检查身份、构图、动作、风格和连续性；
5. 只保留确实提高结果或解决明确失败的图。

## 6. 把关系、背景和运镜写成可见事实

模型容易把抽象叙事意图自行补全成别的画面。以下三类内容必须在需要时明确：

### 6.1 对白绑定可见关系

仅写“妈妈牵孩子说台词”仍可能得到画外音，或让妈妈对画面中心的主角说话。应写清：

```text
母亲牵着自己的孩子，低头看着孩子说：“……”。
孩子的反应是……。母亲只与自己的孩子交流，不与主角交谈。
```

这是叙事关系约束，不是多余修辞。台词的声源、视线对象和排除关系共同保证观众能读懂画面。

### 6.2 背景也要有行为逻辑

“放学人群”“街上行人”“车站旅客”只给出类别，没有给出行为。若方向或行为影响剧情，要写成可观察动作：

```text
所有背景学生和已接到孩子的家长从校门内向外离开。
除两组关键亲子外，其余人只作为持续离校的人流，不承载对白或独立剧情。
```

### 6.3 把随机惊喜变成镜头指令

模型有时会从“溪流向远处延伸”推断出贴水面逆流推进，形成很好的寻找源头感。这种结果不能当作稳定能力。下一轮应写成：

```text
低机位贴近水面，镜头沿溪流逆流方向缓慢向前推进；
前景反光向画面深处延伸，逐步靠近远处森林。
```

同理，双机位必须明确“先什么镜头，直接切到什么镜头，切后哪些主体仍在画面中”，不要依赖模型随机切镜。

## 7. 声音：生成阶段不做分段 BGM

一段短视频的声音分为三层：

| 声音层 | 生成 Prompt 中的处理 | 后期处理 |
| --- | --- | --- |
| 环境声 | 可写火车、雨、风、鸟、脚步、踢球等真实环境或动作声 | 按剪辑需要保留、补充或替换。 |
| BGM | 写 `不要任何背景音乐` | 所有视频剪接完成后，为整条片统一生成或配入。 |
| 人物声音 | 写具体旁白/对白和声音关系；需要时输入干净音色参考 | 固定台词与声线资产，必要时单独配音。 |

“不要任何背景音乐”在本机案例中已足够表达意图，无需把钢琴、弦乐、氛围音、节奏和音乐化音效逐一列入。更完整的整片配乐与声线资产流程见 [[domains/视觉制作/06-AI视频/07-声音设计与BGM/10-Seed-Audio短视频音频一致性工作流|Seed-Audio短视频音频一致性工作流]]。

若要维持人物音色，先从选定成片中提取尽可能干净的单人声音，再生成约 3—5 秒的中文纯人声参考；带明显 BGM、多人说话或强混响的片段不适合作为声线控制源。该做法依赖当前视频/音频模型是否支持参考音频，执行前应复核实际接口并做试听。

## 8. 两类可复制 Prompt 骨架

### 8.1 约 5 秒 TVC / 氛围单镜头

```text
[镜头结构与运镜]。
[人物 / 产品 / 场景] {{参考图}}，构图与光线参考 {{关键图}}。
[一个主要动作链]，[表情或动作结果]。
[必要的风、雨、光斑或背景运动]。

声音：[自然环境声]，不要任何背景音乐。
[如有需要：中文旁白：“……”，音色参考 {{Audio 1}}。]

[R3D 大光圈质感、胶片颗粒、色调参考 {{风格图}}。]
```

验收重点：主体是否正确、一个动作是否完成、镜头是否按预期运动、产品/人物是否可识别、是否无分段 BGM。

### 8.2 10—15 秒剧情双镜头

```text
【共享硬约束】
[时长]，[两个自然镜头]，[同一时间与场景]。
[持续天气 / 光线 / 人物服装 / 关键道具]保持一致。

【镜头一】
[景别、机位、运镜]。
[主角及参考]进行[主动作]。
[其他人物的出场顺序、动作、视线、对白对象]。
[背景人群或环境的方向与行为]。

【镜头二】
直接切为[景别、机位、运镜]。
[同一主角 / 同一关键道具]处于[延续状态]，完成[新动作与情绪结果]。

【声音】
[环境声]；[人物]对[对象]说：“……”。不要任何背景音乐。

【风格控制】
R3D 大光圈质感，胶片颗粒，[色调与风格参考]。
```

不必为了“精确控制”强行写第几秒切镜；若两个镜头的顺序与任务清楚，可让模型按自然节奏分配停留时间。只有当测试显示切点本身反复错误时，再把时序加为最小补丁。

## 9. 生成后的验收与最小补丁闭环

每条生成后，按下表定位，而不是笼统地说“模型不听话”：

| 验收维度 | 检查问题 | 失败后的第一修正 |
| --- | --- | --- |
| 语义 | 主体、场景、道具是否正确？ | 检查是否缺少对应参考图，或是否有多图竞争。 |
| 构图 | 景别、机位、人物位置、左右关系是否成立？ | 把关键空间/视线关系改写为可见动作；必要时补关键构图图。 |
| 运动 | 主动作、镜头路径、切镜是否完成？ | 只补充该动作的顺序、方向或结果；不要同时增加风格词。 |
| 关系 | 对白由谁对谁说？背景行为是否合理？ | 明确说话者视线、对象反应和不与谁互动；明确人群方向。 |
| 声音 | 是否有环境声、无 BGM、音色是否可用？ | 保留简洁的无 BGM 约束；把整片音乐移至后期。 |
| 风格 | 色调、景深、胶片质感是否统一？ | 先检查风格图是否必要，再补一个最小风格描述。 |

建议的实验记录字段是：原 Prompt、优化 Prompt、参考图组合、时长、生成结果、具体失败、唯一新增/删除变量、结论与下一轮测试。这让“感觉更好”逐步转成可归因的方法。

## 10. Agent 使用协议

收到“我已有参考图，帮我写/优化一段 AI 短视频 Prompt”时，Agent 应按以下顺序工作：

1. 判断用户是在做单自然镜头，还是同场景内的多个自然镜头；不要先假设必须 5 秒。
2. 写一句可验收的镜头任务：观众必须看到什么变化？
3. 识别最小必要参考：人物、场景、关键构图、道具、风格各自是否真的需要。
4. 按单镜头公式或多镜头嵌套结构组织 Prompt。
5. 对关系、方向、对白对象、关键结果和连续环境使用可观察语言。
6. 只为本段需要的声音写环境声、具体对白/旁白和“不要任何背景音乐”。
7. 将 R3D、胶片、景深、色调放在最后；不让风格淹没叙事结构。
8. 生成后按语义、构图、运动、关系、声音、风格验收；下一轮只改一个可归因变量。

## 11. 当前证据等级与下一阶段

| 结论 | 当前状态 |
| --- | --- |
| 最小必要提示词、单镜头公式、无分段 BGM、参考音色流程 | 已在多个 TVC/氛围短镜头中验证。 |
| 同一段内显式双机位、显式运镜 | 已在水滴和溪流案例中验证。 |
| 15 秒双自然镜头的共享约束、关系/背景行为/对白绑定 | 已在雨天校门口和操场剧情案例中验证，需要更多题材复测。 |
| 约束负载比固定 5 秒阈值更有解释力 | 有跨案例支持的工作假设，仍非模型内部事实。 |
| 参考图越多可能越不稳定 | 仅是待复测假设；必须做单变量删图测试。 |

下一阶段研究应从产品或故事大纲出发，回答“怎样选择场景、生成角色/道具/风格资产、形成脚本与镜头任务”。那是本页的上游，不应混同为 Prompt 写法问题。
