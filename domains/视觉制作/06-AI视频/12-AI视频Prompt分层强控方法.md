# AI视频Prompt分层强控方法

真正的 Prompt 强控不是把描述无限写长，而是建立约束优先级：模型先满足什么、后满足什么、哪些绝对不能错，以及哪些控制任务不应该继续交给文字。

## 问题：为什么越具体反而越不听话

比较两个输入：

```text
短 Prompt：
一个女生在海边走。

细节堆叠：
27 岁、短发、卡其色风衣、逆光、慢推镜头、表情克制、
电影感、黄昏海岸……
```

短 Prompt 只要求主体、场景和动作成立，目标少、冲突少。细节堆叠后，模型可能乱加细节、丢设定，甚至出现画面崩坏。

问题不是“详细本身有错”，而是未经分层的详细让模型同时承担太多目标。年龄、发型、服装、焦段、运镜、情绪和风格会争夺有限的表达能力，并可能彼此冲突。

## Prompt服从度的四个维度

Prompt 服从度是文本条件约束生成结果的程度，应至少分别检查：

| 维度 | 检查问题 |
| --- | --- |
| 语义 | 主体、对象、场景和含义是否成立？ |
| 构图 | 景别、机位、主体位置和画面结构是否成立？ |
| 运动 | 主体动作、镜头运动和速度方向是否成立？ |
| 风格 | 光调、材质、质感和整体风格是否成立？ |

不能只用“像不像提示词”做笼统判断。模型可能语义正确但运镜错误，也可能风格接近但构图和时序失控。

## 底层理解：Prompt不是命令清单

在常见生成架构中，Prompt 会经过文本编码，形成高维语义向量，再通过交叉注意力、条件引导等机制影响去噪过程。模型获得的不是导演助理手里那种逐项勾选的执行清单，而是被压缩后的语义条件。

生成过程是在有限计算预算和有限步数中寻找一个结果，使它：

1. 尽量符合文本条件；
2. 同时仍像一段自然、稳定的视频。

因此，条件越多，任务越像多目标优化。模型不是故意忽略要求，而是在冲突条件中自动取舍。

视频的信息图用一个总计 100% 的“注意力预算”示意表示竞争：年龄 8%、发型 10%、服装 14%、光线 13%、焦段 12%、运镜 14%、表情 12%、风格 17%。这组数字没有实验来源，只用于把“多个条件共同占用有限表达能力”画出来，不能当作真实权重、配置参数或不同模型的固定分配比例。

> 边界：文本编码、交叉注意力、条件引导和 CFG 是理解常见生成机制的有效模型，但不能据此断言每个闭源视频模型都采用完全相同的内部实现。

## 三个技术压力层

这里的“三个压力层”解释为什么失控；后文的“三层 Prompt”则规定怎样写。两者不要混淆。

### 第一层：文本编码的压缩损失

Prompt 再长也要进入文本编码器。长句并列修饰、抽象风格词和具体物体词被压入同一个语义空间后，信号强度并不均等：

- 容易保留的强信号：海边、女性、电影感。
- 可能被弱化的细粒度信号：卡其色、27 岁、表情克制。

这不是模型完全没读到细节，而是细节在压缩和竞争中没有成为生成的主要语义重点。

### 第二层：条件引导与画面质量的张力

许多扩散系统使用类似 CFG 的条件引导，把结果拉向文本描述：

| 引导状态 | 典型结果 |
| --- | --- |
| 太弱 | 画面自然，但不够听话 |
| 平衡 | 结果靠近提示，形态仍较稳定 |
| 太强 | 更贴近 Prompt，但可能过饱和、纹理噪声、肢体异常、面部不稳定 |

可以把它理解为牵引绳：太松会乱跑，太紧又会走得变形。写更长的 Prompt 不能自动解决这个张力。

### 第三层：视频的时间一致性压力

图片只需要一帧成立；视频还要让以下内容在几十帧中连续成立：

- 角色身份；
- 服装；
- 光线；
- 背景；
- 主体与镜头运动。

局部细节越多，模型不仅要生成每个细节，还要让它们沿时间线不漂移。视频 Prompt 的控制成本因此高于图片 Prompt。

## 先检查条件是否互相冲突

两个典型冲突：

| 条件 A | 条件 B | 冲突位置 |
| --- | --- | --- |
| 35mm 广角感 | 面部特写 | 景别、透视和构图互相拉扯 |
| 逆光剪影 | 清晰表情 | 剪影效果与面部可见度互相拉扯 |

发现冲突后，不应继续加同义词增强两边，而要明确优先级或拆镜头：

- 若面部表演是镜头任务，就减弱剪影，保留边缘光。
- 若环境空间感是镜头任务，就不要同时要求强面部特写。
- 若两者都必须出现，就用两个镜头分别承担。

## 三层Prompt写法

### 第一层：硬约束

先写不能错的结构信息：

- 主体；
- 场景；
- 动作；
- 镜头目标。

示例：

```text
短发女性在黄昏海边缓慢行走，镜头从中景缓慢推进。
```

硬约束决定“这一镜到底是什么”。如果它们没有先成立，服装颜色和电影感再准确也不能挽救镜头。

### 第二层：少量关键细节

再写真正影响画面任务的细节：

- 服装；
- 光线；
- 情绪。

示例：

```text
卡其色风衣，逆光边缘光，表情克制。
```

“少量”不是固定数量，而是只保留对镜头任务有区分度的细节。不能因为字段存在，就把每个字段都填满。

### 第三层：风格控制

最后写整体风格和稳定性要求：

```text
写实电影质感，自然运动，稳定时序。
```

风格词应服务前两层，不能淹没结构词。多个近义风格形容词通常不会线性增加控制力，反而会扩大解释空间。

### 合并后的分层示例

```text
【硬约束】
短发女性在黄昏海边缓慢行走，镜头从中景缓慢推进。

【关键细节】
卡其色风衣，逆光边缘光，表情克制。

【风格控制】
写实电影质感，自然运动，稳定时序。
```

三个标签是编写和检查时的结构。提交给具体模型时，可根据模型语法保留分段，也可合并成短段落，但不能破坏优先顺序。

## 复杂镜头不要一条Prompt全包

当一个镜头必须控制大量细节时，把控制压力拆成可验证阶段：

```text
1. 拆镜头、拆阶段
2. 先锁主体与构图
3. 再加入风格与运动
4. 使用辅助控制
5. 后期校正
```

### 辅助控制手段

| 手段 | 分担的控制任务 |
| --- | --- |
| 参考图 | 锁定人物、产品、场景、材质和颜色等视觉身份 |
| 首尾帧 | 锁定镜头的起点、终点、转场或状态变化 |
| 遮罩 | 限制局部区域的变化范围 |
| 后期校正 | 修复不适合继续由生成模型承担的局部错误 |

若目标是产品或人物一致性，优先使用参考资产，不要把已经明确可见的结构反复翻译成长文字。若目标跨越多个动作、构图或时间状态，优先拆镜头，而不是把所有动作塞入同一段。

## 失控诊断表

| 症状 | 更可能的原因 | 优先修正 |
| --- | --- | --- |
| 主体或场景直接错 | 硬约束不清、目标过多 | 缩短到主体/场景/动作/镜头目标 |
| 年龄、服装、表情丢失 | 细粒度信号被弱化 | 只保留最关键细节；必要时使用参考图 |
| 运镜和构图互相破坏 | 镜头目标冲突 | 每镜一个主要运镜；拆镜头 |
| 逆光成立但脸看不清 | 光线和表演目标冲突 | 明确优先级，改为边缘光或另拍表情镜头 |
| 更贴词但画面变形 | 条件引导过强或约束过载 | 减少竞争条件，回到平衡区间 |
| 前几帧正确、后续漂移 | 时间一致性压力过高 | 减少局部细节；用参考图、首尾帧或分段生成 |
| 风格明显、故事动作不成立 | 风格词淹没结构词 | 把风格移到第三层，先验证硬约束 |

## Agent执行协议

收到“帮我写一个可控的 AI 视频 Prompt”时：

1. 先写一句镜头任务，明确观众必须看到什么。
2. 识别主体、场景、动作和镜头目标，作为硬约束。
3. 只保留影响镜头任务的服装、光线和情绪细节。
4. 检查焦段、景别、光线、表情、动作与运镜是否互相冲突。
5. 最后添加风格、自然运动和时序稳定要求。
6. 若控制项仍多，提出拆镜头或拆阶段方案。
7. 判断哪些约束应交给参考图、首尾帧、遮罩或后期。
8. 输出 Prompt 后，按语义、构图、运动、风格四维验收。

## 生成前检查清单

- 主体、场景、动作和镜头目标是否一眼可识别？
- 哪些是绝对不能错的硬约束？
- 关键细节是否确实服务镜头任务？
- 是否存在 35mm 广角与面部特写、逆光剪影与清晰表情之类的冲突？
- 风格词是否放在结构词之后？
- 单镜头是否承担了过多动作或多个主要运镜？
- 局部细节是否会造成跨帧一致性压力？
- 是否应改用参考图、首尾帧、遮罩或后期？
- 是否能分别验收语义、构图、运动和风格？
