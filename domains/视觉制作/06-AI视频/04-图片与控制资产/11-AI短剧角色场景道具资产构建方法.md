# AI短剧角色场景道具资产构建方法

AI 短剧资产构建的核心不是“会用哪个平台”，而是把剧本中的人物、空间和物件转成可被模型稳定读取的控制资产。平台、模型、画布、审核入口都只是执行层；可复用的原理是资产协议、参考图控制、候选生成、审美筛选和质量门。

这页补充 [[domains/视觉制作/06-AI视频/04-图片与控制资产/07-故事板铁三角AI视频控制法|AI视频控制资产系统]]：那一页定义身份板、故事板、导演台和素材库的控制层；本页更聚焦 AI 仿真人短剧在开拍前如何从剧本生成角色、场景、道具资产包。

## 1. 总流程

```text
剧本/小说
-> 提取角色、场景、道具清单
-> 为角色写人物小传和受众定位
-> 生成角色正面定妆图候选
-> 人工审美与剧情契合筛选
-> 生成脸部特写 + 正侧背三视图
-> 为本集生成核心场景全景或多视角图
-> 为关键道具生成纯白底资产
-> 建立资产包和 QA 记录
-> 再进入分镜图、视频生成和剪辑
```

不要从“发型、发色、衣服、颜值”直接开始。角色看起来漂亮但换一集就认不出来，通常不是工具问题，而是故事功能、受众期待和视觉符号没有闭环。

## 2. 资产库要生哪些图

面向 AI 短剧，资产库不是把所有可能图片都生一遍，而是为后续分镜和视频生成准备“能稳定读取、能被复用、能被检查”的图。最小资产包分为角色、场景、道具三类。

### 2.1 角色资产库

| 图片 | 必选 | 用途 | 生图要点 |
| --- | --- | --- | --- |
| 角色正面全身定妆图 | 必选 | 锁定角色身份、脸、身形、服装、比例 | 纯白底、正面站立、全身含鞋、无手持物、中性表情 |
| 角色四视图 | 必选 | 供后续图生图、分镜、视频参考保持一致 | 左侧脸部特写，右侧正面/侧面/背面全身，纯白底，风格一致 |
| 关键状态变体 | 条件必选 | 角色在剧情阶段发生明显状态变化时使用 | 同一角色身份不变，只改变剧情状态，如婚前/婚后、受伤/健康、落魄/掌权 |
| 表情卡 | 可选 | 近景、对白、情绪镜头需要更稳定脸部表演时使用 | 同一脸型、发型、服装，输出 4-9 个表情，不改变身份 |
| 动作/姿态卡 | 可选 | 打斗、奔跑、跪地、转身等动作镜头前置参考 | 同一服装和身体比例，多姿态但不要混入场景 |
| 服装细节或发饰细节 | 可选 | 服化道复杂、容易漂移时使用 | 局部特写，纯白底或干净底，标明材质、纹样、层次 |

一个主要角色至少要有“正面全身定妆图 + 四视图”。如果一集里同一角色有明显剧情状态变化，每个状态都要有对应定妆图或状态变体，否则后续视频会把状态混在一起。

### 2.2 场景资产库

| 图片 | 必选 | 用途 | 生图要点 |
| --- | --- | --- | --- |
| 核心场景空镜全景图 | 必选 | 建立空间、氛围、陈设和时代感 | 无人物、广角/全景、关键陈设完整、符合剧情阶层 |
| 场景 2x2 多视角图 | 条件必选 | 多人对话、正反打、调度复杂时稳定空间关系 | 同一空间的俯拍、正向、左侧、右侧，元素位置一致 |
| 单视角高清场景图 | 条件必选 | 从多宫格中拆出可用角度后作为后续参考 | 由切片视角再生成高清图，不直接使用低清裁切图 |
| 反打场景图 | 条件必选 | 对话、对峙、看向门口/窗外/前台等反向镜头 | 用视觉锚点定义从 A 看向 B，前景/中景/背景清楚 |
| 场景光影/时间变体 | 可选 | 同一场景跨白天、夜晚、雨夜、烛光等状态 | 空间结构不变，只改变光线、天气、情绪 |
| 关键机位空镜 | 可选 | 后续分镜要固定某个镜头角度时使用 | 无人物，直接服务一个镜头的构图和景别 |

简单单人戏可以只有一张核心场景全景图。多人对话、宅斗审判、打斗、追逐、反打和群像调度，至少补 2x2 多视角图或若干单视角场景图。

### 2.3 道具资产库

| 图片 | 必选 | 用途 | 生图要点 |
| --- | --- | --- | --- |
| 道具纯白底主图 | 必选 | 锁定道具外形、材质和时代气质 | 单件物品、纯白底、无人物、无现代元素 |
| 道具多角度图 | 条件必选 | 道具需要在镜头里翻转、递交、佩戴、打开时使用 | 正面、侧面、背面或俯视，结构一致 |
| 道具细节图 | 条件必选 | 道具承担证据、身份、机关或卖点时使用 | 局部纹样、磨损、材质、开合结构清楚 |
| 道具状态图 | 条件必选 | 道具有打开/关闭、完整/破损、使用前/使用后状态 | 同一件道具，不生成成另一件 |
| 道具与手部/尺度参考 | 可选 | 需要明确大小或使用方式时使用 | 可以有手，但只作为尺度/操作参考，不替代白底主图 |

道具不是越多越好。只有参与剧情推进、身份识别、关系证明、冲突触发、机关操作或镜头特写的物件，才进入核心道具资产库。

## 3. 生图提示词构建模板

提示词应服务资产类型，而不是把剧本内容原样塞进去。每个 prompt 都要包含：资产任务、故事/时代约束、主体信息、画面规格、负向限制、质量目标。

### 3.1 角色正面全身定妆图

```text
生成一张 AI 短剧角色正面全身定妆图。

风格：真人写实 / 电影感 / 目标题材风格。
故事背景：[朝代/时代/世界观/题材]。
角色身份：[姓名]，[年龄段]，[职业/阶层/阵营/故事功能]。
角色气质：[3-5 个性格与情绪关键词]，[一个反差点]。
外形与服化道：[身高体型、脸型、眼睛、发型、发色、服装款式、材质、颜色、发饰、鞋子]。
姿态：正面站立，双手自然垂落或自然放在身体两侧，中性表情，看向镜头。
画面规格：全身入画，鞋子完整可见，纯白背景，干净无阴影污染。
限制：不要拿任何物品，不要出现场景背景，不要出现其他人物，不要文字，不要夸张表情，不要现代元素。
质量目标：角色美观但符合剧情身份，服化道贴合时代，比例自然，便于后续生成四视图和视频参考。
```

### 3.2 角色四视图

```text
基于参考角色图，生成同一角色的四视图资产图。

版式：左侧占约 1/3 为脸部特写；右侧占约 2/3 依次为正面全身、侧面全身、背面全身。
一致性：保持同一张脸、同一发型、同一服装、同一配饰、同一身高比例、同一材质和颜色。
背景：纯白背景。
风格：与参考图完全一致的真人写实风格。
限制：不要加入场景、文字、标签、手持物或额外人物；不要改变角色年龄、脸型、服装结构和发饰关系。
质量目标：供后续分镜图、图生视频和角色一致性控制使用。
```

### 3.3 角色状态变体

```text
基于参考角色图，生成同一角色在[剧情状态]下的定妆图。

必须保持：脸型、五官、发型基础、身高比例、核心身份识别点不变。
只改变：[服装状态/妆容状态/伤痕/疲惫程度/身份阶段/颜色层级]。
姿态与背景：正面全身站立，纯白背景，鞋子可见，无手持物。
限制：不要把角色变成另一个人，不要过度恐怖化或丑化，不要出现场景和其他人物。
质量目标：让观众能认出这是同一个角色在不同剧情阶段。
```

### 3.4 场景空镜全景图

```text
生成一张 AI 短剧核心场景空镜全景图。

场景名称：[场景名]。
故事背景：[朝代/时代/题材/阶层]。
剧情功能：[这个场景承载的剧情，如审判、受虐、密谈、对峙]。
空间类型：[室内/室外/庭院/走廊/房间]，[白天/夜晚/雨夜/黄昏]。
关键陈设：[门窗、桌椅、屏风、柴草、灯具、牌匾、地毯、器物等]。
光影氛围：[压抑/富丽/冷酷/紧张/温暖]，[主光方向与色调]。
构图：广角或全景，能够看清空间结构和主要陈设。
限制：不要出现人物，不要现代物品，不要文字标签，不要生成与时代不符的建筑或家具。
质量目标：作为后续分镜和视频生成的空间参考。
```

### 3.5 2x2 多视角场景图

```text
根据上传图或场景设定生成一张 2x2 多视角场景参考图。

任务：还原同一个完整三维空间，并输出四个标准视角。
左上：俯拍视角，从正上方展示场景整体平面关系。
右上：正向视角，从场景正面朝主体区域观看。
左下：左侧视角，从场景左侧朝主体区域观看。
右下：右侧视角，从场景右侧朝主体区域观看。
一致性：四格必须是同一个场景，元素数量、相对位置、尺度比例、朝向、材质、光影和色调一致。
补全规则：未展示区域只能根据可见线索合理补全，不加入无关新内容。
限制：无人物，无文字标签，视角端正稳定，不要明显斜拍，不要被近景物体大面积遮挡。
质量目标：供后续拆分为正反打、侧面和俯视参考。
```

### 3.6 反打场景图

```text
参照输入图的风格和空间，生成一个反打场景图。

风格：[真人写实/3D/2D/电影感]。
角度：从[位置 A]看向[位置 B]的反打视角。
构图：[中心构图/三分构图/过肩感但不出现人物]。
前景：[前景物体]，轻微虚化。
中景：[主要视觉锚点]，清晰聚焦。
背景：[远处空间、门窗、墙面、陈设]。
环境：保持原场景的光影、色调、材质和氛围。
限制：不要出现人物，不要改变空间结构，不要新增无关陈设，不要现代元素，不要文字标签。
质量目标：与原场景形成可剪辑的正反打空间关系。
```

### 3.7 道具白底图

```text
生成一张 AI 短剧道具资产白底图。

道具名称：[道具名]。
剧情功能：[身份凭证/钥匙/信物/药瓶/账册/机关/武器/证据]。
时代与风格：[朝代/题材/阶层气质]。
外观：[形状、尺寸感、材质、颜色、纹样、磨损、新旧程度]。
画面规格：单件物品，居中展示，纯白背景，结构清晰。
限制：不要人物，不要手，不要场景，不要现代元素，不要无关文字；如必须有文字，避免简体字并优先留给后期可控处理。
质量目标：便于后续融合到场景、手部动作或特写镜头中。
```

## 4. 角色资产协议

角色资产先回答“这个人在故事中是什么”，再回答“这个人长什么样”。人物小传不是文学简介，而是给模型、Agent 和后续制作环节读取的结构化角色协议。

| 字段 | 要回答的问题 | 视觉转译 |
| --- | --- | --- |
| 身份与位置 | 职业、阶层、阵营、故事功能 | 服装等级、身体姿态、配饰复杂度、干净或磨损程度 |
| 性格与反差 | 3-5 个性格标签和至少 1 个反差点 | 表情、站姿、发型规整度、物件或服装细节 |
| 核心欲望与困境 | 最想要什么、现在卡在哪里 | 神态张力、服饰状态、伤痕、遮掩动作 |
| 关系网络 | 与主角、反派、组织的关键关系 | 亲密/疏离、权力感、保护感、敌意感 |
| 视觉暗示 | 可被画面识别的习惯或符号 | 帽檐、伤疤、口袋、小工具、固定色彩、常用材质 |

角色 prompt 应从这个协议生成，而不是孤立堆外貌词。角色功能、性格、关系和视觉符号形成闭环时，角色才会从“好看”变成“有记忆点”。

## 5. 受众与赛道决定视觉方向

网文短剧常见男频/女频差异会影响角色定调。它不是性别刻板印象，而是受众爽点和情绪入口不同。

| 维度 | 男频线 | 女频线 |
| --- | --- | --- |
| 核心欲望 | 权力、征服、升级、反杀 | 情感、被爱、救赎、关系确认 |
| 视觉关键词 | 力量感、等级压制、硬朗轮廓、动作张力 | 情绪感、氛围、眼神和微表情、服饰层次 |
| 主角期待 | 代入“做到我做不到的事” | 共情“经历我渴望的关系和偏爱” |
| 画面倾向 | 高对比、硬阴影、装备感、前倾或向上动作 | 柔和光线、近景表情、饰品暗示、节奏更慢 |

写角色 prompt 时，不要只写“帅哥”“小姐姐”。要明确故事类型、目标读者、角色爽点和视觉风格。

## 6. 可由 API 或 Skill 实现的资产抽取节点

原文中的“智能体/平台”可以替换成我们自己的 Skill 或直接 API 调用。关键是把节点拆开：

```text
输入：剧本全文或本集剧本

节点 A：资产识别
- 输出人物清单、场景清单、道具清单
- 标记主资产、辅助资产、一次性资产

节点 B：角色协议生成
- 为每个主要角色输出人物小传
- 输出受众/赛道判断
- 输出视觉关键词，不直接生成最终图

节点 C：资产 prompt 生成
- 角色：正面全身、纯白底、无手持物、无背景、鞋子可见
- 场景：无人物、全景或多视角、空间关系清楚
- 道具：单件物品、纯白底、无人物、无现代污染

节点 D：候选生成与模型路由
- 同一资产生成多张候选
- 根据题材选择更适合的模型或供应商
- 记录提示词、模型、参考图和版本

节点 E：QA 与返修
- 剧情契合、审美、比例、表情、服化道、空间连续性、道具时代感
```

工具界面里的“添加图片节点”“选择模型”“宫格切分”本质上分别对应：创建生成任务、模型路由、后处理切片/再生成。我们实现时应把这些能力沉淀为可组合命令或 Skill 节点，而不是依赖某个画布产品。

## 7. 角色定妆图规范

角色初版定妆图的任务是锁定身份、外形、服装和比例，不是直接做最终镜头。

| 要求 | 原因 |
| --- | --- |
| 全身正面 | 后续三视图、动作图和视频参考需要完整身体结构 |
| 纯白背景 | 避免背景被视频模型误读进后续镜头 |
| 不拿任何东西 | 除非整集始终持有该物件，否则手持物会污染角色身份 |
| 双手自然垂落或中性姿态 | 让后续动作由分镜控制，而不是由定妆图误导 |
| 鞋子可见 | 全身图经常漏脚，鞋子影响时代、身份和比例 |
| 无夸张表情 | 定妆图负责身份稳定，表演状态留给分镜和表情卡 |
| 贴合人种、时代、发饰、服装 | 避免古装、现代、地域和阶层错位 |

如果是成年人角色，比例可以朝更修长的商业审美靠拢，但不能牺牲角色可信度。反派也不必做得丑陋；更好的做法是让坏、虚伪、风情、压迫感或危险感通过服饰、眼神和姿态表达。

## 8. 四视图与身份板

确定正面全身图后，再生成“脸部特写 + 正面/侧面/背面三视图”。这组资产在短剧里相当于角色的最小身份板。

```text
输入：已筛选的正面全身图
输出：一张四视图图版
结构：左侧脸部特写，右侧正面全身、侧面全身、背面全身
背景：纯白
风格：与原角色图一致
约束：服装、发型、配饰、身高比例、脸型和气质保持一致
```

四视图适合稳定结构；如果短剧需要更强的角色气质、职业感、表情和故事氛围，还应补 [[domains/视觉制作/06-AI视频/04-图片与控制资产/07-故事板铁三角AI视频控制法|电影感角色母卡]]。

## 9. 模型选择原则

原文列举了多个图片模型和平台，但不要把“某模型一定最好”写死。可复用原则是按任务路由：

| 任务 | 选择逻辑 |
| --- | --- |
| 中式古装服化道 | 优先试对中国风、汉服、发饰、古装审美理解更稳的模型 |
| 真人真实感 | 优先试人像真实感强、脸部自然的模型，但警惕网红脸同质化 |
| 复杂 prompt 理解 | 优先试推理和文字遵循能力更强的模型 |
| 批量候选 | 优先成本较低、速度较快、质量够用的模型 |
| 最终定稿 | 以审美、角色契合、后续可控性为准，不以模型名为准 |

模型能力、价格和审核政策都是时效信息。执行前应通过当前官方 API 文档或实际测试复核。

## 10. 角色 QA 与失败模式

| 失败模式 | 表现 | 修正原则 |
| --- | --- | --- |
| 服化道不搭 | 古偶、仙侠、武侠、宅斗、权谋混在一起 | 找同题材影视参考，提取朝代/剧种/阶层服化道规则 |
| 时代错位 | 古装出现现代元素、现代妆造进入古代设定 | 在资产协议中写明时代、材质、禁用元素 |
| 比例错误 | 头大、腿短、身体扭曲、手脚异常 | 用全身正面、鞋子可见、自然站立作为底图 |
| 角色过丑或过极端 | 反派、病弱、落魄被模型夸张化 | 改成“审美化的状态表达”，用病弱/疲惫/破损而不是恐怖化 |
| 表情异常 | 眼神不对称、嘴型怪、表情过度 | 定妆图保持中性表情，情绪镜头另做表情卡 |
| 审美灰脏 | 色彩混浊、缩略图认不出轮廓 | 缩略图检查、色彩检查，对标成熟剧集/国漫/短剧 |
| 背景污染 | 角色图带场景，后续视频把背景带入 | 角色定妆和三视图必须纯白底 |
| 手持物污染 | 后续镜头误以为角色始终拿着物件 | 除非剧情要求始终持有，否则定妆图不带道具 |

AI 只能放大创作者的审美导向。要把“我想要好看”拆成可检查的视觉判断：轮廓、比例、服化道、色彩、表情、身份气质和故事功能。

## 11. 场景资产协议

角色解决“谁”，场景解决“在哪”。场景不是背景图，而是空间化叙事工具。

场景生成前先做场景库：

| 字段 | 说明 |
| --- | --- |
| 场景名 | 如侯府柴房、侯府前厅、网咖前台 |
| 剧情功能 | 受虐、审判、对峙、密谈、转折、告别 |
| 时间 | 白天、夜晚、雨夜、黄昏 |
| 空间类型 | 室内、室外、半开放庭院、走廊、房间 |
| 关键陈设 | 桌椅、屏风、柴草、门窗、灯具、牌匾 |
| 光影色调 | 压抑、富丽、冷酷、温暖、紧张 |
| 需要视角 | 单张全景、正反打、四宫格、多角度、俯视图 |

场景设计原则：

- 先用全景或超广角建立空间容纳性。
- 场景图不要出现人物，避免后续生成被污染。
- 是否需要多个视角由剧本调度决定；简单场景一张全景通常够用。
- 多人对话、对峙、打斗和反打需要正反打或多视角。
- 场景必须符合故事阶层和气质，例如“侯府柴房”不能像乡下破棚，也不能像现代仓库。

## 12. 多视角场景与反打

多宫格场景的本质不是拼图，而是让模型从同一空间推导多个视角。可由我们自己的 Skill 实现为：

```text
输入：单张场景参考图或文字场景协议
任务：还原同一个完整三维空间
输出：2x2 多视角参考图
视角：
- 左上：俯拍，展示平面关系
- 右上：正向，朝主体区域观看
- 左下：左侧，朝主体区域观看
- 右下：右侧，朝主体区域观看
约束：
- 元素数量、相对位置、尺度、朝向、材质、光影一致
- 未展示区域只允许根据可见线索补全
- 不加入无关新内容
- 不添加文字或标签
```

四宫格切分后的单张图如果分辨率不足，不应直接作为最终资产。正确做法是把切出的视角作为参考，再调用图像生成或超分节点重新生成清晰单视角资产。

反打场景的关键是视觉锚点。prompt 结构可以抽象为：

```text
参照输入图的风格，生成一个反打场景图。
风格：真人写实 / 3D / 2D / 其他
角度：从 A 看向 B 的反打视角
构图：中心构图或指定构图
前景：XX，允许虚化
中景：XX，聚焦在 XX
背景：XX
环境：光影、色调、氛围
一致性：保持同一空间、同一材质、同一光照逻辑
```

全景图适合建立大空间和室外空间。室内空间如果角度变化太大，纯全景展开容易畸变；此时多宫格或手动反打比全景截图更可靠。

## 13. 道具资产协议

道具资产相对简单，但它经常承担剧情证据、身份凭证、关系信物或触发事件的功能。不要把它当作随手生成的小物件。

| 要求 | 原因 |
| --- | --- |
| 单件物品 | 防止模型把多个相似物混成一个 |
| 纯白底 | 方便后续融合到场景和分镜中 |
| 无人物 | 避免手、身体、背景污染道具身份 |
| 符合时代气质 | 古装道具不能出现现代材质、现代文字或简体字 |
| 结构清楚 | 关键形状、材质、磨损、纹样要可辨识 |
| 剧情功能明确 | 是钥匙、对牌、信物、药瓶还是凶器，必须服务剧情 |

如果道具上必须有文字，优先把文字作为后期可控设计层处理。图像模型生成文字不稳定，且古装题材应避免简体字误入。

## 14. 输出包规范

面向一集 AI 短剧，资产构建阶段的交付包至少包含：

```text
1. 剧本梗概
2. 主要角色清单
3. 每个主要角色的人物小传和视觉关键词
4. 每个主要角色的正面定妆图 prompt 与候选图
5. 每个主要角色的四视图 prompt 与定稿图
6. 必要的角色状态变体、表情卡或动作卡
7. 本集核心场景库
8. 核心场景空镜全景图 prompt 与定稿图
9. 必要的 2x2 多视角场景图、单视角高清图或反打场景图
10. 关键道具清单、道具白底图 prompt 与定稿图
11. 必要的道具多角度图、细节图或状态图
12. 生成记录：prompt、模型/API、参考图、版本
13. QA 记录：通过项、返修项、风险项
```

这个输出包是后续 [[domains/视觉制作/06-AI视频/02-导演思维/03-导演式镜头设计方法|导演式镜头设计]]、[[domains/视觉制作/06-AI视频/05-视频生成/05-AI视频导演Prompt模板|视频生成 prompt]] 和剪辑连续性的输入，不是孤立的美术稿。

## 15. Agent 使用模板

当用户给出短剧剧本并要求做角色、场景、道具资产时，Agent 不要直接输出图片 prompt。先按下面步骤工作：

```text
1. 读剧本，提取本集剧情梗概。
2. 列出角色、场景、道具三张清单，标记主次。
3. 为主要角色生成角色资产协议。
4. 判断赛道/受众：男频、女频、悬疑、古风、现代、科幻等。
5. 按角色资产库清单判断每个角色要生哪些图。
6. 输出角色正面定妆图 prompt，生成或规划候选图，并按 QA 表筛选。
7. 对通过的角色输出四视图 prompt；需要时补状态变体、表情卡、动作卡。
8. 输出场景库，判断每个场景要生全景、多宫格、单视角高清、反打还是光影变体。
9. 输出对应场景 prompt。
10. 判断每个道具要生白底主图、多角度、细节图、状态图还是尺度参考。
11. 输出道具 prompt。
12. 汇总资产包、版本记录和下一步分镜使用建议。
```

执行边界：

- 可以调用图像生成 API、图像编辑 API、内部 Skill 或本地脚本。
- 不依赖 LibTV、即梦等特定平台；除非用户明确要求使用某平台。
- 涉及具体模型价格、审核政策、可参考图数量、最高分辨率时，必须按当前官方文档或实际 API 测试复核。
