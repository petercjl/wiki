# AI短视频图片与控制资产

图片资产不是装饰性前期稿，而是视频模型的控制接口。资产数量不以“越多越好”或“越少越好”决定，而以缺少该资产是否会造成明确失控决定。

## 资产职责

| 资产 | 主要锁定内容 |
| --- | --- |
| 角色身份板 | 身份、服装状态、体态和可识别特征 |
| 产品/道具图 | 结构、材质、颜色、文字、连接关系和操作事实 |
| 场景资产 | 空间、时代、材质、陈设和反打关系 |
| 基调图 | 项目整体世界、色彩、质感和情绪方向 |
| 故事板/分镜图 | 镜头顺序、构图、人物关系和剪辑意图 |
| 首帧/尾帧 | 单镜头起始与结束状态、运动边界和连续性 |
| 操作参考 | 产品真实动作、机构关系和禁止误读 |

## 阶段门禁

- 每张资产都有唯一主要职责，并能对应一个明确风险。
- 产品和人物事实以参考图为准，不用长文本重建参考中已经清楚的信息。
- 图片 Prompt 能追溯到分镜任务，生成图片能按构图、身份、空间和用途验收。
- 只有通过检查的资产才进入 [[domains/视觉制作/06-AI视频/05-视频生成/index|视频生成]]。
