# 导演决策到图片Prompt的转换协议

本协议解决一个生产断点：上游已经有剧本、导演意图和分镜，但图片 Prompt 仍然只写“电影感、精致光影、某导演风格”。转换的目标不是让 Prompt 更长，而是让关键导演决策进入参考选择、画面控制和验收标准。

## 输入合同

生成图片前至少取得：

| 输入 | 必须明确的内容 |
| --- | --- |
| 剧本依据 | 当前场景、人物任务、冲突或变化 |
| 导演意图 | 观众应知道、感受、期待什么 |
| 镜头任务 | 建立世界、人物、关系、处境、产品动作、转折或收束 |
| 分镜字段 | 景别、机位、构图、站位、关键动作、光色、前后衔接 |
| 事实来源 | 人物、产品、场景、道具和品牌参考图 |
| 资产用途 | 身份板、基调图、场景图、分镜首帧、尾帧或操作参考 |

如果这些输入缺失，先返回对应上游阶段补齐，不用风格词猜测导演意图。

## 转换表

| 上游决策 | 图片中的可见控制 | Prompt 或参考承担方式 | 验收 |
| --- | --- | --- | --- |
| 观众与人物保持距离 | 大空间、人物占比小、环境信息优先 | 写景别、主体占比和空间关系 | 人物没有自动变成中近景主体 |
| 观众进入人物内心 | 更近景别、表情或手部微动作、背景弱化 | 写景别和一个可见情绪动作 | 情绪由动作或表情成立，不靠抽象词 |
| 建立两人关系 | 距离、朝向、视线、遮挡和前中后景 | 写双方关系和构图；身份由角色参考承担 | 谁看谁、谁靠近谁可被直接读懂 |
| 产品是叙事答案 | 产品处于人物动作的因果位置 | 产品图锁定事实，Prompt 写人物如何使用和为何此刻出现 | 产品不是孤立贴片，外观没有变形 |
| 压迫、释放或转折 | 开闭构图、空间密度、光色和方向变化 | 写可见的构图与光线关系 | 去掉情绪形容词后画面仍能表达变化 |
| 镜头需要衔接 | 动作相位、视线方向、主体位置、光线状态 | 继承上一镜状态，写本镜差量 | 与前后镜能够剪接，不发生方向跳变 |

## 参考分工

图片生成必须先给每张参考指定职责：

```text
人物参考：身份和当前服装状态
产品参考：全部可见产品事实和连接关系
场景参考：空间、材质、陈设和时代
构图/分镜参考：主体位置、景别、站位和视线
风格参考：色彩、反差、质感和摄影气质
```

一张图可以承担多个兼容职责，但不能默认“多放一张总会更稳”。每增加一张参考，都要说明它解决哪个明确风险；若职责冲突，优先保留身份、产品结构、剧情空间和本镜构图。

## Prompt骨架

```text
【用途与镜头任务】
这是 {{资产类型}}，服务于 {{镜头任务}}；观众应从画面中感知 {{观众经验目标}}。

【参考锁定】
人物、产品、场景或道具身份遵循对应参考图。
所有可见结构、比例、组件位置、材质、颜色、文字、标识和连接关系遵循参考；不要增加、删除、移动或重新设计可见组成。

【本镜可见事实】
{{景别与机位}}；{{构图、主体位置和空间关系}}。
{{人物或产品的一个关键动作/状态}}。
{{参考图没有提供但本镜需要的光线、天气或环境变化}}。

【与前后镜关系】
继承 {{上一镜状态}}；为 {{下一镜动作或切点}} 保留 {{位置、方向、视线或动作相位}}。

【限制】
不要发明产品部件、控制、文字、标记、附件、效果或界面元素；不要移动或重新解释参考中可见组件的关系。
```

没有参考图时，才用必要文字描述身份或结构；有清晰参考时，不把详细产品结构重新抄进 Prompt。

## 资产级验收

1. **叙事**：图片是否完成对应镜头任务，而不只是好看？
2. **身份**：人物、产品、道具和场景是否忠于参考？
3. **构图**：景别、机位、比例、方向、站位和视线是否正确？
4. **连续性**：与前后镜共享的状态是否保留？
5. **可生成性**：这张图能否直接作为视频参考，动作起点是否清楚？
6. **成本**：它是否解决了明确风险；若没有，是否应从参考输入中移除？

## 失败回路

| 失败 | 优先修复 |
| --- | --- |
| 人物或产品变形 | 回到真实参考，减少文字重绘和冲突参考 |
| 构图不服从 | 增加真实构图/分镜参考、区域控制或确定性合成 |
| 朝向或比例错误 | 使用画布方向、主体轴线、环境线和关系锚点 |
| 风格正确但故事错误 | 回到镜头任务和观众经验，不继续堆风格词 |
| 多参考互相污染 | 做单变量删减测试，只保留有证据提高控制力的参考 |

每次修复只改导致失败的控制层，并保留失败原因，供视频生成阶段判断参考资产是否可靠。
