# AI品牌TVC的气质、视觉符号与产品登场

本页解决 TVC 创意阶段的三个连续决策：

1. 产品应该进入一个怎样的品牌世界；
2. 抽象价值怎样变成观众能看见、听见的证据；
3. 产品在什么时机、以什么强度登场。

这三步不是“高级感公式”。它们必须从已确认的产品研究、目标人群、使用场景和广告任务出发。产品图片此时用于理解产品，不等于已经选定的生产素材；后续仍要重新选择或制作合格的身份参考。

> 主线：产品与人群事实 → 气质坐标 → 可见证据 → 产品登场策略 → 分镜功能 → 资产与生成门禁。

## 1. 开始前需要什么

从前置调研接收以下信息：

| 输入 | 最低要求 | 不能怎样处理 |
|---|---|---|
| 产品事实 | 已确认的外形、品类、功能或利益点；未知项明确标记 | 不从图片猜材质、性能、尺寸、认证或安全性 |
| 目标人群 | 生活阶段、使用处境、主要欲望或顾虑 | 不只写“年轻人”“高端人群” |
| 使用场景 | 产品真实进入生活的时刻、人物和动作 | 不先套模板场景 |
| 广告任务 | 平台、时长、传播目的、语气、允许与禁止的主张 | 不先写“电影感大片” |

若这些输入缺失，应返回产品调研或广告简报，不要用视觉风格掩盖事实空洞。可先读 [[domains/视觉制作/06-AI视频/01-项目定义与剧本/02-AI商业短视频规划方法|AI商业短视频规划方法]]。

## 2. 气质不是一个形容词，而是一组协调关系

“高级、治愈、自由、科技、温暖”都只是方向词。能够指导分镜的气质，至少要协调以下七项：

```text
产品真实特征
× 目标人群的欲望
× 核心情绪
× 向往的生活场景
× 人物状态
× 光色与材质感
× 镜头、节奏与声音
```

可以用一张气质坐标表完成决策：

| 维度 | 要回答的问题 | 输出示例 |
|---|---|---|
| 产品依据 | 哪个已确认事实支持这种气质 | 造型克制、适合家庭共餐 |
| 人群欲望 | 用户真正向往什么状态 | 忙碌后仍能轻松相聚 |
| 核心情绪 | 观众最终应感到什么 | 放松、亲近、被照顾 |
| 场景 | 哪个真实或向往场景能承载它 | 周末傍晚的家庭桌面 |
| 人物 | 人物在做什么，而非“是什么人设” | 自然分工、交谈、递食物 |
| 光色 | 光线和色彩怎样统一情绪 | 温暖自然光，克制对比 |
| 视听 | 镜头、节奏和声音怎样支持 | 近距离观察、留有呼吸、真实环境声 |

### “高级场景”不是昂贵场景

所谓“高级”，更稳妥的解释是：**目标人群向往、且与产品关系成立的生活状态。**

例如，面向成熟家庭人群的礼赠产品，健康、团聚和被子女惦记，可能比豪宅、大理石和礼服更有价值；面向户外运动人群的产品，身体舒展、风、路面和速度，可能比摄影棚更可信。场景贵不贵，不决定广告有没有品牌感。

### 气质校验

- 产品依据被拿掉后，这套气质是否仍适用于大量无关产品？
- 人物是在“表演高级”，还是正在做与价值有关的动作？
- 场景是用户向往的状态，还是创作者自己的审美炫技？
- 光色、镜头、节奏和声音是否在表达同一情绪？

如果答案高度可替换，应回到产品事实与人群欲望重新定位。

## 3. 把抽象价值翻译成可见证据

观众看不见“自由”“治愈”“安全”“品质”，只能看见动作、环境、材质变化、人物反应和结果。视觉符号的任务，是把形容词变成可验证的视听事件。

```text
价值词
→ 用户在哪个时刻会感到它
→ 哪个动作或环境变化能证明它
→ 产品怎样参与因果
→ 镜头和声音怎样让观众感知
```

| 抽象价值 | 弱表达 | 更可执行的证据方向 |
|---|---|---|
| 自由 | 人物站在大景里，字幕写自由 | 路径打开、身体舒展、速度或空间变化，并让产品参与行动 |
| 治愈 | 暖色房间、宠物、窗帘 | 紧张状态因某个具体使用动作而缓下来 |
| 安全 | 蓝色科技光、盾牌图标 | 风险出现后，人物动作或结果保持稳定 |
| 品质 | 慢镜头、水滴、金属反光 | 精确操作、触感反馈、稳定结果或细节工艺被看见 |
| 亲密 | 一家人微笑合影 | 递、等、分享、照顾等关系动作 |

候选符号至少过两项测试：

1. **产品因果测试**：产品是否使这个动作、结果或情绪发生？
2. **替换测试**：换成同类或无关产品后，画面是否几乎不变？

若产品只是最后贴上去的 packshot，前面所有“高级空镜”都可能只是可替换装饰。先修因果关系，再修画面美感。

### 从视觉符号到镜头任务

不要让模型直接“写一个高级 TVC”。先把候选符号写成若干可比较的镜头任务：

| 字段 | 问题 |
|---|---|
| 镜头功能 | 这一镜建立世界、人物、问题、价值证据、产品线索，还是英雄亮相 |
| 可见事件 | 画面里具体发生什么 |
| 产品关系 | 产品是原因、工具、对象、结果，还是仅作识别 |
| 观众感知 | 不看解释时，观众能读到什么 |
| 连续性 | 它怎样承接上一镜、推动下一镜 |

镜头设计方法见 [[domains/视觉制作/06-AI视频/02-导演思维/03-导演式镜头设计方法|导演式镜头设计方法]]。

## 4. 产品登场时机是策略，不是固定套路

“先拍氛围，最后才出现产品”只适用于部分品牌片。登场时机由传播目的、总时长、平台观看习惯、产品陌生度和最低有效曝光共同决定。

| 情况 | 更合适的策略 | 风险 |
|---|---|---|
| 约 5–10 秒、电商转化或信息密集 | 产品尽早出现，或贯穿全片 | 延迟后只剩一瞬 packshot，识别不足 |
| 约 15–30 秒、兼顾情绪与识别 | 前段给产品线索，中段建立使用关系，后段英雄亮相 | 只见氛围，不知卖什么 |
| 约 30–60 秒品牌片 | 可渐进延迟主产品亮相，让世界、人物和价值线索先积累 | 前段符号与产品无因果，结尾像贴片 |
| 新品或新形态 | 更早建立类别与外形识别 | 悬念过长导致认知成本过高 |
| 成熟品牌、强识别资产 | 可依赖颜色、声音、人物或局部细节逐步提示 | 过度自信，高估受众识别能力 |

### 产品登场阶梯

以下不是每次都必须走满的固定步骤，而是一组可选择、可压缩的镜头功能：

```text
品牌世界
→ 人物状态
→ 价值线索
→ 产品线索（颜色、轮廓、声音、局部或使用结果）
→ 产品参与动作
→ 英雄亮相
→ 品牌收束
```

判断登场方案时问：

- 观众最晚在第几秒必须知道广告类别或产品？
- 主产品总共获得多少有效可见时间？
- 登场前的每个镜头都在积累同一个产品价值吗？
- 英雄亮相是前面因果的结果，还是突然出现的包装图？
- 如果平台静音或用户中途划走，核心识别还剩多少？

## 5. 产品参考不是“理解图片”的自然延续

创意阶段收到的图片可以帮助理解外形、使用方式和品类，但不自动成为后续生成用的生产资产。进入资产阶段时，应重新确认：

- 哪张原始产品图作为身份真值；
- 是否需要精修主参考、细节参考、使用参考或多角度参考；
- 哪些角度仍然缺失；
- 哪些误读绝对不能沿用；
- 每张参考图服务哪个具体镜头。

所有可见产品结构、比例、部件位置、材质、颜色、文字、标识和连接关系以批准的原始参考为准；不要用长篇结构描述重新“画一遍产品”。若缺角度，应从真实参考最小改写地生成候选关键帧，并在进入视频前验收。

直播中的虚拟运动鞋案例说明了多角度参考的价值，也暴露了边界：写了“一致”并不能保证不变形；失败衍生图不能成为下一轮的身份来源。它是跨品类方法案例，不是本页的默认产品。

## 6. 把昂贵生成放在确认门之后

AI 能缩短执行时间，但不会自动替代产品分析、定位、创意、分镜、资产、声音和剪辑。一个稳定的 TVC 工作流应把语义决策与算力消耗分开：

```text
读取已确认调研
→ 只分析气质、价值证据和登场策略
→ 人工确认
→ 只输出脚本/分镜
→ 人工确认
→ 只输出资产清单与生成提示
→ 人工确认
→ 每次生成一个资产或一个片段
→ 单项验收
→ 局部修复
→ 汇编与剪辑
```

### 每个门的停止条件

| 门 | 未通过时不要做什么 | 通过标准 |
|---|---|---|
| 调研门 | 不写故事和视觉气质 | 产品事实、人群、场景、广告任务可追溯 |
| 创意门 | 不生成图片 | 气质、符号、产品因果和登场策略已确认 |
| 分镜门 | 不批量生成 | 每镜功能、时长、连续性和产品露出明确 |
| 资产门 | 不生成视频 | 身份参考、镜头参考和禁错项通过 QA |
| Prompt 门 | 不提交高成本任务 | 参考职责、动作、声音、节点数量和参数明确 |
| 单镜验收门 | 不继续后续镜头 | 产品、人物、动作、构图、运动和连续性合格 |

预设 Skill 常见的失败不是“不会生成”，而是没有检查用户已经提供了什么：重复生成多角度图、创建无用节点，或把两段就能完成的片子扩成四段。工作流必须先盘点输入，再决定节点；不得硬编码某个案例品类或固定资产数量。

### 重复失败时

连续失败通常不是“再抽一次”能解决的问题。达到项目预设的失败预算后，应停止并诊断：

- 参考图是否不足、冲突或已经漂移；
- 一个镜头是否装了太多动作；
- 产品是否需要补真实角度；
- 是否选错生成模式；
- Prompt 是否在重复参考图已经承担的视觉事实；
- 是否应该拆镜、改用首尾帧、遮罩或后期。

直播提出“三次失败后重写”作为控费经验。实际项目可以设置别的阈值，但必须有停止条件。

## 7. 生成、修复与声音边界

资产通过后，按自然镜头与约束负载编写生成 Prompt，方法见 [[domains/视觉制作/06-AI视频/05-视频生成/13-AI短视频生成提示词方法论：TVC与剧情短片|AI短视频生成提示词方法论：TVC与剧情短片]]。

执行原则：

- 一次只生成已批准的一个资产、节点或片段；
- 明确时长、画幅、分辨率、数量和参考职责；
- 参考图负责身份，文字主要写镜头、动作、时序、情绪和声音；
- 某一镜失败时，优先提取合格衔接帧并局部重做，不重跑全部镜头；
- 最终会统一配乐的项目，每个生成片段都写“不要任何背景音乐”；
- 允许真实环境声、已指定对白或声线参考，整片 BGM 在剪辑完成后统一处理。

## 8. TVC验收表

### 商业与创意

- [ ] 广告任务和产品事实没有被视觉风格改写
- [ ] 气质来自产品与人群，而非套用“高级感”
- [ ] 抽象价值已经变成可见、可听的证据
- [ ] 核心符号通过产品因果与替换测试
- [ ] 产品登场时机符合平台、时长与传播目的
- [ ] 产品获得足够而清晰的有效曝光

### 资产与生成

- [ ] 原始批准产品图是唯一身份真值
- [ ] 每张参考图都有明确镜头职责
- [ ] 没有用失败衍生图继续生成产品
- [ ] 每次生成的节点、数量和成本边界明确
- [ ] 失败镜头被局部修复，而非无控制全量重跑
- [ ] 生成片段没有背景音乐，最终声音在剪辑阶段统一

### Skill化

- [ ] 流程先读取已有输入，不重复生产
- [ ] 案例产品、时长、资产数量和工具没有被硬编码
- [ ] 有确认门、错误分支、停止条件和返回主线规则
- [ ] 已在干净上下文、跨品类输入中验证

一次成功的对话只能说明流程“可能可用”。要把它变成 Skill，还需明确输入输出契约、机器可读交接、覆盖式更新策略、QA 与跨环境测试。

## 9. 与五个Skill的边界

| Skill | 本页提供什么 | 不替它做什么 |
|---|---|---|
| 1 产品广告简报 | 接收产品事实、人群、场景和广告任务 | 不从理解图片代替产品调研 |
| 2 TVC创意与分镜 | 气质、视觉证据、产品登场和镜头功能 | 本页的核心归属 |
| 3 TVC资产规划 | 给出镜头需要哪些参考职责 | 不直接认定已有图片就是生产资产 |
| 4 TVC资产生成与审核 | 提供产品一致性和门禁原则 | 不替代逐资产 QA |
| 5 视频生成Prompt包 | 交接已批准镜头和参考职责 | 不把长提示词提前塞回创意阶段 |
