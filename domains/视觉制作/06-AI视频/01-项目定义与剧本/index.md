# AI短视频项目定义与剧本

本阶段决定“为什么拍、为谁拍、讲什么”。TVC、品牌故事、情感短片和短剧都需要剧本，但进入剧本前还要明确平台、时长、受众、产品事实、传播任务和交付目标。

## 推荐读取顺序

1. 先用 [[domains/视觉制作/06-AI视频/01-项目定义与剧本/01-产品销售型短视频剧本双路线|产品销售型短视频剧本双路线]] 选择产品介绍型 TVC 或情感故事软广，再用 [[domains/视觉制作/06-AI视频/01-项目定义与剧本/02-AI商业短视频规划方法|AI商业短视频规划方法]] 完成共同商业底座。
2. 产品介绍型 TVC：[[domains/视觉制作/06-AI视频/01-项目定义与剧本/03-产品介绍型TVC信息结构与AV脚本|产品介绍型TVC信息结构与A/V脚本]] → [[domains/视觉制作/06-AI视频/01-项目定义与剧本/04-AI品牌TVC的气质、视觉符号与产品登场|AI品牌TVC的气质、视觉符号与产品登场]]。
3. 情感故事软广：从 [[domains/视觉制作/06-AI视频/01-项目定义与剧本/05-情感故事软广从命题到文学剧本|情感故事软广从命题到文学剧本]] 开始，依次使用 `06–14` 的故事开发、剧本格式、场景、动作、对白与潜台词知识。
4. 完稿后使用 [[domains/视觉制作/06-AI视频/01-项目定义与剧本/15-商业短片改稿与验收|商业短片剧本改稿与验收]]，再按任务选择 `16–17` 的 Agent 模板。
5. 进入导演与分镜前，使用 `18–19` 检查剧本到镜头的拆解边界、视觉结构与节奏意图。
6. 对照案例：[[domains/视觉制作/06-AI视频/90-案例库/10-生活边缘椅子抱枕：产品TVC与情感软广双路线|生活边缘椅子抱枕双路线案例]]；Agent 查询入口：[[queries/AI短视频故事策划|AI短视频故事策划入口]]。

## 阶段输出

- 项目简报：平台、画幅、时长、受众、目标和交付限制。
- 产品或主题事实：可用证据、不可虚构内容和表达边界。
- 故事命题：人物处境、想要、阻碍、关键动作、变化和余味。
- 剧本：场景、人物动作、对白、旁白和声音意图。
- 稿型选择：产品介绍型 TVC 以 A/V 双栏稿为主；情感故事软广先写文学剧本，再按需要转执行稿。
- 导演交接：每一段要让观众知道什么、期待什么、感受什么。

## 边界

- 本阶段可以提出视觉意图，但不直接用景别、运镜和风格词代替故事判断。
- 分镜字段进入 [[domains/视觉制作/06-AI视频/03-分镜脚本/index|分镜脚本]]；模型 Prompt 进入 [[domains/视觉制作/06-AI视频/05-视频生成/index|视频生成]]。
- 第一批已定向重编剧作书籍中的场景、动作、对白、潜台词、格式与改稿知识；其他章节仍按后续问题分批重编。本阶段不清理旧页中的重复或冲突内容。
