# 人物动机阻碍与转变

## 问题定义

短视频里的人物不需要复杂履历，但必须有清楚动机。观众愿意看下去，是因为看见一个人想要某件事、被某种阻碍卡住，并在短时间内做出一个可见选择。

对产品广告来说，人物不是“目标人群拟人化”，而是产品价值的试验场：产品能不能改变他的任务、关系、状态或自我判断。

## 核心模型

```text
人物状态
-> 想要
-> 阻碍
-> 代价
-> 关键动作
-> 转变
```

| 字段 | 问题 | 画面化方式 |
| --- | --- | --- |
| 人物状态 | 他现在处于什么压力、关系或身份中？ | 空间、服装、动作习惯、手边物件 |
| 想要 | 他真正想得到、保住或逃离什么？ | 视线、反复动作、未完成任务 |
| 阻碍 | 是外部环境、关系、心理还是时间？ | 空间阻隔、他人反应、倒计时、沉默 |
| 代价 | 如果不行动会失去什么？ | 错过、失控、关系疏远、情绪累积 |
| 关键动作 | 哪个动作让变化开始？ | 拿起、递出、打开、拍下、倒出、放下 |
| 转变 | 结尾状态有什么不同？ | 同一物件/空间/动作意义改变 |

## 动机要具体到动作

| 抽象动机 | 可拍动机 |
| --- | --- |
| 她想被理解 | 她把做好的饭放在门口，没有敲门就转身离开 |
| 他想保存记忆 | 他举起手机，对准孩子画在墙边的一张歪斜小画 |
| 她想放松 | 她关掉电脑通知，把杯子推到窗边，坐下不再解释 |
| 他想逃离系统 | 他把记忆卡藏进袖口，故意慢半拍走向机器 |

AI prompt 不能只写“人物很想念”“人物很焦虑”。必须写动作、物件、空间和反应。

## 阻碍类型

| 阻碍 | 适合故事 | 产品关系 |
| --- | --- | --- |
| 物理阻碍 | 空间不够、路途远、时间赶、东西乱 | 产品作为功能答案 |
| 关系阻碍 | 不会表达、误解、距离、代际差 | 产品作为连接媒介 |
| 心理阻碍 | 不敢停下、不敢靠近、不敢承认需要 | 产品作为仪式或许可 |
| 世界规则阻碍 | 系统限制、文化规则、时间不可逆 | 产品/主题作为规则中的关键物 |

没有阻碍，产品就没有必要出现。阻碍越具体，产品越自然。

## 转变必须可见

转变不是“人物成长了”，而是同一动作或物件在片头片尾意义不同：

- 片头她反复看手机等待消息；片尾她用手机记录孩子的一句话。
- 片头杯子是桌面杂物；片尾倒酒成为给自己许可的仪式。
- 片头车厢装不下混乱生活；片尾后备箱让家庭动线恢复秩序。
- 片头母亲不会使用外卖软件；片尾外卖成为她新的照顾方式。

这种首尾呼应，比解释性旁白更有力量。

## 人物质检

- 人物是否有一个现在必须处理的任务？
- 阻碍是否在画面里看得见？
- 产品是否介入了关键动作，而不是只在片尾出现？
- 人物转变是否能用同一物件、同一空间或同一动作对比出来？
- 情感短片是否避免把人物写成单纯受害者或口号载体？
- 多人物广告是否让每个人承担不同关系功能，而不是重复同一情绪？
