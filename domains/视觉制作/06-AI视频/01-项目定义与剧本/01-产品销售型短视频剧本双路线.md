# 产品销售型短视频剧本双路线

## 范围

当前知识库中的“短视频剧本”首先服务产品销售。它可以讲产品，也可以讲人物和情感，但最终都必须让观众形成更清楚的产品理解、购买理由或品牌偏好。

本阶段暂不把纯艺术短片、院线长片、连续短剧和纯 IP 世界观当作主线。它们的剧作知识可以补充方法，但不能改变商业任务。

## 两条主路线

| 维度 | 产品介绍型 TVC | 情感故事型软广 |
| --- | --- | --- |
| 叙事中心 | 产品、使用、利益、证据 | 人物、处境、选择、变化 |
| 观众首先理解 | 这是什么、有什么用、为何不同 | 这是谁、遇到什么、为何改变 |
| 产品作用 | 被展示、被使用、被证明 | 触发器、行动工具、关系物证、变化载体 |
| 常用结构 | 钩子→核心承诺→证明→结果→行动 | 处境→重复/阻碍→触发→关键行动→新状态→品牌余味 |
| 主稿型 | A/V 双栏脚本 | 文学剧本，确认后再转 A/V 执行稿 |
| 主要风险 | 信息堆积、像详情页念稿 | 故事成立但产品可被替换、结尾硬贴品牌 |

TikTok 官方品类建议中存在 Product-Led 与 Talent/Story-Led 的区分；本页结合用户当前业务，把它进一步编译成“产品介绍型 TVC / 情感故事型软广”两条生产路线。该中文模型是知识库应用，不冒充平台原始完整分类。

## 路线选择

优先选择产品介绍型 TVC，当：

- 新产品需要先建立品类认知；
- 核心差异可以通过演示、材质、使用或对比被看见；
- 观众购买前的主要障碍是“不知道是什么、怎么用、为何值得”；
- 多数素材本身就是产品图、使用图和细节图；
- 投放目标更接近考虑与行动。

优先选择情感故事型软广，当：

- 产品的价值主要来自情绪、身份、关系、仪式或文化含义；
- 商品本身简单，但背后的用户处境值得被看见；
- 产品能够参与关键选择，而不是只在结尾出现；
- 品牌希望观众先产生认同，再理解产品；
- 有足够时长建立人物重复、触发和变化。

混合路线只有在两个问题都回答清楚时成立：故事为什么需要产品，产品凭什么能被观众理解。混合不等于两条片子各写一半。

## 先锁定共同商业底座

无论走哪条路线，写稿前都要填写：

```text
产品事实：直接可见 / 商品页声称 / 仍待确认
目标受众及具体处境：
传播目标：认知 / 考虑 / 行动 / 品牌偏好
单一核心承诺：
必须表达的一个主卖点：
支持它的证据或动作：
品牌记忆物：
观众看完后的下一步：
不能写的承诺：
```

多个卖点不能并列抢夺主线。可以用一个主承诺统领若干证明，但每个证明必须回答同一个购买问题。

## 五种交付物不能混淆

| 交付物 | 回答的问题 | 不应包含 |
| --- | --- | --- |
| 广告命题 | 观众最终相信什么 | 完整情节和镜头参数 |
| 故事梗概 | 大致发生什么 | 全部对白、景别和运镜 |
| 分场大纲 | 每场发生什么变化 | 摄影执行细节 |
| 文学剧本 | 人物在何时何地做什么、说什么 | 大量焦段、机位、运镜 |
| A/V 脚本 | 每一时段观众看到与听到什么 | 每个画面的详细镜头语言 |

分镜脚本才决定景别、机位、镜头运动、起止帧和镜头衔接。A/V 脚本可以写必要画面关系和字幕，但不能因此自动等于分镜。

## 路线验收

- 产品型 TVC：关掉声音仍能理解主要产品价值；只听声音也不会变成参数朗读。
- 故事软广：拿掉产品后，人物的关键行动或结局会失去成立条件。
- 两条路线：观众都能说出产品是什么、片子想让我相信什么、下一步是什么。
