# 创意记忆点与传播钩子

## 问题定义

短视频故事讲完以后，观众不一定记得品牌。广告创意需要把故事压成一个可复述的核心：一个反差、一个具体物件、一个动作、一句命题或一个世界规则。

Heath 兄弟的 SUCCES 模型和 Sullivan 的广告创意原则可以转成 AI 短视频的记忆点检查：简单、意外、具体、可信、有情绪、以故事承载。

## 核心模型

```text
单一核心想法
-> 意外入口
-> 具体物件/动作
-> 可信处境
-> 情绪利益
-> 故事承载
-> 品牌收束
```

## 六类记忆机制

| 机制 | 短视频用法 | 风险 |
| --- | --- | --- |
| 简单 | 只保留一个核心命题 | 把简单误解成空泛口号 |
| 意外 | 开头制造视觉问题或反常物件 | 为反转而反转，伤害产品可信度 |
| 具体 | 用物件、动作、声音替代抽象词 | 只堆细节，不服务命题 |
| 可信 | 场景、人群、产品使用方式真实 | 过度纪实导致不够鲜明 |
| 情绪 | 让观众感到“这说的是我” | 情绪泛滥或鸡汤化 |
| 故事 | 用人物选择承载产品价值 | 剧情太长，产品失焦 |

## 钩子类型

| 钩子 | 观众问题 | 示例 |
| --- | --- | --- |
| 反常物件 | 这个东西为什么在这里？ | 便利店柜台上有一张旧电话卡 |
| 未完成动作 | 他为什么停住？ | 父亲举起手机，却没有按下快门 |
| 关系距离 | 他们之间发生过什么？ | 母亲在厨房学点外卖，没有告诉孩子 |
| 时间压力 | 如果再晚一点会怎样？ | 记忆清除机器倒计时 |
| 功能摩擦 | 这个麻烦怎么解决？ | 后备箱前堆着孩子画板、行李和折叠椅 |

钩子不是大声喊“你一定要看完”，而是让观众自然产生问题。

## 记忆点四件套

```text
一句命题：轻松不用等谁批准
一个物件：一杯低度果酒
一个动作：关掉电脑通知，给自己倒一杯
一个收束画面：湖边或窗边，人物终于坐下
```

好的广告短片至少要有其中两件。只有命题没有物件，会像文案；只有物件没有命题，会像素材。

## 品牌收束

产品营销短视频的结尾要把故事记忆和产品价值扣在一起：

- 不要前面讲故事，最后突然硬切产品大字报。
- 产品名、品牌句、logo 应该像故事得出的结论。
- 片尾最好回应开头的物件、动作或问题。
- 高客单产品可以收束身份和意义；低客单产品应收束具体使用场景。

## Agent 使用提示

每个故事方案必须输出：

```text
核心命题：
开头钩子：
反常/意外点：
具体物件：
关键动作：
观众情绪：
品牌收束句：
可以复述的一句话：
避免的俗套：
```

如果输出里只有“温暖治愈、高级质感、引发共鸣”，说明还没有记忆点。
