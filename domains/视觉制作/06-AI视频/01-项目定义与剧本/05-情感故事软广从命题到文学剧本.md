# 情感故事软广从命题到文学剧本

## 核心任务

软广不是隐藏产品，而是让产品价值通过人物行动自然成立。故事负责让观众感到“这与我有关”，产品负责让关键变化具备具体载体。

```text
产品事实
→ 用户处境
→ 情绪或关系缺口
→ 人物重复行为
→ 触发事件
→ 关键选择
→ 产品参与行动
→ 可见的新状态
→ 品牌余味
```

## 从命题到事件

广告命题仍是判断句，不能直接当剧情。例如“也要给自己留一个位置”要继续完成四次翻译：

| 层级 | 示例 |
| --- | --- |
| 心理状态 | 她习惯把自己的需要放在最后 |
| 重复行为 | 在不同关系中把位置让给别人 |
| 关键动作 | 第一次亲手为自己清出一个位置 |
| 产品作用 | 椅形抱枕让抽象的“位置”成为可以建立、保留和使用的物件 |

如果只能写出“她感到不被看见”，还没有进入剧本；必须写出观众能看见和听见的事件。

## 五步剧本化

### 1. 写一句故事梗概

格式：一个处于具体状态的人，因为一个触发，做出一个关键选择，产品帮助这个选择落地，最终产生可见变化。

### 2. 建立重复与变化

短片不需要完整人生史，可以用两到三次同构事件快速建立人物模式。重复必须升级或变形，不能只是同一句话换地点。

### 3. 写分场大纲

每场只回答：

```text
人物进入时是什么状态？
他想得到或避免什么？
谁或什么阻碍他？
他采取什么动作？
离开时发生了什么变化？
这场若删除，故事会损失什么？
```

### 4. 确定产品的叙事职位

| 职位 | 定义 | 检查 |
| --- | --- | --- |
| 触发器 | 让人物第一次看见缺口 | 没有它，觉察是否发生？ |
| 行动工具 | 帮人物完成关键动作 | 产品能力是否真实可见？ |
| 关系物证 | 保存、传递或证明关系 | 证据能否被另一人物发现？ |
| 仪式载体 | 让情绪变化成为具体行为 | 行动是否可重复、可记忆？ |
| 身份符号 | 让人物选择被看见 | 是否来自真实设计，而非强行象征？ |

### 5. 写文学剧本

按场景标题、动作、人物和对白展开。此时写“发生什么”，不写完整镜头方案。每一场必须由动作改变状态，而不是由旁白宣布人物成长。

## 产品入场的三个条件

1. 入场前，观众已理解它将回应什么缺口，或入场本身制造这个理解。
2. 入场时，通过人物动作展示真实可支持的价值。
3. 入场后，产品继续参与选择、关系或新状态，而不是完成一次特写后消失。

## 拿掉产品测试

把品牌和产品从剧本删除：

- 如果关键选择仍可由任意物件完成，产品职位太弱；
- 如果故事完全不受影响，产品只是贴片；
- 如果人物必须靠不真实功效才转变，产品职位过度；
- 合格状态是：故事仍像人的故事，但关键行动、证据或结尾因产品而具有独特形态。

## 两分钟的范围控制

两分钟仍属于短片。优先一个主人公、一个主要心理缺口、一条行为重复、一个关键选择和一个余味。背景信息只保留能改变观众理解的部分。

推荐检查而非固定公式：

```text
0–25秒：人物处境与行为模式
25–55秒：重复升级或关系压力
55–80秒：触发与觉察
80–105秒：关键行动，产品参与
105–115秒：新状态
115–120秒：品牌余味
```

## 软广不是隐性欺骗

故事表达仍然属于商业传播。不能虚构使用体验、功效、来源或人物证言；发布时还要遵守广告可识别性和平台标识要求。
