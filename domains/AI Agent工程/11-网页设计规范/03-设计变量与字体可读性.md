# 设计变量与字体可读性

## v0.1 色彩基线

| 语义 | 建议值 | 用法 |
| --- | --- | --- |
| 主色 | `#315BD6` | 选中、主按钮、关键图形 |
| 页面背景 | `#F3F5F7` | 工作区底色 |
| 面板背景 | `#FFFFFF` | 卡片、侧栏、顶栏 |
| 主文字 | `#20242C` | 标题、正文、关键数值 |
| 次文字 | `#6F7784` | 说明、辅助口径 |
| 分割线 | `#E1E5EA` | 卡片边界、表格分隔 |
| 成功 | `#198754` | 正向变化、正常状态 |
| 警告 | `#9A6500` | 样本不足、注意事项 |
| 风险 | `#BD3E3E` | 异常、负向变化、停止线 |

状态不能只用颜色传达；同时使用文字、图标、标签或符号。

## 字体层级

| 内容 | 基线 | 约束 |
| --- | --- | --- |
| 页面标题 | 25px | 清晰但不做巨型封面标题 |
| KPI 数字 | 26px | 使用等宽数字特性，单位与值分层 |
| 模块标题 | 15px | 中等或半粗字重 |
| 正文、表格单元格 | 13px | 高频业务阅读的主基线 |
| 次级说明、图例、状态解释 | 12px | 不得承载唯一关键结论 |
| 键盘提示、微型界面文字 | 10–11px | 仅非关键 chrome 使用 |

**硬规则：用户需要阅读、比较或据此决策的信息原则上不得低于 12px。** 紧凑感应通过网格、间距和信息归组实现，而不是继续缩小字体。

## 行高与密度

- 正文行高：1.5–1.65。
- 模块标题行高：1.3–1.45。
- 表格表头高度：约 44px；正文行高：约 50px。
- 按钮和可点击控件建议不低于 34px 高；移动端触控区域应更大。
- 页面内边距约 24px，卡片内边距通常 12–16px，模块间距 8–12px。
- 圆角 7–10px；同一层级不要混用多个圆角体系。

## 字体与数字

- 优先使用系统无衬线字体栈，避免远程字体成为报告打开的硬依赖。
- 数字使用 `font-variant-numeric: tabular-nums`，提高纵向对比稳定性。
- 金额、比例、次数和日期必须带单位或在列头中明确单位。
- 负号、百分号、小数位和千分位格式在同一模块中保持一致。
- 标签与数值之间保留足够对比，避免浅灰小字叠加造成双重可读性损失。

## 可读性检查

在 100% 浏览器缩放下检查：

1. 图例、表头、卡片副标题、左下状态和快照标签无需放大即可阅读。
2. 主文字与背景达到足够对比；次级文字仍清楚，不使用接近边框灰的颜色。
3. KPI 和变化值不因颜色相近、字重过轻或单位过小而误读。
4. 1440px 桌面和约 390px 移动宽度都不存在通过缩字“塞进去”的情况。
