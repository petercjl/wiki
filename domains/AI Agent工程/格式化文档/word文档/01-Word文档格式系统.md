# Word 文档格式系统

## 核心判断

Word 格式不是一堆“加粗、变色、放大”的按钮，而是四层信息系统。任何格式都应至少回答一个问题：它在表达什么信息角色，帮助读者完成什么阅读动作，或者控制什么页面行为？

| 层级 | 解决的问题 | 典型能力 |
| --- | --- | --- |
| 语义层 | 这段内容是什么 | 标题、正文、引语、列表、题注、脚注、超链接、强调 |
| 导航层 | 读者怎样找到和引用它 | 大纲、目录、页码、页眉页脚、书签、交叉引用、图表目录 |
| 视觉层 | 怎样形成层级、节奏和品牌感 | 字体、字号、字重、颜色、行距、段距、缩进、对齐、边框、底纹、留白 |
| 页面层 | 内容怎样分页、打印和改变版式 | 纸张、页边距、分页、分节、横竖版、分栏、页眉页脚范围 |

## 样式是系统的核心

Word 中应优先使用命名样式，而不是逐段直接设置格式。

### 段落样式

适合定义整段的角色和排版，例如标题、正文、列表、引语、题注。它可以同时控制字体、行距、段距、缩进、分页和大纲级别。

### 字符样式

适合标记段落中的局部语义，例如术语、警告词、代码、书名或轻度强调。它比直接加粗更容易统一更新。

### 表格样式

适合统一表头、边框、底纹、首列、末行和交替行。表格样式解决一致性，但不能修复错误的数据结构。

### 列表样式

适合稳定管理多级编号和项目符号。章节编号、步骤编号与普通清单应使用不同列表体系。

## 常用格式的语义角色

| 格式或组件 | 主要作用 | 不应被当成 |
| --- | --- | --- |
| 标题 | 建立层级、生成大纲与目录 | 仅仅放大的正文 |
| 正文 | 承载连续论述 | 无限加长的单段文字 |
| 项目符号 | 表达并列、无强顺序的项目 | 所有短句的默认形式 |
| 编号列表 | 表达顺序、优先级或可引用步骤 | 装饰性序号 |
| 加粗/字符强调 | 标记局部关键词 | 用来替代标题层级 |
| 引语 | 保留外部声音或案例证据 | 替代作者分析 |
| 信息框 | 隔离提醒、结论、风险或行动 | 大面积彩色正文容器 |
| 表格 | 精确比较、查值和展示规则 | 页面布局工具 |
| 图表 | 展示趋势、构成和关系 | 没有结论的装饰图 |
| 题注 | 命名并编号图表，支持引用 | 手工输入的普通小字 |
| 页眉页脚 | 提供身份、章节、状态和页码 | 重复正文或大面积广告位 |
| 脚注/尾注 | 放置来源或补充说明 | 藏匿正文关键条件 |

## 页面行为也是格式

- **分页符**：明确下一部分从新页开始；不要用连续回车顶到下一页。
- **分节符**：当页眉页脚、页码、纸张方向、栏数或页边距需要改变时使用。
- **与下段同页**：防止标题落在页底而正文跑到下一页。
- **段中不分页**：适合短引语、紧凑步骤或不可拆分的小块，不宜套在超长段落上。
- **表头跨页重复**：长表格必须让读者在每页重新看到列含义。
- **孤行寡行控制**：避免一段文字只剩一行孤立在页首或页尾。

## 主题与品牌变量

主题字体、主题色和样式集应表达品牌，而不是逐处手工染色。一个可维护系统至少定义：

- 中文正文、中文标题、拉丁字母和数字的字体策略；
- 主色、辅助色、中性色和警示色；
- 标题层级、正文、题注、引语、表格的样式；
- 徽标、页眉页脚和封面的使用范围；
- 黑白打印和无颜色状态下的可辨识方式。

## 直接格式的边界

直接格式适合一次性、局部且不需要全局更新的例外。以下情况应升级为样式：

- 同一种格式反复出现；在模板开发中可暂把“出现三次”当作升级检查点，但这是工作启发式，不是 Word 的技术阈值；
- 格式表达稳定的信息角色；
- 以后可能统一换字体、颜色或间距；
- 需要生成目录、交叉引用或自动编号；
- 多人协作容易产生漂移。
