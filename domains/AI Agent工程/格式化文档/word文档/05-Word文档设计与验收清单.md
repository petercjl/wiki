# Word 文档设计与验收清单

## 制作前

- [ ] 已明确读者、阅读任务、交付媒介和篇幅。
- [ ] 已选择文档菜谱，而不是只选择视觉风格。
- [ ] 已定义必须保留的事实、数据、结论和行动。
- [ ] 已确认品牌、保密、打印、协作和可访问性要求。
- [ ] 已决定 Word 正文与 Excel/附件的数据边界。

## 结构

- [ ] 标题能单独说明各节内容，层级连续，没有跳级。
- [ ] 全文只有一个最高级页面标题。
- [ ] 最重要的结论和决策位于前部。
- [ ] 摘要能脱离正文独立阅读。
- [ ] 每节回答一个明确问题，段落顺序支持论证。
- [ ] 长文档有自动目录；图表和附录可被正确引用。

## 样式与一致性

- [ ] 标题、正文、列表、引语、题注和信息框使用命名样式。
- [ ] 没有用空行、空格或制表符模拟布局。
- [ ] 字体、字号、颜色和间距数量受控。
- [ ] 相同信息角色始终呈现为相同样式。
- [ ] 多级列表自动编号，增删项目后仍正确。
- [ ] 直接格式只用于明确的局部例外。

## 阅读与视觉

- [ ] 正文字号、行距、行长和对比度适合目标读者。
- [ ] 标题与后文的视觉距离小于与前文的距离。
- [ ] 强调有层级，没有全篇加粗、满页高亮或多色竞争。
- [ ] 留白用于分组，不是为了填空或制造“高级感”。
- [ ] 封面、摘要、正文、数据和附录页面节奏一致。
- [ ] 黑白打印后仍能辨识层级和状态。

## 表格、图表与图片

- [ ] 表格使用真实结构，表头、单位、来源和注释完整。
- [ ] 长表跨页重复表头，行没有被错误拆分。
- [ ] 合并单元格和空白占位已降到最低。
- [ ] 图表标题表达结论，正文解释意义和限制。
- [ ] 图片清晰、裁切正确，并有题注或替代文本。
- [ ] 过大的数据表已移到 Excel/CSV 附件。

## 页面与导航

- [ ] 分页符和分节符使用正确，没有连续回车顶页。
- [ ] 横向页面只影响需要横向的节。
- [ ] 页码连续，封面、目录和正文的编号规则符合预期。
- [ ] 页眉页脚中的名称、版本、状态和日期准确。
- [ ] 标题没有孤立在页底，正文没有明显孤行寡行。
- [ ] 目录、题注、图表目录和交叉引用已更新。

## 可访问性与协作

- [ ] 标题样式、大纲和阅读顺序正确。
- [ ] 链接文字描述目标。
- [ ] 颜色不是唯一的信息信号。
- [ ] 图片替代文本、表格表头和语言设置正确。
- [ ] 已运行 Word 可访问性检查器。
- [ ] 评论、修订、隐藏文字、文档属性和敏感元数据已处理。

## 发布验证

- [ ] DOCX 可重新打开，样式和域没有损坏。
- [ ] 已渲染或导出 PDF，并逐页检查断页、溢出、空白页和图像清晰度。
- [ ] 在实际交付环境检查字体替换和跨平台差异。
- [ ] 目录链接、书签、交叉引用和外部链接可用。
- [ ] 文件名、版本号、日期和最终状态一致。
- [ ] 保留可编辑源文件；最终交付物与源文件版本对应。

## Agent 完成条件

Agent 不能以“文件已生成”作为完成标准。至少应交付：

1. 输出文件路径；
2. 使用的菜谱和模板版本；
3. 结构与格式改动摘要；
4. 渲染检查结果；
5. 无法验证的字体、域、链接或兼容性风险；
6. 对明显语义错误的修订记录。
