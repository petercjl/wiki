# Word 格式适用场景与误用

## 先判断阅读问题

| 阅读问题 | 优先使用 | 避免 |
| --- | --- | --- |
| 看不出结构 | 标题样式、段距、目录 | 只加粗或变色 |
| 找不到结论 | 执行摘要、结论标题、克制的信息框 | 到处高亮 |
| 步骤难执行 | 编号列表、检查点、预期结果 | 一整段叙述 |
| 多项难比较 | 结构简单的表格 | 用空格对齐或截图 |
| 数据看不出趋势 | 图表 + 结论性标题 + 正文解释 | 三维效果和无来源图表 |
| 文档太长难定位 | 大纲、自动目录、页码、页眉 | 手工目录和手工页码 |
| 格式反复漂移 | 命名样式、主题、模板 | 复制粘贴局部格式 |
| 页面方向需要改变 | 分节符 + 横向页面 | 把整篇文档改成横向 |
| 需要协作审阅 | 修订、评论、文档状态 | 用颜色代表不同作者 |

## 组件选择矩阵

| 组件 | 适合 | 不适合 | 常见误用 |
| --- | --- | --- | --- |
| 一级/二级标题 | 建立章节和小节 | 只想让一句话醒目 | 标题跳级；全篇多个最高级标题 |
| 项目符号 | 并列要点、特征、条件 | 有严格先后关系 | 每段都拆成碎片 |
| 编号列表 | 步骤、优先级、规则引用 | 无顺序的要点 | 手工输入序号导致增删错乱 |
| 加粗 | 句内关键词、短结论 | 整段、整页 | 加粗比例过高，失去对比 |
| 颜色 | 品牌识别、有限状态编码 | 唯一的状态信号 | 颜色过多、对比不足 |
| 底纹/信息框 | 结论、风险、行动、案例 | 连续正文 | 大量彩色框破坏阅读流 |
| 引语 | 证据、原话、用户声音 | 作者自己的核心论证 | 用长引语逃避分析 |
| 表格 | 精确查值、二维比较、规则矩阵 | 长篇叙述、复杂嵌套 | 合并单元格、过宽、字号过小 |
| 图表 | 趋势、构成、相关关系 | 少量可直接写出的数值 | 装饰、无基数、无来源 |
| 图片 | 实物、界面、流程证据 | 可用文字清楚表达的简单关系 | 无题注、无替代文本、分辨率过低 |
| 分栏 | 简报、词条、短块并列 | 长表格、复杂编辑 | 为“高级感”强行分栏 |
| 页眉页脚 | 身份、版本、保密状态、页码 | 放置长说明 | 占用过大、与封面重复 |

## 字体与段落

- 公共报告可把清晰无衬线字体和约 12 pt 视为稳健起点，但中文字体、纸张、读者年龄和输出方式会改变最佳参数。
- 左对齐通常最稳定。两端对齐只在版心、字距、断行和打印效果经过检查时使用。
- 用段前段后和行距建立节奏，不用连续空行制造距离。
- 设计时应共同检查页边距、字号、分栏与阅读宽度；本批来源未给出适用于中文 Word 文档的统一行长阈值。
- 可把“标题更靠近其后正文”作为视觉分组启发式，但具体段距仍需通过真实内容、打印和导出结果验证。

## 表格规则

1. 使用真实 Word 表格。
2. 第一行或第一列提供明确表头。
3. 单位写进列标题，基数、来源和注释放在表下。
4. 数字精度和小数位保持一致。
5. 避免合并单元格、空白占位和多层嵌套。
6. 长表重复表头；不要让单行被无意义拆开。
7. 大表移到 Excel/CSV，Word 正文只保留结论和必要摘要。

## 长短文档的复杂度路由

| 情况 | 推荐复杂度 |
| --- | --- |
| 1—2 页通知或备忘录 | 标题、正文、轻量品牌、必要的行动项 |
| 3—10 页方案或复盘 | 两到三级标题、页码、简短摘要、少量表格图表 |
| 10 页以上报告 | 自动目录、页眉页脚、题注、交叉引用、附录 |
| 持续维护的手册 | 稳定编号、导航、版本状态、术语和索引 |
| 数据附件 | 不强塞 Word；使用电子表格并在正文解释 |

## 可访问性底线

- 标题层级必须连续且由样式表达。
- 链接文字要描述目标，不只写“点击这里”。
- 图片提供替代文本；纯装饰图正确标记。
- 不只靠颜色传递含义。
- 表格保持线性、简单、可由屏幕阅读器理解。
- 发布前运行可访问性检查器并清除隐藏数据。
