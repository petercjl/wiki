# 跨 Agent Skill 注册库

本页是所有 AI Agent skill 的统一检索入口。目标不是只记录“某个 agent 当前能不能直接调用”，而是帮助任何 Agent 回答：我们以前有没有写过类似 skill？它在哪个文件夹？是否可以复用、迁移或改造？

当前覆盖 6 个 Agent / 环境，共 549 个 skill；其中个人/项目自定义 282 个。

## 检索协议

当用户问“有没有类似 skill”“以前是不是写过”“能不能复用某个能力”时，Agent 应按以下顺序处理：

1. 日常先搜索 [[domains/AI Agent工程/90-Skill注册表/01-个人与项目Skill注册库|个人/项目 Skill 注册库]]。
2. 如果个人库没有候选，再搜索本全量页和下方各 agent 注册页的 skill 名称、功能检索描述、输入方式、检索关键词。
3. 找到候选 skill 后，打开对应 `SKILL.md` 文件位置，阅读完整设计内容。
4. 判断可复用方式：直接使用、跨 Agent 迁移、抽取脚本/参考文件、合并重复 skill、或新建 skill。
5. 不因 skill 位于其他 agent 环境就忽略它；大多数 skill 的流程、脚本、参考文件都可以跨环境复用。
6. 执行或迁移前检查运行环境差异：工具名、MCP、浏览器、API key、文件路径、脚本依赖、权限和输出目录。

## 维护规则

- 每个 agent 仍保留独立注册页，避免运行环境混乱。
- 总入口页负责跨 Agent 检索，不负责替代原始 `SKILL.md`。
- 新增、删除或迁移 skill 后，同步更新本页和对应 agent 注册页。
- 不写入真实密钥、cookie、token、客户隐私数据。
- 发现重复 skill 时，不要马上删除；先记录候选重复关系，再决定合并或保留。
