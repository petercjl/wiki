# 广告故事与产品视频质检

广告片的读取目标不是“复述发生了什么”，而是判断成片是否完成预期故事和商业任务，并定位具体失败镜头。

## 先取得目标契约

分析前尽量取得：

- 目标受众与投放场景；
- 核心卖点、品牌语气和 CTA；
- 剧本、分镜、参考图或产品原图；
- 必须保持的角色、产品、文字与合规信息；
- 时长、画幅、字幕、安全区和平台规范。

没有目标契约时，只能做技术和观感诊断，不能断言广告“策略错误”。

## 五条读取线

### 1. 故事与商业线

- 开头是否快速建立人物处境或用户问题；
- 人物想要什么，阻碍是什么；
- 产品是解决方案、触发器、证据还是背景道具；
- 是否有明确变化、转折或结果；
- 品牌/产品记忆点是否出现在观众注意力高点；
- CTA 是否自然、明确且与故事承诺一致。

### 2. 镜头与剪辑线

逐镜记录：

| 字段 | 内容 |
| --- | --- |
| 时间码 | 起止时间 |
| 景别/机位 | 全景、中景、特写；平视、俯拍等 |
| 运动 | 主体动作、摄影机运动 |
| 光线/色彩 | 情绪和产品可见性 |
| 声音 | 对白、环境、音效、音乐变化 |
| 叙事功能 | 建立、推进、证明、转折、收束 |
| 问题 | 技术、连续性、产品、叙事或合规 |

### 3. 角色与空间连续性

检查跨镜头：

- 人物身份、服装、发型、左右位置和视线；
- 动作是否接得上；
- 道具数量、握持方式和位置；
- 场景朝向、门窗、光源和背景关系；
- 对话声线、环境声和空间感。

SAM 2 类分割/跟踪工具可以生成对象轨迹和遮罩证据，但不能独立判断“是否符合剧情”。

### 4. 产品一致性

以用户提供的产品参考图/视频为唯一事实源，逐镜核对：

- 可见结构、比例、部件位置和连接关系；
- 材质、颜色、文字、Logo；
- 操作方式和使用状态；
- 是否凭空增加、删除、移动或重设计部件；
- 产品是否被人物手部、光效或运动模糊遮挡到无法辨认。

不要只让模型凭文本“想象正确产品”。缺少目标角度时，应先基于真实参考生成关键帧并验收，再进入视频生成。

### 5. 感知质量

借鉴 Q-Bench-Video，将问题分为：

- 技术：清晰度、噪点、曝光、压缩、抖动、音画同步；
- 美学：构图、色彩、光线、主体突出和整体风格；
- 时序：闪烁、形变、运动不连续、纹理漂移；
- AIGC 特有：肢体/物体突变、文字崩坏、凭空出现、物理关系错误。

Video-MME-v2 提醒应单独检查信息查找、时间建模和跨时推理；只看单帧美不美不能替代动态理解。

## 严重度

| 等级 | 定义 | 示例 |
| --- | --- | --- |
| S0 阻断 | 无法发布或核心事实错误 | 产品结构错误、Logo 错、违规信息、音画损坏 |
| S1 严重 | 破坏理解或信任 | 角色突变、关键动作断裂、卖点未证明 |
| S2 一般 | 明显降低完成度 | 节奏拖沓、局部闪烁、字幕遮挡 |
| S3 建议 | 优化空间 | 构图、音效、转场可更精炼 |

报告应按严重度排序，并给出时间码、证据帧、影响和可执行修改。

## 两遍法

第一遍“观众模式”：不中断观看，记录理解、情绪、记忆点和困惑。

第二遍“取证模式”：逐镜读取，调用 OCR、波形、密集帧、对象跟踪或参考图比对，验证第一遍判断。

只做第二遍容易只见错误不见效果；只做第一遍则无法给出可修复证据。

## 标准输出

```md
# 成片 QA
## 目标契约与缺失输入
## 观众第一遍感受
## 故事与商业目标
## 逐镜问题表
## 产品/角色连续性
## 技术、美学、时序与 AIGC 问题
## 按严重度排列的修改清单
## 已通过项
## 未检查项与限制
```
