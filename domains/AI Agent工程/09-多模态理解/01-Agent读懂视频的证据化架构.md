# Agent 读懂视频的证据化架构

## 什么才叫“读懂”

视频不是一篇带画面的文本。它同时包含容器与编码、音频、画面、烧录字幕、时间关系、对象变化、剪辑结构和叙事意图。Agent 的合格交付物不是一段摘要，而是：

> 结论 + 时间范围 + 证据类型 + 证据内容 + 冲突/置信度。

同一视频可以有不同的“读懂”目标：

- 内容提取：讲了什么、有哪些步骤和术语；
- 定点问答：某个观点或操作出现在哪里；
- 时间推理：事件先后、因果、状态如何变化；
- 导演拆解：镜头、声音、节奏如何服务故事；
- 质量验收：是否存在技术、连续性、产品或叙事错误。

没有任务定义，就无法判断抽帧密度、OCR 范围和分析是否完成。

## 六层证据模型

| 层 | 典型证据 | 回答的问题 |
| --- | --- | --- |
| L0 媒体层 | 时长、分辨率、FPS、音视频流、旋转、码率 | 文件是否正常、怎样处理 |
| L1 分段层 | 镜头边界、静音、章节、黑场、场景变化 | 视频由哪些时间单元组成 |
| L2 语言层 | ASR、字幕、说话人、画面文字、PPT/UI OCR | 说了什么、屏幕写了什么 |
| L3 视觉层 | 代表帧、对象、人物、动作、环境、产品状态 | 画面发生了什么 |
| L4 时间层 | 对象轨迹、动作顺序、跨镜连续性、因果候选 | 前后如何连接与变化 |
| L5 意图层 | 教学结构、故事命题、品牌目标、质量标准 | 为什么这样组织、是否达成目标 |

上层推理必须引用下层证据。L5 的“作者想表达”属于解释，不能伪装成画面明确事实。

## 统一时间轴

所有中间产物使用同一个时间基准，最少保留：

```json
{
  "start_ms": 42310,
  "end_ms": 48720,
  "source": "asr|ocr|scene|frame|audio|tracking",
  "content": "证据内容或文件路径",
  "confidence": 0.86
}
```

推荐同时保存毫秒和人类可读时间码。帧号只适合 CFR 视频；存在可变帧率时，以实际时间戳为准。

## 三种采样不能互相替代

1. 均匀采样：成本低，适合快速建立全局印象，但容易漏掉短暂关键动作。
2. 场景采样：按剪辑边界取代表帧，适合短视频、广告片和快切内容。
3. 查询驱动采样：先用字幕或粗视觉定位，再对候选时间片加密取帧，适合长视频和精确问答。

稳定做法是“均匀/场景建立索引 + 查询驱动补证”，而不是只选一种。

## 多通道交叉校正

ASR、OCR 和视觉模型都会错，但错误分布不同：

- ASR 容易把术语、品牌名、英文模型名识别为同音常用词；
- OCR 容易受压缩、花字、运动模糊、背景和界面干扰；
- 视觉模型可能根据少量帧补全并未发生的动作；
- 字幕可能是作者后加的概括，并不逐字对应语音。

处理冲突时：

1. 保留各通道原始结果；
2. 标记冲突词和时间段；
3. 读取相邻字幕、画面 UI 和上下文；
4. 给出修订词及修订依据；
5. 证据不足就保留“不确定”，不强行统一。

本地抖音案例中，ASR 曾把“3D 白模”识别为“白毛”；画面字幕和故事板示例才能完成纠错。这说明“转写视频”不等于“读懂视频”。

## Evidence Ledger

Agent 回答时应维护证据账本：

| claim_id | 结论 | 时间范围 | 证据 | 状态 |
| --- | --- | --- | --- | --- |
| C01 | 作者建议用 3D 白模故事板提高一致性 | 00:08—00:24 | ASR + 字幕 + 画面案例 | confirmed |
| C02 | 所有生成模型都会因此稳定 | 无 | 无直接证据 | unsupported |

状态建议使用：

- `confirmed`：至少一个直接证据，关键结论最好跨通道确认；
- `inferred`：由多个证据合理推断；
- `conflicted`：通道之间不一致；
- `unsupported`：视频没有提供支持；
- `not-inspected`：相关时间段尚未读取。

## 读取深度路由

| 深度 | 适用 | 最小动作 |
| --- | --- | --- |
| D0 探测 | 文件检查 | ffprobe、音视频流、时长 |
| D1 速览 | 判断值不值得看 | 场景/均匀帧、短摘要 |
| D2 内容提取 | 教程、采访 | D1 + ASR + OCR + 章节 |
| D3 证据问答 | 精确问题、长视频 | D2 + 检索 + 局部密集观察 |
| D4 专项目标 QA | 广告、连续性、产品 | D3 + 对象轨迹 + 目标检查表 |

默认只做到满足问题的最低深度；发现证据冲突或高风险结论时升级。

## 完成条件

- 所有核心结论都有时间定位；
- ASR 专有名词已经过字幕/OCR或语境复核；
- 抽帧策略覆盖开头、结尾、镜头变化和问题相关片段；
- 明确区分事实、推断和未检查区域；
- 产物可供下一次查询复用；
- 给出限制：无音轨、字幕不全、遮挡、快切或未部署专项模型。
