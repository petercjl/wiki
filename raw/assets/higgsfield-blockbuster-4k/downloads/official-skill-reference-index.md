## 未来参考重点

1. 触发条件和“单个独立 Prompt”输出合同。
2. `@tag` 资产句柄、最小身份描述与无关资产隔离。
3. 固定主干加可选控制块的 Prompt 结构。
4. 单镜头、顺序切镜、定时多镜头和自由 B-roll 四种控制等级。
5. 把情绪翻译为动作、肌肉、视线、光线和物理行为。
6. FOV、表演、物理、灯光、声音和正向锁定的 QA 规则。
