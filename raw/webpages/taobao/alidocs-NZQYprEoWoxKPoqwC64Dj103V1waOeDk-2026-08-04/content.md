使用场景与优势

| 适用场景 | 不适用场景 |
| --- | --- |
| 商品大促场景：帮助用户快速花费预算，获取更多曝光量和转化量，提升起量效果，对于大促期间电商场流量高峰拿量较为有用 | 非常看重转化成本 |
| 常规投放场景：希望新广告快速起量，获取效果反馈 |  |

## 使用原理

|  | 套餐包 | 持续推广 |
| --- | --- | --- |
| 起量预算逻辑 | 从套餐包金额中划拨一部分进行起量 ，整体花费不变； 如小明买了5000元的套餐包，起量预算是300，则小明最后支付的是5000元 | 在日预算的基础上，额外新增一笔起量预算，日消耗=日预算+起量预算； 如小明设置¥300/日的持续推广计划，起量预算为60，则小明最后的日预算为300+60=360 |
| 出价逻辑 | 系统在6小时内花完指定预算尽快拿量，快速起量策略推出后平滑调价拉回成本 |  |
| 是否支持投中再次起量 | 不支持 | 支持 |
| 起量预算消耗时间 | 从设置起量后的6小时内，若6小时内未花完 | 从设置起量后的6小时内，若6小时内未花完，则起量预算不会继续消耗 |
| 设置流程 |  |  |
| 起量预算效果数据查看 | 注意： ① 仅针对2022-03-02创建的新计划提供起量周期效果数据查看 ② 起量周期数据为起量预算+日预算整体的效果表现，非单单起量预算部分 |  |
