全站推已经实现**商家营销回流再投放**的需求，商家可以在**达摩盘后台**对于全站推的回流数据**透视**和**二次营销**投放，具体步骤如下：

| 打开达摩盘后台，进入**人群管理tab**，选择**我的人群**板块 |  |
| --- | --- |
| 选择**自定义人群** |  |
| 搜索框选择**万相台无界版回流再营销** |  |
| **一二级场景**均选择货品全站推广 |  |
| 根据运营诉求进行**可选项的编辑**后创建完成 |  |
