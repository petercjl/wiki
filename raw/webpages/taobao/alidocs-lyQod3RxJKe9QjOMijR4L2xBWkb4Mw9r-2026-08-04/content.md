### 1、关键词推广计划上限情况。

每个账户默认20个推广计划，当达到准入门槛后，次日自动开通。具体门槛见下：

| **万相台无界版关键词推广计划数** | **准入门槛** | **开通方式** |
| --- | --- | --- |
| 20 | 无 | 自动开通 |
| 50 | 关键词推广近30天消耗>1500，近半年消耗>3000 | 自动开通 |
| 100 | 关键词推广近30天消耗>5w，近半年消耗>15w | 自动开通 |
| 200 | 关键词推广近30天消耗>50w，近半年消耗>200w | 自动开通 |
| 300 | 关键词推广近30天消耗>200w，近半年消耗>1000w | 自动开通 |

### 2、流量金卡算计划数么？

流量金卡计划数量单独统计，不计入关键词推广计划数。单卡片最多可以创建50个，流量金卡合计最多可创建300个。

​

​

### 3、迁移前后计划数量对应表情况

| **原直通车计划数量** | **万相台无界版 关键词推广计划数量** |
| --- | --- |
| 智能计划20个 + 标准计划8个 | 20个计划 |
| 智能计划20个 + 标准计划20个 | 50个计划（总量增加） |
| 智能计划20个 + 标准计划50个 | 100个计划（总量增加） |
| 智能计划50个 + 标准计划50个 | 100个计划（总量维持） |
| 智能计划100个 + 标准计划 100个 | 200个计划（总量维持） |
| 标准计划300个 | 300个计划（总量维持） |
