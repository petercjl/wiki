# GitHub Docs 内容类型模板来源记录

## 来源信息

- 来源：GitHub Docs 官方贡献者文档。
- 页面类型：不同内容类型的写作模板。
- 抓取日期：2026-07-30。
- 说明：该来源不是 Word 模板，但能说明“模板菜谱”如何根据读者任务定义不同内容骨架。

## 内容类型

GitHub Docs 为不同用户意图设置不同模板，包括：

- 概念说明；
- 参考资料；
- 操作指南；
- 快速开始；
- 教程；
- 语言指南；
- 服务卡片。

每类模板都规定标题、简介、正文模块和需要回答的问题。其价值不在视觉皮肤，而在于让作者选择与读者任务相匹配的结构。

## 对 Word 模板研究的迁移

- Word 模板不应只按“蓝色商务、极简灰、科技风”等美学标签分类。
- 更稳定的一级分类是读者任务：了解、决策、执行、查询、汇报、说服、留档。
- 同一视觉主题下，可以有报告、SOP、提案、备忘录等不同“内容菜谱”。
- 一套真正可用的模板资产需要把内容模型和视觉样式分离，又通过组件映射把两者重新组合。

## 限制

- 来源面向网页技术文档，不包含 Word 的分页、页眉页脚、题注、域和打印约束。
- 迁移到 Word 时必须重新考虑纸张、页长、表格跨页和可编辑性。
