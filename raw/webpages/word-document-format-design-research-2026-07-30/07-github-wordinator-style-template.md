# Wordinator DOTX 样式模板来源记录

## 来源信息

- 来源：GitHub 项目 `drmacro/wordinator`。
- 页面类型：DOCX 生成工具及 DOTX 样式管理说明。
- 抓取日期：2026-07-30。
- 用途：不是研究生成引擎，而是观察工程实践如何把 Word 样式模板作为稳定设计资产。

## 样式模板机制

- 项目把 Word 的 DOTX 文件作为样式定义来源，内容结构再映射到命名样式。
- 一份可用模板必须真实定义所需的段落、字符、表格等样式；只有名称但没有实际定义的潜在样式会导致映射失败。
- 新建或修改样式时，需要把修改写回模板，而不是只保存在某一份文档实例中。
- 已有文档中的样式可以通过 Word 的样式管理/组织功能迁移到模板。
- 内容元素到样式名称的映射应显式管理，例如正文、标题、强调、列表、题注分别映射到不同语义样式。

## 对本研究的意义

该项目提供了“食材—菜谱—出菜”的工程对应关系：

- 食材：Word 能表达的格式和组件；
- 菜谱：DOTX 中的样式、页面设置、组件与适用规则；
- 出菜：某篇具体文档对模板样式的调用。

它也提示模板资产不能只保存一份看起来漂亮的 DOCX，还应保存样式清单、命名约定、内容到样式的映射和验收规则。

## 限制

- 项目核心仍是生成技术，不应成为文档设计理论的主要来源。
- README 中的具体命令、依赖和版本具有时效性，本研究只提取模板与样式管理原则。
