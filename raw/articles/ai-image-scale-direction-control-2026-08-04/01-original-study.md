# AI生图实战经验：皮鞋"自主行走斑马线"场景——尺寸比例与朝向约束研究

## 一、研究背景

**目标场景**：超现实主义创意画面——一双黑色商务休闲皮鞋，在没有人物出现的情况下，"自己"走过城市清晨的斑马线，营造电影剧照般的诗意叙事感。

**使用模型**：gpt-image-2

**参考图构成**：

- 产品图：黑色商务休闲皮鞋白底四视图（荔枝纹黑皮、棕色内里、厚底防滑鞋底、四孔系带）
- 场景角度参考：城市林荫道正前方透视
- 光影色彩参考：暖金晨光+冷灰蓝阴影的电影色调板

**核心难点**：AI在处理超现实场景时，容易出现两类系统性失真——主体尺寸巨大化（皮鞋比门还大）、朝向失控（鞋头朝镜头而非行走方向）。

---

## 二、问题一：主体尺寸相对比例约束

### 2.1 问题现象

AI倾向于把"主体"理解为"填满画面的大特写"，导致皮鞋尺度过大——鞋长超过斑马线白线宽度、比路缘石高、甚至比远处建筑的门还大，物理比例完全崩坏。

### 2.2 失败方案（按约束力从弱到强）

|方案|约束写法|效果|
|---|---|---|
|模糊比例词|"真实比例""不要太大""符合真实尺寸"|❌ 几乎无效，AI不理解否定词|
|画面占比数字|"鞋在画面中仅占高度的1/5"|⚠️ 部分有效，AI对"1/5"执行力不稳定|
|镜头焦距+距离|"35mm镜头，距鞋2.5米"|⚠️ 有一定帮助，但单靠数字仍会跑偏（方案A综合约束版鞋子仍然偏大）|
|远景留白|"50mm镜头，距鞋5-6米，占比1/10"|✅ 尺度真实了，但鞋太小成了环境点缀，失去产品展示价值（方案B远距叙事版）|

### 2.3 ✅ 有效方案：前景参照物递进阶锚定法（方案C贴地低角版）

**核心思想**：不用抽象数字约束尺寸，而是在画面前景放置多层**已知真实尺寸**的参照物，通过"近大远小"的透视递进关系，让AI自动推理出主体的正确尺度。

**约束结构**：

```
【镜头与尺度硬约束】
- 镜头：28mm轻微广角，镜头几乎贴地（距地面10-15cm）
- 前景锚点（画面最前1/3）：
  · 沥青路面粗糙颗粒纹理（超近距离超大纹理）
  · 梧桐枯叶数片，每片叶子约8-10cm
  · 最近的斑马线白色粗条纹完整铺在前景，白线宽约40cm
- 透视递进：通过近景元素自然过渡，让中景的皮鞋呈现真实大小
  · 皮鞋距离镜头约3米远
  · 鞋长约30cm（≈前景白线宽度的3/4）
  · 鞋在画面中约占高度的1/6
- 透视规律：斑马线条纹从近到远由粗变细，严格遵循线性透视
```

**为什么有效**：

- 给AI的不是"占比1/5"这类抽象要求，而是具体的"画了什么东西、各多大"的画面指令
- 前景参照物（叶子8-10cm → 白线40cm → 鞋30cm → 树干→建筑）形成连续的尺度链条
- AI在生成画面元素时，会自然保持元素之间的相对比例关系
- 贴地广角视角本身就需要前景大纹理/大叶子来建立透视，尺度锚点与画面美学需求天然契合

### 2.4 尺寸约束可接受方案

经过测试，以下两种方案均能获得可接受的尺度效果：

- **方案B（50mm远距叙事）**：鞋小但氛围强，适合品牌海报/KV
- **方案C（28mm贴地低角+前景锚点）**：鞋尺度真实且足够大，兼顾产品展示与氛围感，**为最终采用方案**

## 三、问题二：主体朝向约束

### 3.1 问题现象

AI对"横穿""向前走""朝前"等方向词的理解依赖场景默认值——在正前方透视道路场景下，"前"默认=朝向镜头方向；加上两只鞋容易被生成横向并排状态，导致鞋头朝镜头飘来，而不是沿行走方向运动。

### 3.2 失败方案（按约束力从弱到强）

|方案|约束写法|效果|
|---|---|---|
|方向动词|"横穿马路""走过斑马线""朝前走"|❌ "前"被理解为朝镜头，严重跑偏|
|时钟单点坐标|"鞋头朝3点钟方向"|⚠️ 方向对了，但步态容易变成"平移飘"而非行走|
|时钟坐标+线条对齐|"鞋头朝1:30方向，与道路中心线呈45度"|❌ 后脚鞋型严重走样（系带鞋变成乐福鞋）|

### 3.3 ✅ 有效方案：时钟坐标 + 环境线条对齐 + 步态序列分解 三重锁定（方向C正侧面版）

**核心思想**：单一方向词不够，必须同时锁定**鞋头绝对方位**、**与环境线条的关系**、**两只鞋的前后位置与步态分解**，三管齐下。

**约束结构**：

```
【步态与朝向硬约束】
- 绝对方向：两只鞋从画面左侧向右侧横穿，鞋头一致指向画面正右侧（3点钟方向），鞋跟朝画面左侧
- 环境对齐：与斑马线白色条纹垂直、与道路中心线垂直（正侧对镜头）
- 步态分解（两只鞋角色明确）：
  · 前脚（画面右侧）：落地承重，鞋外侧全貌可见——鞋头侧面弧度、鞋面车线、四孔系带侧面、厚鞋底防滑纹路、后跟弧度清晰展现
  · 后脚（画面左侧）：蹬地离地向前摆动，鞋底与地面3-5cm缝隙，鞋跟微微抬起
- 步幅与排列：两只鞋沿水平方向左右相距约60cm（一个自然步幅），横向排列但有前后（远近）轻微错开表现纵深，步态方向一眼可辨从左向右横穿
```

**为什么有效**：

- **时钟坐标**（3点钟方向）给了AI画面上的绝对方位，消除"前/后/左/右"的歧义
- **环境线条对齐**（与斑马线白线垂直、与道路中心线垂直）利用了场景中已有的强烈透视线，让鞋头方向与这些线条绑定
- **步态序列分解**（哪只脚在前/做什么/能看到什么细节）让AI不再把两只鞋当成独立物体，而是理解成一个连贯步态的两个时间切片

### 3.4 朝向测试结论

|方向|鞋头指向|效果|结论|
|---|---|---|---|
|A 纵深走向对面|12点钟（画面深处）|只能看到后跟，无产品展示价值|❌ 淘汰|
|B 斜侧45度横穿|1:30钟方向|理论展示角度最佳，但AI处理后脚离地时鞋型严重走样|❌ 鞋型还原不稳定|
|C 正侧面横穿|3点钟方向（正右）|鞋型还原最好，步态自然，外侧全貌可见|✅ **唯一可接受方案**|

## 六、方法论提炼：AI生图"约束"的底层逻辑

经过本次探索，可以归纳出两条通用原则：

### 原则一：用"画什么"代替"不要怎样"

|❌ 低约束力|✅ 高约束力|
|---|---|
|"不要太大""真实比例"|"前景落叶8-10cm，白线宽40cm，鞋长30cm（≈白线的3/4）"|
|"鞋头朝前走"|"鞋头指向画面3点钟方向，与斑马线白线垂直"|
|"不要并排"|"两只鞋沿水平方向左右相距60cm，前后轻微错开表现纵深"|

AI不是听得懂"要求"，而是画得出"画面"。与其告诉它"不要怎样"，不如直接告诉它"这里应该有什么、各多大、朝向哪里"。

### 原则二：用"关系锚点"代替"绝对数字"

孤立的数字（"占画面1/5""距离镜头2.5米"）AI执行力有限；但当你把主体放进一个**有多层已知尺寸参照物构成的关系网络**里，AI就会在渲染元素间关系时自动保持比例——这是利用了AI生图的"场景一致性"先验，比任何抽象比例指令都有效。

### 原则三：复杂姿态必须"分解到每只脚"

描述步态时，不要只说"在走路"，要明确：

- 哪只脚在前、哪只在后
- 前脚是什么状态（落地/承重/哪个部位可见）
- 后脚是什么状态（蹬地/离地/抬起高度）
- 两只脚之间的空间关系（距离、排列方式、朝向）

把一个"走路"的动作拆成两个独立物体各自的具体状态描述，AI就不会把两只鞋当成对称摆件。
