# 生图主体比例与朝向控制：通用方法论初测

日期：2026-08-04  
模型路径：Codex 内置 `imagegen`  
测试性质：探索性单次对照（每个方案 n=1），可用于筛选机制，不代表统计成功率。

## 1. 结论摘要

1. **朝向比比例更容易由文字稳定控制。** 五组结果都正确执行了“画面左→右、主体自身后端→前端、主轴近水平、侧面可见”。
2. **比例不能仅靠提示词硬控。** 物理尺寸、画面百分比和抽象占位框都可能被“广告主体应放大”的模型先验覆盖。
3. **真实构图参考图是本轮比例控制的决定性因素。** 带最终效果构图参考的 B/C，主体尺度明显接近目标；去掉该参考后的 D，即使保留相同数字与尺度链，主体仍被显著放大。
4. **抽象控制图更擅长位置，不擅长尺寸。** E 基本遵守左右位置与方向，但把占位框内的主体放大。
5. 通用生产方案应分档：
   - 容许波动：提示词软控制；
   - 要求稳定：提供具有真实透视和真实尺度关系的场景级构图参考；
   - 要求像素级精确：使用确定性合成、区域控制或 3D/布局工具，不再继续堆提示词。

## 3. 通用约束协议

### 3.1 参考图先分工

不要笼统地说“参考这些图片”。为每张图指定唯一职责，并给出冲突优先级：

```text
参考图职责：
1. 主体身份图：主体身份的唯一事实来源。
2. 构图/机位图：只负责画幅、相机方向、透视和主体位置。
3. 风格图：只负责光线、色彩、材质表现和氛围。
4. 可选场景级关键帧：负责主体尺度、空间关系和留白。

冲突优先级：主体身份 > 朝向 > 物理尺度 > 动作细节 > 风格。
```

主体锁定保持关系化、参考化，不把产品细节重新抄进提示词：

```text
主体身份只来自参考图 1。所有可见结构、比例、部件位置、材质、颜色、文字、标识和连接关系均遵循参考图；不得新增、删除、移动、重释或重新设计主体部件。
```

### 3.2 比例控制栈

比例至少用四层互相校验，不依赖单一百分比：

```text
【比例控制】
1. 同平面锚点：主体与一个具有常识尺寸的参照物处于同一透视/地面平面。
2. 相对尺寸：主体相对该参照物是略小、相等或几倍关系。
3. 尺度链：近景小物/纹理 → 同平面锚点 → 主体 → 中远景建筑/家具/人物，透视连续。
4. 构图保险：主体组位于画布约 (x=?, y=?)；宽约 ?–?%，高不超过 ?%；至少 ?% 画面保留环境。
5. 裁切限制：主体完整出现，不能触碰哪些画面边界。
```

关键规则：

- 百分比是“保险线”，不是主约束。
- 最有用的参照物必须与主体处于同一深度平面；前景物只能帮助建立透视，不能单独证明主体真实尺寸。
- “不要太大”应改写成“主体与什么相比多大、画面还必须保留什么”。
- 若模型仍放大，优先增加真实构图参考，不要继续增加更多孤立数字。

### 3.3 朝向控制栈

朝向不要只用世界语言中的“向前、向左”，应显式建立画布坐标系：

```text
【朝向控制】
1. 画布坐标：屏幕 x 轴为左→右，y 轴为上→下；目标运动向量为 [→/←/↗/...]。
2. 主体自身轴：主体后端→前端、尾部→头部或根部→尖端必须指向目标向量。
3. 角度容差：主体主轴相对画面水平/垂直线保持在 ±?°。
4. 环境关系：主体主轴与道路线、桌边、地砖缝、地平线等平行/垂直。
5. 可见面：明确看正面、侧面、背面、顶面中的哪一面，用于排除镜头歧义。
6. 角色分解：多主体或复杂姿态时，分别定义每个对象/部件的位置、状态、前后关系和动作阶段。
```

通用方向句式：

```text
目标运动向量为画面左→右（+x，→）。主体自身的【后端】→【前端】轴与 +x 同向，主轴与画面水平线夹角不超过 ±5°；主体同时与场景中的【环境线】垂直。镜头看到【指定可见面】，不看到【会造成歧义的面】。
```

### 3.4 多主体动作分解

```text
对象 A 位于目标方向前方，处于【承重/接触/展开/完成】阶段；
对象 B 位于后方一个自然间距，处于【离地/摆动/收拢/准备】阶段；
两者是同一动作的连续阶段，不是对称陈列。
```

## 4. 推荐的通用 Prompt 模板

```text
用途：{广告关键帧 / 分镜关键帧 / 产品场景图 / 角色场景图}
目标：在 {场景} 中生成 {主体}，完成 {动作或叙事}。

【参考图职责】
参考图 1 是主体身份的唯一事实来源。所有可见结构、比例、部件位置、材质、颜色、文字、标识和连接关系均遵循它；不得新增、删除、移动、重释或重新设计主体部件。
参考图 2 只负责 {构图、机位、透视、场景几何}。
参考图 3 只负责 {光线、色彩、材质表现、氛围}。
参考图 4（如有）只负责 {主体尺度、位置、空间关系、留白}。

【比例控制】
主体与 {常识尺寸锚点} 位于同一 {地面/桌面/墙面} 深度平面。
在该平面上，主体尺寸约为锚点的 {相对关系}。
画面形成 {近景参照} → {同平面锚点} → 主体 → {中远景参照} 的连续透视尺度链。
完整主体组位于画布约 (x={?}%, y={?}%)，宽约 {?–?}%，高不超过 {?}%；至少 {?}% 画面保留环境。

【朝向控制】
屏幕坐标中，目标方向为 {+x / -x / +y / 向量箭头}。
主体自身的 {后端}→{前端} 轴与该向量同向，和画面 {水平/垂直} 线夹角不超过 ±{?}°。
主体主轴与场景中的 {环境线 A} {平行/垂直}，与 {环境线 B} {平行/垂直}。
镜头看到主体的 {指定可见面}，不采用 {歧义视角}。

【动作/多主体角色】
对象 A：{位置、接触状态、动作阶段、可见面}。
对象 B：{位置、接触状态、动作阶段、可见面}。
两者表现同一动作的连续阶段，不是对称陈列。

【优先级】
主体身份 > 朝向 > 物理尺度 > 动作细节 > 风格。

【避免】
避免改变参考主体、主角式夸张放大、错误可见面、主轴旋转、对称陈列、无依据漂浮、重复主体、额外部件、文字和水印。
```

## 5. 当前鞋子案例的推荐策略

本案例优先使用 B/C 的组合：

- 原始鞋图只负责产品身份；
- 街景图负责道路与机位；
- 风格板负责光色；
- 最终效果图负责主体尺度、位置和留白；
- 提示词继续用 `+x/→`、后跟→鞋头轴、与斑马线垂直、侧面可见、前后鞋角色分解做方向校验。

不建议把鞋长、孔数、缝线、部件位置等识别笔记重复写入生成提示词；这些只用于生成后的 QA。

## 6. 下一轮验证建议

若要把方法论升级为可复用规范，下一轮应做重复采样，而不是继续增加形容词：

1. 选 3 类主体：刚性产品、车辆/工具、人物或角色。
2. 每类选 3 种方向：水平、斜向、朝向纵深。
3. 对“仅文字”“真实构图参考”“抽象控制图”各生成至少 5 次。
4. 记录：主体包围盒占比、主轴角度误差、指定可见面命中率、结构变形率。
5. 只有重复结果达标后，才把规则写成稳定生产模板。
