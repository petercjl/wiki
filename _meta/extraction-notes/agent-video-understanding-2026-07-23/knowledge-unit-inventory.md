# 知识单元清单

## 总体架构

- KU01：读视频的交付物应是“结论 + 时间范围 + 证据类型 + 置信度/冲突”，而不是无来源摘要。
- KU02：视频需先解复用为元数据、音频、画面和时间轴；所有后续产物必须共享统一时间坐标。
- KU03：均匀抽帧只能做预览；镜头切分与按问题追加取证共同降低漏读。
- KU04：音频、烧录字幕/OCR、视觉和上下文是相互校正的通道，不能把 ASR 当成最终事实。
- KU05：读视频深度应按问题路由：速览、内容提取、精确问答、叙事/广告 QA、对象连续性。
- KU06：结果必须区分“视频明确呈现”“工具推断”“Agent 解释”。

## 教学短视频

- KU07：短视频适合一次性生成完整证据包：ffprobe、镜头边界、密集开头帧、ASR、OCR、联系表。
- KU08：开头 3—10 秒常承载钩子、问题和核心承诺，采样密度应高于主体。
- KU09：教程中的软件名、模型名、提示词和术语必须用字幕/OCR校正 ASR。
- KU10：输出应还原“问题—方法—步骤—例子—限制—行动召唤”，并附关键时间点。
- KU11：抖音/视频号界面文字、作者字幕和画中软件 UI 应分层识别，避免混为正文。

## 长教学视频

- KU12：长视频不能只用固定数量均匀帧或一次性上下文压缩，否则会丢失稀疏证据。
- KU13：第一层建立章节/场景/字幕索引，第二层按问题检索候选片段，第三层局部精读。
- KU14：字幕检索适合定位“讲了什么”；视觉查询负责对象、动作、屏幕内容和演示步骤。
- KU15：Agent 应执行有上限的迭代循环：检索—观察—判断证据是否足够—继续或回答。
- KU16：长视频要保存可复用索引和 chunk 摘要，避免每个问题都从零转写和抽帧。
- KU17：跨视频课程需要图或层级索引，连接人物、概念、章节、例子和时间片。
- KU18：章节摘要不能替代原始时间片；回答必须回链到局部证据。

## 故事广告与产品广告

- KU19：广告片的“读懂”至少包括故事目标、受众、冲突、转折、产品角色、品牌记忆点和 CTA。
- KU20：镜头级分析应记录景别、机位、运动、光线、表演、对白/声音、时长和转场功能。
- KU21：质量 QA 要分开技术质量、美学质量、时间连续性、AIGC 失真和业务目标。
- KU22：角色/产品连续性需要对象轨迹或区域级检查；SAM 2 类工具是证据工具，不是最终裁判。
- KU23：产品广告还需把产品结构、颜色、标识、部件关系与参考素材逐镜核对。
- KU24：广告片最合适的阅读入口不是开放式“总结”，而是带目标的检查表和失败严重度。
- KU25：音效、音乐、对白与画面节奏共同构成叙事，静音抽帧不足以判断成片。

## Agent 与工具协议

- KU26：稳定实现面应定义 `probe/transcribe/detect-scenes/extract-frames/ocr/index/query/qa` 等可组合能力。
- KU27：Codex 与 SealSeek 应共享文件型中间产物，如 manifest、SRT、scene JSON、OCR JSON、evidence ledger。
- KU28：工具调用要先定位再提取；长视频避免让视觉模型反复扫描全片。
- KU29：按能力选工具：确定性预处理、本地 ASR/OCR、VLM 语义解释、RAG/Agent 检索、专项 QA。
- KU30：模型和工具输出必须能回退；单一 VLM、ASR 或 benchmark 分数不能成为唯一判据。
- KU31：测试集必须覆盖三类视频以及术语、长尾证据、无字幕、快切、长镜头、产品一致性等失败模式。

## 评测和演进

- KU32：理解评测应拆成信息查找、时间建模、跨时推理、音频利用、动作/物理理解。
- KU33：广告质量评测应拆成技术、美学、时序和 AIGC 特有失真，并叠加业务目标。
- KU34：开源项目应按“采用、借鉴协议、暂不安装”分级，不能因下载仓库就默认进入生产栈。
- KU35：重复需求成熟后应收敛到稳定 CLI 命令、解析器、测试和 Skill 文档，而非永久使用一次性脚本。
