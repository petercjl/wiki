# Image analysis

The 2,027 images are predominantly interface screenshots, configuration steps, field diagrams, product posters, campaign rules and case results.

## Retrieval policy

- Text carries concepts, decisions and searchable operating rules.
- Image manifests preserve every source image and its local file.
- A stable page should surface an image only when it materially clarifies UI location, field mapping, workflow or evidence that prose cannot replace.
- Decorative posters and expired campaign banners remain available in raw packages but are not duplicated into every formal page.
- Image-only claims must be described in prose when needed for semantic retrieval; screenshots are evidence, not the only carrier of the rule.

## Quality risks

- Some source extensions may not match the actual image signature; copied aliases must use the detected format without modifying bytes.
- UI screenshots are time-sensitive and must not override current backend behavior.
- Small text, crop loss and composite screenshots can weaken OCR; high-risk numeric claims require cross-checking against source text or current UI.
