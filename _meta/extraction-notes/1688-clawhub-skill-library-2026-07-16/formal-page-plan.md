## 为什么最终这样放

- 内容是 1688 平台专属，用户希望未来所有 1688 平台知识具有独立入口；CLI 是该平台下的一个具体工具专题。
- 以 3 个强页面融合 7 份 Skill，可同时保留逐能力细节和跨 Skill 的旅程路由，避免 7 个互相重复的薄页。
- 查询入口让未来 Agent 不需要记住页面数量，即可从“找货、比价、找工厂、询盘、铺货、活动、采购单”等自然语言进入。
