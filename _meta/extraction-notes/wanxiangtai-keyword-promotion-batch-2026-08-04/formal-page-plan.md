# 正式页计划

- Source understanding：10 份来源围绕流量智选治理、新品、选品、机会品和关键词人群，不是 10 个互相独立的方法。
- Existing category：`万相台无界白皮书/01-关键词推广` 已是本批次的确认模块。
- Disposition：异常流量过滤 `extend-existing-with-section`；其余来源按主题 `merge-into-new` 为 4 页。
- 新页：新品推广、搜索机会品、智能选品、关键词推广人群。
- 用户确认：用户确认“我要推广”按目录连续编译，并明确要求先串行处理 10 个文档。
- Confirmation evidence：当前对话“继续 你不用一个个做，可以串行，先做10个文档的知识库编译”。
- Rejected alternative：一文一页；会产生“如何选人”25字空壳和多份重复机会品/新品页面。
- Query entry：not-needed；关键词推广模块索引已能按新品、机会品、智能选品、人群拿量和流量智选问题路由，新增 Query 会造成入口过细。
