# Knowledge Unit Inventory

| id | unit | reusable knowledge |
| --- | --- | --- |
| K01 | 先故事再人物 | 角色资产必须从故事功能、性格、欲望、关系和视觉暗示推导。 |
| K02 | 男频/女频视觉差异 | 受众爽点决定角色轮廓、光影、服饰、表情和镜头节奏。 |
| K03 | AI 辅助提取资产 | 剧本先抽取人物、场景、道具，再生成结构化 prompt。 |
| K04 | 工具平台抽象 | 平台按钮对应生成任务、模型路由、画幅协议、后处理和审核门。 |
| K05 | 模型路由 | 不固化模型名，按中式古装、真实感、prompt 理解、成本和定稿质量选择。 |
| K06 | 角色定妆规范 | 全身正面、纯白底、无手持物、鞋子可见、中性表情、贴合时代。 |
| K07 | 角色 QA | 服化道、比例、表情、审美灰脏、背景污染和手持物污染都要独立检查。 |
| K08 | 四视图 | 正面全身定稿后生成脸部特写 + 正侧背三视图，作为最小身份板。 |
| K09 | 场景库 | 场景是空间化叙事工具，先列场景名、剧情功能、时间、陈设、光影和视角需求。 |
| K10 | 多视角场景 | 四宫格用于从同一空间推导俯拍、正向、左侧、右侧视角。 |
| K11 | 反打场景 | 反打靠视觉锚点、前中背景、视线方向、构图和同一空间一致性。 |
| K12 | 道具资产 | 道具应单件、纯白底、无人物、符合时代气质，并明确剧情功能。 |
| K13 | 交付包 | 剧本梗概、角色四视图、核心场景图、道具图和 QA 记录组成资产包。 |
| K14 | 时效边界 | 具体模型能力、价格、审核政策属于执行前复核项。 |
