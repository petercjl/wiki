# 抖音商品卡选品诊断入口

当用户询问抖音商品卡选品、类目机会、需供比、商机中心、跟款、商品榜单、店铺榜单、UV价值或竞品筛选时使用。

2. [[domains/电商运营/05-抖音/01-商品卡运营/02-商机中心数据化选品SOP|商机中心数据化选品 SOP]]

## 分支读取

- 需要判断企业是否有资格进入大市场：[[domains/电商运营/01-通用电商方法/04-选品与运营增长/01-电商运营与选品策略深度解析/02-市场分层与选品策略|市场分层与选品策略]]。
- 需要把候选款变成月度执行动作：[[domains/电商运营/01-通用电商方法/04-选品与运营增长/01-电商运营与选品策略深度解析/03-选品库与月度打款机制|选品库与月度打款机制]]。
- 需要完整核算成本和 SKU 利润角色：[[domains/电商运营/01-通用电商方法/05-产品开发与供应链管理系统/04-成本结构利润模型与SKU角色|成本结构、利润模型与 SKU 角色]]。

## 最少输入

- 商家主体、主营类目、店铺阶段和可售资质。
- 目标类目/商品及数据采集时间。
- 成交人数、动销商品数、1/7/30 日趋势和需供比。
- 商品卡/直播/短视频分渠道成交。
- TOP 商品或竞品链接、价格带、转化和退款信息。
- 采购、包装、物流、佣金/广告和售后成本。
- 库存、交期、运营渠道能力和试款预算。

## 诊断顺序

```text
行业容量与趋势
→ 需供竞争
→ 渠道适配
→ 头部/品牌壁垒
→ 价格带与完整利润
→ 商机标签与多窗口数据
→ 生命周期与竞品
→ 测试动作和止损
```

## 输出结构

1. 当前最大机会或阻断项。
2. 行业七道门结论。
3. 商机商品 A/B/C 分级。
4. 生命周期阶段和竞品证据。
5. 完整利润与履约风险。
6. 测试、观察或放弃动作。
7. 需要从当前后台补取的数据。
8. 课程阈值与当前事实的区分。

## 边界

- 课程阈值是 2026 年 1 月教师经验，不能冒充平台门槛或类目基准。
- 商机中心、罗盘、选品广场、权益和资格必须以执行当天当前账号页面为准。
- 不用“平台只给五家流量”等未经证实的黑箱说法解释结果。
- 没有利润、退货、库存和渠道能力数据时，不得给出“一定能做/一定能爆”的结论。
