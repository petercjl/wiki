# AI 生图主体比例与朝向控制查询入口

当用户出现以下需求时，先读本入口：

- 主体太大、像巨物、挤满画面或与环境比例失真；
- 产品朝向不听指令、鞋头/车头/人物面向镜头；
- 需要主体从 9 点走向 3 点、沿某条环境线移动或保持指定侧面；
- 多主体动作变成对称陈列、平移或漂浮；
- 需要为视频生成稳定的产品/角色关键帧；
- 要判断仅靠 Prompt、构图参考或确定性合成中的哪一种方案。

## 标准执行步骤

```text
1. 标注每张参考图的唯一职责：身份 / 构图机位 / 风格 / 场景关键帧。
2. 确认原始身份图，禁止把失败派生图作为身份来源。
3. 比例：选择同平面尺度锚点，建立连续透视尺度链。
4. 比例保险：写主体组 x/y 区域、宽高范围、环境留白和裁切边界。
5. 朝向：写画布运动向量、主体后端→前端轴、角度容差、环境线关系和可见面。
6. 多对象：分别写前导/后随、承重/离地和动作阶段。
7. 声明冲突优先级，独立生成，不拿失败稿继续迭代。
8. 按占位、角度、可见面、动作角色和身份一致性逐项验收。
9. 若仍需像素级准确，停止堆 Prompt，切换确定性工具。
```

## 输出结构

```text
1. 参考图职责表
2. 同平面尺度锚点与透视尺度链
3. 画布占位保险
4. 朝向向量、主体自身轴、环境线和可见面
5. 多对象动作角色
6. 冲突优先级
7. 完整 Prompt
8. 生成后 QA 与失败升级路径
```

## 执行边界

- 不把“真实比例”“不要太大”当作充分约束。
- 不把百分比或抽象框图称为硬包围盒。
- 不把产品识别细节逐项重写进生成 Prompt。
- 不把一次成功升级为稳定成功率。
- 不承诺纯 Prompt 实现像素级比例；严格任务应切换区域控制、合成、3D 或后期。
