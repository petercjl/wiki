# Agent 读懂视频入口

## 何时使用

- “帮我读/理解/总结这个视频。”
- “这段课程讲了什么，某个观点在哪里？”
- “分析一两个小时的教学视频。”
- “检查我的故事广告或产品广告。”
- “Codex/SealSeek 应怎样读取视频？”
- “选什么 GitHub 项目做视频理解？”

## Agent 标准诊断

1. 识别视频类型、时长和用户问题。
2. 确认是速览、内容提取、证据问答还是目标 QA。
3. 检查本地已有证据包和工具，避免重复转写或下载模型。
4. 建立统一时间轴：元数据、场景、ASR、OCR、帧和对象轨迹。
5. 短视频一次完成证据包；长视频先索引、检索、再局部精读。
6. 广告片先取得目标、剧本和参考素材，再按失败严重度报告。
7. 所有关键结论附时间码，标记事实、推断、冲突和未检查项。

## 向用户补充索取

- 视频文件或可下载链接；
- 具体想知道的问题；
- 长课程是否需要一次性总结还是长期查询；
- 广告片的目标、剧本/分镜、产品/人物参考和发布规范。

缺少后两项时仍可开始媒体探测和通用读取，但应说明分析边界。

## 标准输出

- 一句话结论；
- 结构化内容或 QA 结果；
- 关键时间点；
- 证据通道及纠错；
- 可复用产物路径；
- 限制、冲突和未检查范围；
- 下一步需要局部精读或修复的事项。
