# 拼多多开店与合规决策

## 触发语

- 应该开个人店、企业店、旗舰店、专卖店还是专营店？
- 能不能多开店、一个主体能开几家、账号怎么管理？
- 保证金交多少、能否退、活动保证金有什么区别？
- 主营类目怎么选、能否修改、错放类目有什么风险？
- 收到违规通知、物流异常、知识产权投诉或资金限制怎么办？

## 按问题读取

- 店铺类型与品牌：[[domains/电商运营/04-拼多多/04-店铺类型品牌权益与店铺权重|店铺类型、品牌权益与店铺权重]]

- 主营类目：[[domains/电商运营/04-拼多多/07-主营类目选择与变更规则|主营类目选择与变更规则]]
- 违规风控：[[domains/电商运营/04-拼多多/08-平台规则红线与合规风控|平台规则红线与合规风控]]

## 标准输出

1. 当前主体、品牌授权、商品、类目和经营目标。
2. 当前后台/官方规则可确认的事实。
3. 需要核验的时效参数：金额、次数、时限、资格和处罚。
4. 推荐方案及不推荐方案。
5. 主体、账号、资金、履约、知识产权和税务风险。
6. 下一步后台检查或专业咨询清单。

## 边界

- 不提供短期号码、借实名、批量注册资源、错放类目、刷单、套补贴或规避关联检测的方法。
- 不把课程中的店铺数量、保证金金额、处罚比例和时限当成当前规则。
- 涉及法律、税务、知识产权和产品安全时，不替代专业意见。
