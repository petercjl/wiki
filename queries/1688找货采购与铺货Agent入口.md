# 1688 找货采购与铺货 Agent 入口

## 何时使用

用户提到 1688 找商品、找同款、图片找货、链接比价、找供应商/工厂/产业带、采购询盘、招商活动、商机、选品铺货、绑定店铺、分销订单、旺旺催发、88 生意通采购单或店管家经营问题时使用。

1. [[domains/电商运营/07-1688/01-1688CLI/02-从找货到采购铺货的意图路由与工作流|从找货到采购铺货的意图路由与工作流]]
2. [[domains/电商运营/07-1688/01-1688CLI/01-1688采购与分销Agent能力地图|1688 采购与分销 Agent 能力地图]]
3. 真实执行时读 [[domains/电商运营/07-1688/01-1688CLI/03-1688电商Skill执行安全与输出契约|1688 电商 Skill 执行安全与输出契约]]，再定位当前 Skill 的 `SKILL.md` 与 capability reference。

## 先问清楚

- 是找商品、找企业、发布询盘、铺货、参加活动，还是管理交易？
- 是否已有具体商品 ID、链接或目标供应商？
- 输入是文字、图片还是链接？是否明确比价？
- 询盘是否具备商品名、纯数字数量和需求？
- 铺货目标店铺是否唯一且已授权？
- 是否涉及报名、铺货、退款、确认收货、拒签或失效？

## 标准执行

1. 按对象确定性和动作选择 Skill。
2. 读取当前 reference，不从知识库猜参数。
3. 补齐输入，不改写原话。
4. 判断读取、写入、不可逆写入或资金/状态变化。
5. 达到该能力的确认要求后执行。
6. 按输出契约展示，数据与分析分层。
7. 失败时输出真实错误，不用浏览器或搜索引擎补业务数据。

## 输出结构

- 意图判断与所选 Skill
- 缺少的输入或确认
- 原始业务结果
- 必要风险、授权或时效说明
- 仅在来源流程允许时给出下一步

## 边界

- 本批来源不含 `1688-order` 完整下单说明；已有商品直接下单时只能路由，不能虚构命令。
